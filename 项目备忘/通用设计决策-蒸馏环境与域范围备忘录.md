## 一、蒸馏取证环境

### 1.1 取证浏览器（Chrome for Testing · 规划人员登录）

| 项 | 值 |
| :--- | :--- |
| 浏览器 | **Google Chrome for Testing**（“测试版谷歌浏览器”，独立于日常 Chrome） |
| 二进制路径 | `~/.cache/puppeteer/chrome/mac-149.0.7827.22/chrome-mac-x64/Google Chrome for Testing.app/Contents/MacOS/Google Chrome for Testing` |
| 调试端口 | `9222`（CDP；`cdp-capture.js` 默认连此端口，可用 `CDP_PORT` 覆盖） |
| 独立 profile | `~/.chrome-cdp-profile`（**必需**：Chrome 136+ 默认 profile 下 `--remote-debugging-port` 不生效） |

**启动命令**（先用 `osascript -e 'quit app "Google Chrome"'` 确保普通 Chrome 已退干净）：

```bash
"$HOME/.cache/puppeteer/chrome/mac-149.0.7827.22/chrome-mac-x64/Google Chrome for Testing.app/Contents/MacOS/Google Chrome for Testing" \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/.chrome-cdp-profile" \
  --no-first-run --no-default-browser-check
```

> ⚠️ 独立 profile 是全新环境 → 首次需**重新登录**三套系统；会话只在该 profile 内保持。

### 1.2 取证工具

| 工具 | 路径 | 作用 |
| :--- | :--- | :--- |
| CDP 只读取证 | [`tools/cdp-capture.js`](../tools/cdp-capture.js) | `list / probe / shot / text / eval / nav / click / hover / mouse / open`；对已在 Chrome 中登录的页面**只读**取证 |
| 内网访问通道 | [`tools/internal-reverse-proxy.js`](../tools/internal-reverse-proxy.js) | 内网自签证书打不开时（`ERR_CERT_AUTHORITY_INVALID`）开本地 HTTP 通道；备用 |

**常用取证动作**：

```bash
node tools/cdp-capture.js list                              # 列出可取证页面
node tools/cdp-capture.js probe  "<URL或标题关键字>"          # 关键读数（表头/量级/行高/卡片/Tab）
node tools/cdp-capture.js shot   "<关键字>" /tmp/x.png        # 整页截图（素材存仓库外）
node tools/cdp-capture.js eval   "<关键字>" "<JS表达式>"      # 页面上下文求值（取 Token / DOM）
node tools/cdp-capture.js nav    "<关键字>" "<一级模块>" "<二级页>"   # 按左侧菜单进入（ix-menu）
```

> 📌 **SASE 侧栏不用 `<a>`、三级菜单（如 XDR 系统日志）不适用 `nav`**：改用 `eval` 按文本定位菜单项并 `.click()`（见 D-08 / D-09 取证记录）。
