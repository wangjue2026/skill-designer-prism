## 一、决策场景清单（母尺）

> **本清单定位**：这是从「操作组织」这一交互矛盾自顶向下推导出的**前置客观思考母尺**，不依赖任何特定产品的已有实现。面对任何需求，均以本表决策场景与分析维度为统一准绳逐条读数。

| 决策场景 | 分析维度 | 候选答案空间 |
| :--- | :--- | :--- |
| ① 单对象 / 单行的**操作入口该挂在哪个位置**？ | 操作项数量、使用频次、是否主操作、行高 / 列宽约束 | 行内操作列 / 顶部工具栏 / 选中后浮出的批量栏 / 收纳进「更多」/ 右键菜单 |
| ② **批量操作该怎样组织与触发**？ | 批量规模、对象可执行性差异、是否需跨页选择、操作风险 | 行内勾选 + 顶部批量栏 / 列表级「选择模式」/ 筛选结果全选 / 逐条操作替代批量 |
| ③ **导入 / 导出等文件类操作**该用什么壳与流程？ | 文件体量、是否需字段映射、是否需逐行校验反馈、使用频次 | 弹窗（小文件简配）/ 抽屉（含字段映射）/ 独立页（大文件 + 逐行校验）/ 后台任务 + 通知 |
| ④ 耗时操作该**即时执行还是转后台**？ | 耗时量级、是否阻塞主流程、是否需通知、是否可中断 | 同步即时执行 + 结果反馈 / 后台运行 + 入口提醒 / 通知中心回看 |
| ⑤ **批量修改同一字段**该用什么形态？ | 涉及对象数、字段类型、是否需逐行差异、误改风险 | 批量弹窗改同值 / 表格内批量编辑 / 逐行编辑 |
| ⑥ **"全选"该作用于当前页还是全部筛选结果**？ | 量级、是否需全量操作、误操作风险 | 仅当前页 / 全部筛选结果 / 全量需二次确认 |
| ⑦ 该不该提供**键盘快捷键 / 行内快捷图标**？ | 操作频次、专业用户占比、可发现性 | 无 / 行内快捷图标 / 快捷键 |
| ⑧ 新建对象该不该支持**复制 / 克隆已有**？入口放哪？ | 对象字段复杂度、复用频次、来源是否可公开 | 无 / 行内「复制」入口 / 详情内「复制新建」 |

* **共用 Why**：
  * **【为什么策略类给行内 Copy】** 策略对象字段多、组间差异小，从已有策略"复制再微调"远快于空白新建；放在行内与 `编辑 / 删除` 同级，复制源一目了然。
  * **【为什么任务类用"模板"】** 检测任务的复用源是一套预设模板（跨任务共享），故把复用入口上提为顶部「模板管理」，而非复制某一条任务。
