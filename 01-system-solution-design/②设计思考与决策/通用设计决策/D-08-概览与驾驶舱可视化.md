## 一、决策场景清单（母尺）

> ⚠️ 本域为**新建决策域**，场景清单已校；判据尚未经多产线盲扫，待补齐。

| 决策场景 | 分析维度 | 候选答案空间 |
| :--- | :--- | :--- |
| ① 概览该**独立成驾驶舱**（指标卡 + 图表页），还是**并入主列表顶部统计卡**？ | 指标数、图表数、是否需要多视角总览、使用频次 | 独立驾驶舱页 / 列表顶部统计卡 / 二者并存 |
| ② 驾驶舱的**指标与图表怎么分组**？ | 指标分组维度数、图表数、视角数 | 指标卡组 + 图表分区 / 多视角 Tab / 单页平铺 |
| ③ 概览与明细怎么**衔接**？ | 是否需下钻、下钻目标 | 点击卡片即下钻 / 概览只读 + 跳转入口 |
| ④ 驾驶舱的**时间维度**该用**全局统一时间筛选**还是**各卡片独立时间**？ | 跨卡片是否需时间对齐、图表数、数据时效 | 全局统一 / 卡片独立 / 全局默认 + 局部覆盖 |
| ⑤ 驾驶舱该按**几列栅格**排布、**首屏承载多少卡片**、主指标如何置顶？ | 视口宽度、卡片最小宽度需求、首屏信息优先级、卡片数 | 2/3/4 列栅格 / 指标卡置顶 + 图表分区 / 图表置顶 |
| ⑥ 驾驶舱内**卡片间是否联动**（一处筛选 / 点击，其余卡片联动响应）？ | 卡片数据关联度、是否需同屏对照、交互成本 | 全局联动（同源筛选）/ 局部联动（下钻明细）/ 不联动 |
| ⑦ 驾驶舱卡片该**固定排布**还是**允许用户自定义**（显隐 / 排序 / 拖拽）？ | 角色差异、指标稳定性、是否多人共用、指标数 | 固定 / 角色预设模板 / 用户自定义 |
| ⑧ 概览面向**"全局态势"**还是**"我的待办 / 我的任务"**？是否同页承载？ | 受众角色（管理者 / 操作者）、是否需行动项、个性化诉求 | 全局态势页 / 个人工作台页 / 同页分区（态势 + 待办） |
| ⑨ 列表筛选变化时，**顶部概览卡是否联动刷新**？ | 概览与列表是否同源、概览语义（整体态势 vs 当前结果） | 联动刷新 / 概览只统计全量不联动 / 提供切换 |
| ⑩ 驾驶舱 / 概览的**数据刷新**该自动定时刷新还是手动刷新、如何表达新鲜度？ | 数据时效要求、刷新成本、是否影响决策 | 自动定时刷新 + 时间戳 / 手动刷新 / 静默刷新 + 变更提示 |
| ⑪ 概览中**异常 / 超阈值指标**该如何被突出？ | 阈值告警需求、指标数、是否需第一时间察觉 | 常态展示 / 异常高亮 + 置顶 / 独立告警区 |
| ⑫ **指标卡该带对比基准吗**（单值 / 环比 / 目标进度 / 迷你趋势）？ | 指标性质、是否有历史或目标、误解成本 | 单值 / 单值 + 环比同比 / 单值 + 目标进度 / 迷你趋势 |
| ⑬ 概览要不要**全屏 / 大屏值守模式**？ | 使用场景（值守大屏 / 桌面）、指标数 | 常规页 / 全屏模式 / 大屏适配 |
