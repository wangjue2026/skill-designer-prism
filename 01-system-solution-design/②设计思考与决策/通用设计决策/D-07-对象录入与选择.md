## 一、决策场景清单（母尺）

> **本清单定位**：这是从「对象录入与选择」这一交互矛盾自顶向下推导出的**前置客观思考母尺**，不依赖任何特定产品的已有实现。面对任何需求，均以本表决策场景与分析维度为统一准绳逐条读数。

| 决策场景 | 分析维度 | 候选答案空间 |
| :--- | :--- | :--- |
| ① **字段控件**该如何选型（输入框、下拉、单选 / 多选、日期选择器）？ | 字段类型、候选值数量、是否可多选 | 输入框 / 下拉 / 单选多选 / 日期选择器 / 时间范围（起止 + 快捷项） |
| ② **对象选取**该用穿梭框、多选列表、树选择器还是弹窗列表页？ | 对象量级、是否需多维筛选、是否多选 | 穿梭框 / 多选列表 / 树选择器 / 弹窗列表页 |
| ③ **海量对象**如何按量级与是否需要多维筛选切换选择器？ | 量级、筛选维度数、是否需搜索 | 简单下拉 / 弹窗列表页 / 带筛选的选择器 |
| ④ **多类型对象混选**如何分组承载？ | 类型数、是否需跨类型同选 | 分组展示 / 分步选择 |
| ⑤ **字段校验**该在何时触发（实时 / 失焦 / 提交时）？ | 字段类型、错误代价、表单长度 | 实时 / 失焦 / 提交时 / 首次提交后转实时 |
| ⑥ **条件 / 规则类组合输入**（且 / 或 + 多条件）该用什么交互形态？ | 条件层级深度、条件数、是否需嵌套分组 | 单行条件组 + 逻辑切换 / 条件构建器（可嵌套）/ 表单分步 |
| ⑦ **多值字段**（多个 IP / 域名 / 端口）该用什么录入形态？ | 值数量、是否需校验与去重、单值长度 | 标签输入 / 逐行文本域 / 逐条添加 + 批量粘贴 |
| ⑧ 字段间存在**联动依赖**时，切换上游字段后下游该重置还是保留？ | 依赖强度、下游是否已填、重置代价 | 清空下游 / 保留兼容值 / 提示确认 |
| ⑨ **数值 / 区间类字段**该用什么控件？ | 数值范围、精度、是否需快速调整、是否成对 | 数字输入 / 步进器 / 滑块 / 带单位的组合输入 / 起止区间 |
| ⑩ **结构化表达式**（正则 / SPL / JSON）该用什么编辑器？ | 表达式复杂度、是否需即时校验、用户专业度 | 普通文本域 / 带校验的文本域 / 代码编辑器（高亮 + 补全） |
| ⑪ **子对象集合**（可动态增删的行 / 卡片）该用什么录入形态？ | 子项数量、字段数、是否动态增删 | 行内可增删表格 / 卡片列表增删 / 弹窗逐条添加 |
| ⑫ **字段该常驻显示还是随条件显隐**？ | 依赖字段、显隐规则复杂度、是否造成布局跳动 | 常驻显示 / 条件显隐 / 置灰不可用 |

### 案例 A：XDR - 资产中心（仅作对照样本，正文不在此展开）

> 📌 **一句话画像**：按对象结构分派选择控件——层级用树、平面多值用标签选择器、逐级归属用级联。

#### A. 决策场景与判据取值
* **涉及决策场景**：D-07 ②
* **分析维度实测取值**：层级对象 2 类（资产组 / 所属业务）｜ 平面多值字段 3 项 ｜ 位置为上下逐级
* **该方案的取舍结论**：树选择器 / 多选标签选择器 / 级联选择器分派

#### B. 做法与物理规格（可复现）
* **承载形态**：`Tree Selector`（只读输入 + 下拉树）、多选标签选择器（`Selector` multiple）、`Cascader`
* **组件与 Token 硬指标**：`ix-selector-input-inner` / `ix-input-inner` 高 `22px`

#### C. Why 因果推演（紧扣判据问句）
* **【对象结构决定控件】为什么不全用下拉**：层级与逐级对象用平铺下拉难定位，按结构选树 / 级联更"选得准"。

* **蒸馏日期 / 覆盖局限**：2026-09-28 ｜ 单产线（XDR）；量级切换阈值未取
