## 一、决策场景清单（母尺）

> 📐 决策场景按**六段分组**（组名见每条前缀）：【触发选型】/【嵌入方式】/【联动】/【退化】/【表达克制】。

| ⑩【表达克制】件的**异常 / 超阈值怎么突出**？ | 阈值告警需求、指标数、是否需第一时间察觉 | 常态展示 / 异常高亮 + 置顶 / 独立告警区（**与 D-04 交界**） |
| ⑪【表达克制】件的**视觉权重克制到什么程度**（相对主内容）？ | 业务严肃度、件是否辅助主内容、主内容是否为主任务 | 弱于主内容（降噪）/ 与主内容同级 / 允许强视觉（风险红） |

**取用三步**

1. `node tools/viz-ref.js VIZ-xx-<形态>` → 输出「填空清单 + 本件命中的 CSS + DOM」（只抽本件规则，不会把同族兄弟件的样式带进来）。

3. 落进说明书线框 → 写《可视化件声明》→ 跑 `node tools/viz-audit.js <说明书>` 对账。

**三条红线**

- **不许整页照搬**：`body` 外距、演示用容器、别的件型的 CSS 都不许带进说明书。
- **不许残留示例**：新页面出现"在线用户 / 在线终端 / PC-DEV-001 / 研发一部"即判没还原。
- **不许改尺寸凑版面**：放不下就换形态键或加宽容器，不压缩 44 / 40 / 36 这类元素尺寸；容器一律自适应。

**图标**：按新对象语义重画——形状变，尺寸 / 线宽 / 底色 / 状态色不变；状态类图标（对勾圆 / 三角感叹 / 叉圆 / 空心圆 / 虚线圆）是状态编码本身，不换。

**样板的边界（先说清，别指望它替你做）**

| 样板覆盖 | 样板不覆盖（按经验项另行实现） |
| :--- | :--- |
| 常态视觉：结构 / 几何 / 配色 / 状态编码 | **交互**：收起（EP-04）、随筛选联动（EP-05）、改配置实时刷新（EP-06）——样板是静态页，行为要自己接 |
| 组件内布局与自适应（auto-fit / 横向滚 / 不写死尺寸） | **嵌入档位**（EP-03）：列表顶通栏 / 表单右栏 / 详情内嵌卡——样板是孤立件，不含页面壳与栅格 |
| 单个状态（正常 / 异常）的静态呈现 | **退化态**（母尺 ⑦）：空 / 加载 / 无权限 / 窄屏折叠，样板未逐一示范 |

* **共用 Why**：
  * **【为什么要按七类场景判"要不要图"】** 只问"要不要可视化"没有抓手，答案会退化成个人偏好；换成"这块内容替读者回答什么"（总结 / 指引 / 解释 / 流转 / 归整 / 联动 / 装饰），需求方与设计师能在同一句话上对齐；且每类天然对应一类件型，判完触发即落到 ②.1，不会出现"该配图的地方写了段文字""该用文字的地方硬画了张图"两极。
  * **【为什么图是位图】** 首轮「原理 / 图解」类图实测均为 `<img>` 位图素材，非 DOM 节点 + 连线 → 这类"业务定制的图"**画不出来、只能保留素材**；只有「指标卡 / 帮助卡 / 联动预览 / L2 研判拓扑」这类 DOM / 组件化件可参数化重绘。**拓扑按形态分档**：形态 A（原理型）走保留件，形态 B（研判型、数据驱动）可重绘——见 `VIZ-08` 样式卡。

  * **【为什么异常用图标不用独立告警区】** 概览卡职责是"一眼看出哪个指标异常"，语义色图标即命中，独立告警区会打断读数、冗余。
