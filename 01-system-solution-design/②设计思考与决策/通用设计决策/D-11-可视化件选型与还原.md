## 一、决策场景清单（母尺）

> 📐 决策场景按**六段分组**（组名见每条前缀）：【触发选型】/【嵌入方式】/【联动】/【退化】/【表达克制】。

| ⑧【退化】主内容**变窄 / 窄屏**时件怎么退化？ | 视口宽度、件与主内容的宽度优先级 | 收起 / 折叠 / 换位到主内容下方 / 缩为迷你态 |
| ⑨【表达克制】统计件里的**指标卡展示到哪一档**？ | 指标有无目标 / 构成 / 分布、误解成本 | 单值 / 单值 + 进度占比 / 单值 + 环形占比 / 单值 + 分档小字 |
| ⑩【表达克制】件的**异常 / 超阈值怎么突出**？ | 阈值告警需求、指标数、是否需第一时间察觉 | 常态展示 / 异常高亮 + 置顶 / 独立告警区（**与 D-04 交界**） |
| ⑪【表达克制】件的**视觉权重克制到什么程度**（相对主内容）？ | 业务严肃度、件是否辅助主内容、主内容是否为主任务 | 弱于主内容（降噪）/ 与主内容同级 / 允许强视觉（风险红） |

### 场景 ③⑥⑨⑩ → 关键样本（嵌入 / 联动 / 指标卡档位 / 异常突出）

| 场景 | 产线 | 模块 | 判据取值 | 实测样例 |
| :--- | :--- | :--- | :--- | :--- |
| ③ 嵌在哪 / 占多大 | SASE | 应用管理 | 列表台账 → 列表顶通栏（项 `≈72px`） | 概览条贴列表顶部、横向铺满 |
| ③ | aTrust | 虚拟IP设置 / 扩展能力对接 | 配置表单 → 左配置右图解 | 图 `868×416` / `373×378` 随内容取宽 |
| ⑥ 配置项与图解联动 | aTrust | 升级配置 / 扩展能力对接 | 单向解释（图随配置项整体切换） | 改连接类型 → 整张图换，不做点图定位字段 |
| ⑥ | aTrust | 门户设置 | 实时预览（改配置即刷新图） | 左侧改 → 右侧预览 ≈`499×586` 实时变 |
| ⑨ 指标卡档位 | SASE | 应用 / 部署统计 / 数据外发分析 | 扁平 / 分组 / 分析型三档 | 见场景 ② 件型表 |
| ⑩ 异常突出 | SASE | 部署统计 | 异常指标用语义色图标 + 数值突出 | 「未安装用户 253」红色告警图标 |

* **共用 Why**：
  * **【为什么要按七类场景判"要不要图"】** 只问"要不要可视化"没有抓手，答案会退化成个人偏好；换成"这块内容替读者回答什么"（总结 / 指引 / 解释 / 流转 / 归整 / 联动 / 装饰），需求方与设计师能在同一句话上对齐；且每类天然对应一类件型，判完触发即落到 ②.1，不会出现"该配图的地方写了段文字""该用文字的地方硬画了张图"两极。
  * **【为什么图是位图】** 首轮「原理 / 图解」类图实测均为 `<img>` 位图素材，非 DOM 节点 + 连线 → 这类"业务定制的图"**画不出来、只能保留素材**；只有「指标卡 / 帮助卡 / 联动预览 / L2 研判拓扑」这类 DOM / 组件化件可参数化重绘。**拓扑按形态分档**：形态 A（原理型）走保留件，形态 B（研判型、数据驱动）可重绘——见 `VIZ-08` 样式卡。
  * **【为什么左配置右图解】** 配置项与"它影响的图"同屏对照，改配置立刻能在旁边看到范围 / 拓扑变化（单向解释），比"配置在上图在下"少一次滚动。
  * **【为什么异常用图标不用独立告警区】** 概览卡职责是"一眼看出哪个指标异常"，语义色图标即命中，独立告警区会打断读数、冗余。
* **蒸馏日期 / 覆盖局限**：2026-10-13 ｜ 仅 SASE / aTrust；**XDR 待补**（掉线）；② 顶部对象信息卡、⑦ 状态流程条无样本（EQ-01）。
