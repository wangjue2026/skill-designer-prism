## 一、决策场景清单（母尺）

> **本清单定位**：这是从「操作确认与防错」这一交互矛盾自顶向下推导出的**前置客观思考母尺**，不依赖任何特定产品的已有实现。面对任何需求，均以本表决策场景与分析维度为统一准绳逐条读数。

| 决策场景 | 分析维度 | 候选答案空间 |
| :--- | :--- | :--- |
| ① **删除 / 下线**等破坏性操作要不要二次确认？用气泡、阻断弹窗还是输入口令？ | 可逆性、影响面大小、操作频次、风险等级 | 直接执行 / 气泡确认 / 阻断弹窗 / 输入对象名或口令 |
| ② **无权限操作**该隐藏还是置灰并说明原因？ | 用户是否需感知能力存在、权限粒度 | 隐藏 / 置灰 + 原因 |
| ③ **批量操作**中不满足条件的对象如何跳过、如何告知？ | 对象可执行性差异、批量规模 | 整体禁用 / 允许勾选 + 执行时校验跳过 / 勾选即过滤 |
| ④ **变更类操作**是否先给影响面清单 / 配额试算再放行？ | 影响面可预知性、是否涉配额或越界 | 直接执行 / 影响面清单 / 配额试算拦截 |
| ⑤ **批量**破坏性操作（批量删除 / 禁用）要不要二次确认、确认到什么程度？ | 批量规模、可逆性、影响面 | 直接执行 / 弹窗回显数量 + 清单 / 输入口令 |
| ⑥ **编辑表单有未保存修改**时，离开 / 关闭该不该拦截？ | 是否有未保存改动、改动量、是否可自动存草稿 | 直接离开 / 弹窗提醒（保存 / 放弃 / 继续编辑）/ 自动草稿 |
| ⑦ **低频可逆操作**该用"事后撤销（Undo）"替代"事前确认"吗？ | 可逆性、操作频次、误操作成本、反馈延迟容忍 | 事前确认 / 事后撤销（提示 + Undo）/ 二者结合 |
| ⑧ **高风险操作**该用什么视觉编码、是否设"危险操作区"隔离？ | 风险等级、操作频次、是否常驻可见 | 普通按钮 / 危险色按钮 / 危险区隔离 |
| ⑨ **破坏性删除**要不要提供**回收站 / 软删除 / 快照恢复**兜底？ | 可逆性、数据重要性、是否可重建 | 直接硬删 / 软删除 + 回收站 / 快照恢复 |
| ⑩ **查看 / 导出敏感数据**前该不该二次身份校验？ | 数据敏感度、合规要求、操作频次 | 直接查看 / 二次认证（密码 / MFA）/ 申请审批 |
| ⑪ **策略 / 配置变更**该直接生效，还是试运行 / 定时生效 / 灰度？ | 变更风险、是否影响线上流量、可否回滚 | 直接生效 / 先试运行（dry-run）/ 定时生效 / 灰度放量 |
