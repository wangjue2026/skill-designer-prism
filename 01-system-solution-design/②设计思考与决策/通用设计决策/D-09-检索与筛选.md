## 一、决策场景清单（母尺）

> **本清单定位**：这是从「检索与筛选」这一交互矛盾自顶向下推导出的**前置客观思考母尺**，不依赖任何特定产品的已有实现。面对任何需求，均以本表决策场景与分析维度为统一准绳逐条读数。
> ⚠️ 本域为**新建决策域**，场景清单已校；判据尚未经多产线盲扫，待补齐。

| 决策场景 | 分析维度 | 候选答案空间 |
| :--- | :--- | :--- |
| ① **检索 / 筛选的入口**该常驻在列表页里，还是单独开一个检索页？ | 查找诉求（模糊 / 精确）、可筛字段数、是否需常驻可见、是否跨模块 | 列表页常驻入口（顶部搜索框 / 可展开的筛选入口）/ 独立检索页 / 二者并存 |
| ② 多条件筛选该用**哪个壳承载**？ | 条件数量、条件组合复杂度、是否需与结果同屏、屏幕空间 | 常驻行内筛选条 / 可展开高级筛选面板 / 抽屉 / 弹窗 / 独立检索页 |
| ③ 筛选该**什么时候触发**？ | 查询成本、条件数量、数据量级、是否需条件组合完再查 | 输入即时筛选 / 点「查询」统一提交 / 键入防抖 + 回车提交 |
| ④ 筛选条件该不该**保存为视图 / 方案**并可复用 / 共享？ | 条件组合稳定性、复用频次、是否需跨用户共享、角色差异 | 不保存（每次重设）/ 个人保存 / 角色预设 + 共享 |
| ⑤ **高级检索能力**（SPL / 自然语言 / 结构化条件）该以什么方式暴露？ | 用户专业度、查询复杂度、是否需自由组合、学习成本 | 仅表单化条件 / 高级语法开关 / 独立检索页（表达式为主） |
| ⑥ 列表的**视图 Tab 与筛选条**该怎样分层组织？ | 子集维度数、筛选条件数、是否需叠加 | Tab 切大类子集 + 筛选条细筛 / Tab 即筛选结果 / 合并为筛选条件 |
| ⑦ 已生效的筛选条件该**如何回显与清空**？ | 条件数量、是否需回顾已选、清空频次 | 条件标签回显 + 一键清空 / 面包屑 / 仅控件内隐含 |
| ⑧ **排序**该用什么方式？ | 是否需多列排序、默认序是否需确定性、量级 | 列头单列排序 / 多列排序 / 独立排序面板 / 固定默认序 |
| ⑨ 检索 / 筛选该**作用于什么范围**？ | 适用范围（全局 / 模块 / 当前子集）、是否有层级、结果内能否再筛 | 全局检索 / 模块内检索 / 当前子集内筛 / 结果内再筛 |
| ⑩ **关键字检索**该匹配哪些字段、命中如何高亮？ | 可搜字段数量、是否需精确匹配、结果量、命中定位诉求 | 仅主标识字段 / 多字段模糊匹配 / 多字段 + 命中高亮与范围说明 |
| ⑪ 该不该提供**搜索历史 / 最近查询 / 常用筛选**？ | 复用频次、角色稳定性、是否需要团队共享 | 无 / 本地历史 / 团队共享常用筛选 |
