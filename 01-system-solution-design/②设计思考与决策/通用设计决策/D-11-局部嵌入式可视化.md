### 场景 ③⑥⑨⑩ → 关键样本（嵌入 / 联动 / 指标卡档位 / 异常突出）

| 场景 | 产线 | 模块 | 判据取值 | 实测样例 |
| :--- | :--- | :--- | :--- | :--- |
| ③ 嵌在哪 / 占多大 | SASE | 应用管理 | 列表台账 → 列表顶通栏（项 `≈72px`） | 概览条贴列表顶部、横向铺满 |
| ③ | aTrust | 虚拟IP设置 / 扩展能力对接 | 配置表单 → 左配置右图解 | 图 `868×416` / `373×378` 随内容取宽 |
| ⑥ 配置项与图解联动 | aTrust | 升级配置 / 扩展能力对接 | 单向解释（图随配置项整体切换） | 改连接类型 → 整张图换，不做点图定位字段 |
| ⑥ | aTrust | 门户设置 | 实时预览（改配置即刷新图） | 左侧改 → 右侧预览 ≈`499×586` 实时变 |
| ⑨ 指标卡档位 | SASE | 应用 / 部署统计 / 数据外发分析 | 扁平 / 分组 / 分析型三档 | 见场景 ② 件型表 |
| ⑩ 异常突出 | SASE | 部署统计 | 异常指标用语义色图标 + 数值突出 | 「未安装用户 253」红色告警图标 |

* **共用 Why**：
  * **【为什么图是位图】** 首轮全部「原理 / 拓扑 / 图解」类图实测均为 `<img>` 位图素材，非 DOM 节点 + 连线 → 意味着这类"业务定制的链路 / 拓扑图"**画不出来、只能保留素材**；只有「指标卡 / 帮助卡 / 联动预览」这类 DOM / 组件化件可参数化重绘。
  * **【为什么左配置右图解】** 配置项与"它影响的图"同屏对照，改配置立刻能在旁边看到范围 / 拓扑变化（单向解释），比"配置在上图在下"少一次滚动。
  * **【为什么异常用图标不用独立告警区】** 概览卡职责是"一眼看出哪个指标异常"，语义色图标即命中，独立告警区会打断读数、冗余。
* **蒸馏日期 / 覆盖局限**：2026-10-13 ｜ 仅 SASE / aTrust；**XDR 待补**（掉线）；② 顶部对象信息卡、⑦ 状态流程条无样本（EQ-01）。

> 2. **风格参数**：线宽 / 圆角 / 填充描边 / 配色 / 图标风格（对齐 [`03-design-assets/visual-styles/README.md`](../../../03-design-assets/visual-styles/README.md)）；

> 另附**件型级图标清单**（语义 → idux 图标名；查无则标"需按风格绘制"，对齐 [`03-design-assets/components/icon-map.md`](../../../03-design-assets/components/icon-map.md)）。
>
> **② 第二交付物 · 件型风格规范（同批产出）**：同一次取证的风格读数（配色 / 图标风格 / 图形语言 / Token 映射）写入 [`03-design-assets/visual-styles/README.md`](../../../03-design-assets/visual-styles/README.md)——即"**一次蒸馏，两份产出**"（经验 + 风格规范）。多产线风格不一致时，收敛为统一基线或分叉为风格档，**默认档由规划人员指定**。
>
