# 4.2 业务能力 ➔ 真实 idux 组件与设计经验映射指引 (Components & Experience Mapping)

> 💡 **定位**：方案系统设计主线步骤 3 的关键落地环节。
> 严禁虚构或口语化组件名称！组件名称按「**两轨制**」落地：将各页面的业务能力项 / 蒸馏组件名，对照 [`03-design-assets/components/idux-component-map.md`](../../03-design-assets/components/idux-component-map.md) 映射为真实的前端 idux 组件名（**能映射的，最终以 idux 组件落地**）；**凡在映射表中查无对应项的，如实保留该蒸馏的真实组件名，严禁为凑映射而杜撰或改写成不存在的名称**。同时将组件与步骤 2 沉淀的标杆设计经验（`EP-xx`）逐项锚定。

## 一、能力族裁决表（先判族，再选组件）

> 🛑 **先回答"什么时候该用这种形态"，再回答"对应哪个组件"。** 族选错了，组件选得再对也是错的形——把研判台做成台账，用 `IxTable` 用得再标准，也不是研判台。

| 能力族 | 什么条件下选它 | 什么条件下不许选 | 硬指标与出处 |
| :--- | :--- | :--- | :--- |
| **F1 台账 / 列表** | 对象同构、字段固定、要横向对比同一批对象的同一组字段 | 对象类型混杂或字段不对称（如任务卡：左侧 3 行标签值 + 右侧 4 组指标）；对象 ≤10 条且以"逐条看内容"为主 | 表头 32px、行高 40px、数字列右对齐、操作列冻结（`patterns/02-table-patterns.md`） |
| **F2 检索与筛选** | 条件 ≥3，或需要组合条件反复用 | 条件 ≤2 时只许常驻筛选条，不许上复合搜索框；不许用筛选条替代"默认视图" | 32px 高；筛选条 ≤4 条平铺；>4 或一行放不下才换 `IxProSearch`（D-09 ②） |
| **F3 表单与配置录入** | 改动小、要保留列表上下文 → 抽屉；步骤多、需前后对照 → 独立页；≤6 字段的轻改 → 弹窗 | 抽屉里再套抽屉；把 20 字段的大表单塞进 640 抽屉；用弹窗承载需要对照数据的配置 | 抽屉 480 / 640 / 800；页脚主按钮在左；Label 左、控件右（`components/design-form.md`） |
| **F4 批量动作与导入导出** | 动作可枚举、要逐条回执；批量前需要预览影响 | 不可逆动作走批量却无预览；批量中途失败无法定位到具体行 | 失败清单可导出；执行前给影响面台数（EP-02 / EP-04） |
| **F5 状态与进度** | 长耗时、异步下发、需要知道"到底成了多少" | 用转圈代替进度；用"成功 / 失败"两态盖住部分成功；进度条没有分档 | 三态（达标 / 违规 / 跳过）+ 计数 + 失败原因（EP-04） |
| **F6 详情与排障** | 需要证据链、因果链，或要从列表就地看细节 | 把详情做成字段堆叠（只是把表格竖过来）；跳页后丢失筛选与位置 | 抽屉 640 / 800；就地展开保留列表上下文（EP-07） |
| **F7 概览与可视化** | 需要看**趋势 / 关系 / 分布**——三类之外不上图 | 3 个数字也要占一整块图；没有对比基线的折线；用图代替一句结论 | 卡组间距 8px、单值优先；件型走 §二 / D-11 |
| **F8 策略与周期配置** | 有依赖、冲突、影响面，配错代价大 | 无影响面预判直接下发；用一段说明文字代替冲突提示 | 配额实时试算与超限拦截（EP-02）；周期表达式 + 下次执行时间 |

## 三、映射原则与装配规范

1. **真实性第一**：绝对不允许输出“居中框”、“小气泡”、“小药丸”等口语化组件名，必须输出标准 `Ix...` 组件名；
2. **分页面绑定**：在注入设计说明书第四章时，必须按页面（Page-01, Page-02...）分别列出该页面所使用的 idux 组件和所融合的 EP 设计经验，严禁笼统堆成一张全局扁平大表；
3. **来源必须注明**：组件映射清单中的「来源」列必须注明是 `标杆复用 EP-xx`、`模板还原`、`业务独立推导` 还是 `可视化件复用 D11-件型`。
4. **可视化件不冒名**：由 D-11 承载的定制可视化件（顶部统计概览 / 顶部对象信息卡 / 功能原理示意图 / 顶部帮助指引卡 / 配置逻辑图解 / 配置联动展示件 / 状态流程条），**不借 idux 组件名冒名顶替**；在映射表里按「件型」列，并在说明书第四章另出《可视化件声明》（含图形编码规则 / 风格引用 / 可替代性）。
