## 二、四维无损升维铁律（Part2 → Part3 绝不打折）

### 维 1 · 内容与结构 100% 无损承接（目标 ①）
1. **源码全量解析**：直接读取 `design-spec-<业务名>.html` 源码——严禁按截图或可见文本解析，**必须全量读完 `<details class="sec-fold">` 与 `tr.rows-extra` 折叠行**、第 5.1 节页面清单、第 7 节全部 `<h5 id="page-0x">` 页面、全部 `[data-wf-pane]` 子 Tab 与尾部六节编码契约（`SP-D`）；
2. **产线导航壳装配**：若说明书顶部标明了产线（SASE / aTrust / XDR / aES），直接复用 `03-design-assets/product-lines-knowledge/` 对应真实左侧导航壳并高亮当前所属菜单；无明确产线归属时使用标准轻量顶栏 + 面包屑；
3. **页面与子 Tab 零遗漏（防缩水铁律）**：
   - 每个 `Page-0x` 在 Demo 中必须标注 `data-demo-page="Page-0x"`（独立页/抽屉/弹窗各自按真实交互形态承载）；
   - 每个页内子 Tab 必须标注 `data-demo-tab="<Tab名>"` 与对应内容面板，**面板内的列数、数据行数、多模态卡片、高亮证据与 Tab 标题括号计数 100% 账实相符**，严禁把非默认 Tab 做成“暂无更多数据”空壳或缩水凑数；
4. **可视化双轨还原**：
   - **在册件型（`VIZ-*` / `CHART-*`）**：先跑 `node tools/viz-ref.js <件型键>` 取样落地，严禁凭记忆手写或残留示例业务词；**注意**：`VIZ-01-A2` 等浅灰格底（`#F7F9FC`）的扁平统计条放在 `#F7F9FC` 灰底页面画布上时，**外层必须用白底容器（`#FFFFFF` + `1px solid #E1E5EB` + `padding: 12px 16px`）包裹**，避免与页面画布融成一片；
   - **规范外创新可视化（`data-viz="REF / 资产未覆盖"`）**：**100% 保骨直承 Part2 的 SVG/DOM 骨架与视觉层次**（绝不降级成文字卡片），并在此基础上注入真实点击高亮、悬浮提示与跨区块联动！

### 维 2 · 真实交互闭环与零死按钮（目标 ②）
1. **以说明书 `SP-D` 交互行为表为唯一行为依据**：逐行落实《交互逻辑与状态机》表中的每一条触发元素、联动目标、状态变化与边界反馈；
2. **单一内存状态源（`AppState`）**：所有筛选条件、分页、排序、未读计数、实体状态（如标记误报后状态变更）、当前选中抽屉/瀑布节点/子 Tab 均由统一 `AppState` 驱动——**一处变更，抽屉头部、列表行、顶部 KPI 数字实时同步**；
3. **六类必备真实交互闭环**：
   - ① **全局导航与多页切换**：主页面可切换，侧边栏其他演示外菜单点击给轻量 Toast 提示（非死链）；
   - ② **查询/筛选/排序/分页真过滤**：复合日期快捷项、下拉/ProSearch 添加与删除 Tag、点击搜索真实过滤表格、列头排序、分页切换、一键重置；筛选为 0 时真实展示 `IxEmpty` +「重置筛选」；
   - ③ **抽屉/弹窗完整生命周期**：点击列表行/操作按钮右侧滑入抽屉（保留列表筛选与滚动位）、支持右上角 `✕`/取消/遮罩/`ESC` 退出；弹窗含影响面预演、表单校验、提交 `300ms` Loading 锁与成功后 Toast；
   - ④ **页内子 Tab 与可视化真联动**：点击 Tab 切换保留主信息头部；点击桑基流带/瀑布条/拓扑节点高亮选中并联动过滤列表或切换原地证据/JSON（再次点击可取消）；
   - ⑤ **禁用与边界保护可感知**：禁用按钮 Hover 显示真实禁用原因 Tooltip；超长文本带 `title` 截断提示；
   - ⑥ **内置可折叠「演示态切换器」**：右下角固定默认收起的轻量胶囊（带 `data-demo-chrome="true"`），一键切换「正常态 / 空数据态 / 加载骨架态 / AI 降级异常态 / 权限受限态」并支持「重置演示数据」，让七态异常真正可点可验；
4. **零死按钮铁律**：禁止 `href="#"` 空锚点，界面上每一个可点击控件、行操作、图标按钮都必须有真实响应或明确反馈。

### 维 3 · 样式直承与克制动效（目标 ② + ③）
1. **直承 Part2 规范级 CSS 基底**：完整继承 `tokens-cheatsheet.md` 与 Part2 已对齐的组件硬指标（32px 控件/表头、40px 行高、12px 正文、14px 浮层页脚、2×12px 蓝竖条、428px 复合日期、四套状态三元组、无边框 Alert、表格防折护栏、禁红按钮），**补齐真实交互态（`:hover` / `:active` / `:focus-visible` / `:disabled`）**；
2. **全量落地 [`design-motion.md`](../../03-design-assets/global-styles/design-motion.md) 动效 Token**：
   - `--motion-dur-fast: 150ms` / `--motion-dur-base: 220ms` / `--motion-dur-slow: 280ms`；
   - `--motion-ease-out` / `--motion-ease-in` / `--motion-ease-std`；
   - 抽屉右侧滑入（`280ms`）、弹窗缩放淡入（`220ms`）、Tab 面板上浮淡入（`220ms`）、Toast 顶部滑入、列表行更新高亮回落、骨架屏微光 + `prefers-reduced-motion` 无障碍降级。
