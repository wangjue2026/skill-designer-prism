# 跨域创新原语卡（Part1 · 1.3 破题专用燃料）

> 💡 **定位**：专门解决网安 B 端设计中最容易平淡与固化的两类场景——**A 组：可视化价值与产品力类（AI 能力 / 全局可视 / 大屏）**、**B 组：研判分析 + 处置闭环类**。
> 🛑 **用法铁律（防模板化）**：每张卡只是**“可嫁接的思维杠杆”**，不是固定页面模板。在 1.3「范式跃迁前置步」时，**强制挑 2~3 张最契合当前任务本质的原语卡进行跨界嫁接**，且**方案一与方案二必须嫁接不同的原语组合**。

---

## A 组：可视化价值与产品力原语（专治 AI 能力 / 全局可视 / 大屏平淡）

| 编号 | 原语名称 | 跨界标杆来源 | 核心机制（破什么局） | 适配视觉文法（1 对 N） |
| :---: | :--- | :--- | :--- | :--- |
| **A1** | **黑盒白盒化机理透视** | AI Eval / 编译器可视化 | 不只报“AI 拦截了 12 次”，而是把**输入 → 检测引擎各层命中 → 决策依据 → 精准拦截**画成可透视的因果机理图，让客户一眼看懂产品技术含金量与购买价值 | 分层机理 SVG 图 / 三段式因果流 |
| **A2** | **反事实影响面对比沙盘** | 金融风控 / 仿真推演 | 同屏并置**“若未防护的波及半径（外泄 500 条 / 横向 12 台）” vs “已拦截后的 0 扩散”**，把看不见的“没出事”转化成极具冲击力的可感知价值 | 左右对比拓扑 / 半径衰减圆环 |
| **A3** | **全量价值流向桑基** | 能量/资金流分析 | 把“原始流量/会话 → 风险识别分类 → 自动拦截 / 脱敏放行 / 人工处置”画成**比例流带**，一眼看见 95% 风险被系统无感消解、仅 5% 惊动人工 | SVG 桑基流转图（`renderSankeySVG`） |
| **A4** | **语义缩放全局拓扑** | 地图引擎 / Datadog Map | 全局视角看宏观分区/业务域健康度与红线攻击路径，**点击/缩放原地展开**为节点级调用与风险参数，不跳页、不丢全局坐标 | 分层 SVG 拓扑（`renderLayeredTopoSVG`）+ 原地展开 |
| **A5** | **高管语言 ROI 归因故事** | BI 叙事报表 | 不堆 8 个孤立 KPI 卡片，而是用**“1 句核心价值结论 + 3 个归因微图（省了多少工时 / 挡了哪类高危 / 较上期变化）”**讲完一个可直接截图汇报的故事 | 顶部叙事条 + 迷你对比微图 |
| **A6** | **离群尖刺聚光灯** | APM 异常检测 | 全局 98% 正常态压成极浅静默灰底，只对**突变尖刺、首见异常实体、突破阈值红线**给高对比度聚光与上下文注释，一眼锁死真正值得看的东西 | 去色降噪时序轨 / 散点离群高亮 |
| **A7** | **覆盖率与盲区热力矩阵** | 攻防演练 ATT&CK 矩阵 | 按“业务域 × 能力项 / 部门 × AI 应用”铺成色阶矩阵，把**“已覆盖安全区 / 高危爆发区 / 监测盲区”**一次摊开，直击管理者最怕的“有没有漏网之鱼” | 多维热力覆盖矩阵（带缺口斜纹态） |

## B 组：新一代研判分析与处置原语（专治网安研判+处置固化老三样）

| 编号 | 原语名称 | 跨界标杆来源 | 核心机制（破什么局） | 适配视觉文法（1 对 N） |
| :---: | :--- | :--- | :--- | :--- |
| **B1** | **同源模式聚类工作台** | Sentry Issue Grouping | **把对象粒度从“单条告警”升维到“同源攻击手法/同一实体事件簇”**：100 条重复触发聚成 3 个模式簇，核验 1 条代表样本即可批量定性/标误报，工作量降一个量级 | 聚类卡片流 + 样本展开抽屉 |
| **B2** | **融合执行时间轴** | LangSmith / Chrome DevTools | **消灭“规则 / 对话 / 链路”三 Tab 割裂**：把多轮对话、规则命中点、外部工具调用耗时与拦截点全部对齐到**同一条因果时间轴**，顺着时间一眼看清前因后果 | 瀑布 Trace 轨（`renderWaterfallHTML`）+ 内联对话节点 |
| **B3** | **结论↔证据双向锚定对照** | IDE Debugger / 论文引用 | AI 研判结论里的每个判断词（如“越权查询生产表”）与原文敏感词、工具参数 JSON **双向悬停/点击发光联动**，做到“敢信、秒验、零记忆负担” | 双栏联动画布 / Inline Diff 高亮 |
| **B4** | **AI 置信度分层托管** | 自动驾驶接管模型 | 系统按置信度把待办切成三层：**高置信自动预归类/建议闭环（人一键批过）、中置信高亮疑点待人裁决、低置信标出证据缺口**，把人的注意力集中在真正难判的 20% | 三层分诊工作台 + 置信度刻度条 |
| **B5** | **流式清零分诊队列** | Linear Triage / Superhuman | 面向高频值守场景，提供**极简聚焦主视图 + 单键快捷处置（确认风险 / 标误报 / 跳过）+ 下一条预加载**，彻底消除“进列表 → 点开 → 关抽屉 → 找下一条”的机械往返 | 沉浸式单焦队列 + 底部微缩进度点 |
| **B6** | **处置前影响面预演** | Terraform Plan / 变更仿真 | 按下阻断、封禁或整条标误报前，就地预演**“本次动作覆盖哪几条规则 / 影响哪些用户与业务 / 可否一键撤销”**，用透明因果取代流于形式的二次确认弹窗 | 内联影响范围条 / 前后状态 Diff |
| **B7** | **活体案卷与零重做交接** | 医疗病历 / 协同白板 | 安全运营每点选核验一条证据，系统自动将其钉进右侧**“已核实证据袋”**；需跨角色拉 AI 应用负责人协查或复核留档时，一键生成带高亮锚点的结构化案卷，接手人零重跑 | 侧边证据收集轨 + 可分享案卷卡 |
