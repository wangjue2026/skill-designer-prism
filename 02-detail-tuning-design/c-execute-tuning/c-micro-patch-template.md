# 微观细节模板：局部调优与吐槽修复 Prompt 模板 (Micro Prompt Template)

> 💡 **微观模板定位**：
> 当规划人员针对已有 Demo 提出 **“太挤了”、“颜色土”、“搜索框笨重”、“表格操作列太乱”、“按钮太大”** 等细节吐槽时，织雨调用本模板合成双重交付成果：
> 1. **输出 A**：向规划人员通俗解释病因与改动细节；
> 2. **输出 B**：向 Coding AI 提供像素级、带八重安全带约束的精准补丁修改 Prompt。

---

## 📤 输出 A：面向规划人员的微观细节调优解释模板 (Planner Explanation)

```markdown
### 💡 织雨设计思考：[调优模块名称] 细节优化说明

1. **为什么这么改？（痛点病因）**
   - [指出原版问题，例如：控件高度撑大至 44px 导致视觉笨重、缺少 8px 网格留白导致找数据费劲、操作列杂色过多造成视线杂乱]。

2. **织雨做了哪些精细升级？**
   - 🌿 **空间与呼吸感**：[阐述收紧/放大 padding 与 gap 的具体效果]；
   - 🎨 **色彩与视线降噪**：[阐述换用中性灰底与柔和三元色，去除多余粗框线]；
   - 🔤 **排版与对齐**：[阐述数值启用 Outfit 等宽字体，数字列右对齐，操作列统一链接蓝]；
   - ⚡ **交互与微反馈**：[阐述添加 Hover 轻微阴影与 Focus 蓝光圈]。

3. **预期效果**：界面变得清爽通透，视线一秒锁定关键内容，符合专业 B 端设计审美。
```

---

## 💻 输出 B：面向 Coding AI 的局部调优执行 Prompt 模板 (Coding Prompt)

```markdown
### 🎯 任务目标：针对 [模块名称/组件名称] 进行局部高保真精细化调优

---

#### 🛠️ 一、 [修改子项 1：如搜索框 / 顶部工具栏]
1. **DOM 结构与尺寸收紧**：
   - 容器样式：`relative flex items-center w-60 (240px)`；
   - 输入框：`h-8 (32px) pl-8 pr-3 text-xs bg-[#F8FAFC] border border-[#CBD5E1] rounded-[2px]`；
   - 前置放大镜微图标：`absolute left-2.5 w-3.5 h-3.5 text-[#94A3B8]`；
   - 聚焦反馈：`focus:ring-2 focus:ring-[#1C6EFF]/20 focus:border-[#1C6EFF]`。

---

#### 🛠️ 二、 [修改子项 2：如表格 / 按钮 / 指标卡片] (参考 components/ 对应组件规范)
1. **组件硬性尺寸与样式约束**：
   - [若为按钮]：双字按钮固定 `w-14 (56px) h-8 text-xs rounded-[2px]`，主按钮 `bg-[#1C6EFF] hover:bg-[#4FA1FF]`，清除径向扩散阴影；
   - [若为表格]：表头高度固定 `32px bg-[#EDF1F7]`，内容区行高固定 `40px`，数字列严格右对齐 `text-right font-mono tabular-nums`，操作列统一链接蓝 `text-[#1C6EFF] hover:underline`；列数超宽必须配置左右双向粘性冻结与微阴影；
   - [若为指标卡]：移除外层多余包裹大边框，主数值升级为 `text-2xl font-bold font-outfit text-[#1E293B]`，数字与单位留半角空格。

---

#### 🛠️ 三、 状态色与视觉三元组注入
* 状态徽标与标签统一遵循柔和三元组：
  - 正常/良好：`bg-[#F6FFED] text-[#12A679] border border-[#B7EB8F]`；
  - 警告/中危：`bg-[#FFFBE6] text-[#FA8C16] border border-[#FFE58F]`；
  - 异常/高危：`bg-[#FFF1F0] text-[#D9363E] border border-[#FFA39E]`。

---

#### 🚫 四、 防破坏与连带约束 (Regression Guard - 强制从 b.3 选取注入)
1. **结构安全**：仅修改当前目标容器内部样式，严禁影响外层 Shell 与父容器 Flex/Grid 响应式流；
2. **数据安全**：保持既有字段绑定与事件逻辑（如 `@click`、`v-model`）完整，严禁篡改业务逻辑；
3. **容错保障**：动态文本全部添加 `truncate` 并附带 Tooltip，数字格式化必须支持千分位（如 `1,280`）；
4. **层级与遮罩**：弹窗与抽屉必须配置 `z-50` 遮罩层与防滚动锁定，避免事件穿透；
5. **规范复用**：禁止为同类语义对象（弹窗、分页器）手写临时样式，强制复用平台标准组件；
6. **外跳感知**：新开 Tab 或跳出跨系统的操作文字后强制渲染 `↗` 标识；
7. **禁用反馈**：所有 disabled 控件与单图标必须配置 hover 解释性 Tooltip；
8. **高危防线**：不可逆删除/注销必须配置红色阻断 Modal + 受影响资产清单 + 强制键入口令校验。
```
