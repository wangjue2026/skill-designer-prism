一、需求洞察与体验目标

1. 目标用户角色与本质任务 (JTBD)

  • 企业安全运维管理员 (SecOps - 最高频主战角色)：
    • 使用情境与心智：求稳、防背锅、怕误杀、怕盲盒；日常负责全公司 2,000~50,000 台混合办公 PC 的安全基线管控，最怕规则配错导致全员报障，最怕巡检耗时数小时不知道卡在何处。
    • 核心用户本质任务 (JTBD)：“我需要能按部门或标签一键装配规则并下发巡检，在 3 秒内看清执行健康度与离线跳过状态，并能在不跳页的情况下定位违规根因并完成批量处置。”
  • 企业安全合规负责人 (CISO / 审计员)：
    • 核心用户本质任务 (JTBD)：“我需要宏观掌握企业整体合规率趋势，能一键导出满足《等保 2.0》规范的合规证明报告，确保高危终端均已进入受控闭环。”

3. 务实体验目标（A ➔ B 对比跨越与量化度量）

  • 体验目标 1（配置效率与确定性 · 翻转 🚩 S1-P1）： 通过提供【必装+黑名单】预置规则勾选库与部门树即时测算 ➔ 用户由手工拼写参数变为 3 步勾选 ➔ 彻底解决配置易错与盲盒心理 ➔ 任务装配耗时从 30 分钟 ➔ ≤ 30 秒，覆盖终端大数秒级透明可见。
  • 体验目标 2（巡检监控确定性 · 翻转 🚩 S2-P2）： 通过三态机进度控制（达标/违规/跳过）与 10min 超时自动熔断 ➔ 用户随时掌握执行健康度 ➔ 消除长时间未知等待的焦虑 ➔ 巡检进度从“黑盒死信挂起” ➔ “三态进度秒级可见，离线超时 100% 自动跳过”。
  • 体验目标 3（排障闭环与联动阻断 · 翻转 🚩 S3-P3 / S4-P4）： 通过 In-situ 原地抽屉体检单与 SASE 零信任动态降权联动 ➔ 用户在当前页直接定界违规项并一键发起阻断 ➔ 消除跳页断流与线下催办脱节 ➔ 排障跳页 6 次 ➔ 0 跳页原地闭环，高危终端处置响应从天级 ➔ 秒级联动阻断。

二、设计思考、发力点与标杆经验选型

1. 业务属性与严肃程度定性 (定“度”，不定“向”)

  • 业务属性与严肃度：企业安全管控与合规巡检 / 极高严肃度 (Mission-Critical)。高危阻断直接影响员工能否正常接入公司网络，交互必须极度克制、理性且具备严密防呆。
  • 色彩基调与视觉风格：深沉克制 / 石墨冷灰底色 (`#F7F9FC`)，全面去框线化，仅高危违规状态启用柔和珊瑚红（`#FEF2F2` 浅底 + `#D9363E` 深字三元组），确保操作专注且无色彩噪音。

  • 核心业务矛盾穿透：本次合规检测的核心矛盾是“海量终端覆盖的广度”与“管理员单机排障定界的深度”之间的断层，以及“安全强管控”与“员工正常办公低打扰”之间的冲突。

3. 选定专家范式与系统机制 (L2 承载机制)

  • 专家范式选型：P-07 全生命周期巡检与合规 + P-05 多维下钻联动排障
  • 元设计机制：
    • 实时目标预估测算状态机（动态监听部门树勾选，即时拉取后端资产大数）；
    • 任务三态机流转机制（进行中、合规达标、违规检出、离线跳过）；
    • In-situ 原地抽屉双轴排障单元（左侧必装核对 + 右侧违规进程证据链）；
    • 零信任策略动态隔离联动通道（调用安全网关 API 将终端置入隔离安全组）。

六、页面体验与异常保护规则

  • 🛑 长耗时心跳防死信 (EP-04 机制延伸)： 针对离线或弱网终端超过 10 分钟未回传心跳，任务状态机自动将其归类为 离线跳过 (OFFLINE_SKIPPED)，并记录在案，严禁因单机离线阻塞全局巡检进度。
  • 🛑 In-situ 上下文视线锚定： 抽屉关闭或隔离完成后，底层主表格自动高亮保留在原先选中的终端行，绝不重置滚动条位置、不重置分页码、不重置已选筛选条件。
  • 🛑 高危操作二次防呆防线： 对【联动零信任动态隔离】与【终止巡检任务】强制挂载 IxModal / IxPopconfirm 二次确认，并用通俗自然语言告知业务影响面，严禁技术黑话。
  • 🛑 客户端文案人性化大白话： 下发给员工的弹窗文案强制采用自然语言：“您的电脑缺少必备安全软件【DLP数据防泄密】，请点击链接快速安装”，严禁向员工弹出底层十六进制报错代码（如 `Error 0x800401`）。
  • 🛑 四重防破坏安全带： 严格遵循 SASE 外层响应式框架约束，严禁破坏导航栏、严禁修改 API 绑定的实体字段名、严禁将组件行高脱离 8px 网格规范。
