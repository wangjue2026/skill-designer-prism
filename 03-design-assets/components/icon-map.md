# 语义 → 图标映射 (Icon Semantic Map)

> **定位**：把「业务语义」映射到真实图标名，供设计说明书与 coding 直接引用。与 [`idux-component-map.md`](idux-component-map.md)（组件映射）并列，管**图标**这一层。
> **用途**：说明书第四章《可视化件声明》的「图标」字段；步骤 5 coding 按名取图标。
> 🚧 **状态**：骨架已立，**待补全真实图标库名**（以项目实际图标库为准，严禁杜撰）。

---

## 使用规则

1. **优先映射现成图标**：能查到就写真实图标名，coding 直接调用；
2. **查无则标"需按风格绘制"**：业务专属图标若图标库没有，标注由 coding 按 [`visual-styles/`](../visual-styles/README.md) 的风格参数绘制，**严禁杜撰图标名**；
3. **风格统一**：图标线宽 / 圆角 / 线性或面性，须与 `visual-styles/` 一致。
