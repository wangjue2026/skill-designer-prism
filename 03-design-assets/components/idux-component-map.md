# idux 组件映射

## 文档目的

本文件定义 Common Design 中页面语义到 idux 标准组件的映射与调用约束，用于指导 AI Coding 准确选择组件、调用组件能力并保持页面样式一致。

本文件只定义：

- 页面语义对应的首选组件；
- Coding 时命中组件的触发条件；
- 关键调用、样式、组合与状态要求；
- 禁止采用的替代实现方式。

本文件不负责判断：

- 当前产品是否已有业务封装组件；
- 是否应复用已有页面或业务模块；
- 当前代码仓库中具体组件路径、版本或完整 API；
- 页面最终采用直接引用、组件复用、复用框架还是全新开发。

上述内容由 `prd-design-code` 结合 Product Design 和当前代码环境决定。

## 调用边界

- 本表用于确定组件选型和项目内统一调用规则，不替代当前仓库 idux 版本的类型声明与组件文档。
- 生成代码前，优先复用仓库中已有的业务封装组件；没有对应封装时，再按本表调用 idux 标准组件。
- 本表未声明的 Props、事件和插槽不得凭空假设；应检查当前仓库中的同类实现或组件类型定义。
- 表内“适用场景”均表示 Coding 触发条件：页面描述或设计说明出现相应结构时，应优先命中对应组件。
- 表内“禁止做法”均表示实现禁区，重点避免原生元素替代、手写重复逻辑和自定义样式复刻组件。

## 组件映射表

| 设计语义 | 组件名称 | 适用场景 | 使用要求 | 禁止做法 |
|---|---|---|---|---|
| 按钮 | `IxButton` | 页面描述中出现新增、保存、取消、查询、重置、导入、导出、删除、确认等可点击操作时，统一使用。 | 默认使用 `size="sm"`；页面、弹窗、抽屉底部操作区使用 `size="md"`；唯一主操作使用 `mode="primary"`，常规操作使用 `mode="default"`。异步操作必须绑定 loading 状态并阻止重复提交；同组按钮按主操作在前、次操作在后排列。 | 不要使用原生 `button`、可点击 `div` 或自定义 CSS 模拟按钮；不要在同一区域混用不一致的按钮尺寸或主次规则；同一组禁止多个主按钮；不要遗漏异步操作的 loading 和重复点击保护。 |
| 弹窗/对话框 | `IxModal` | 页面需要展示确认、提示、告警、结果反馈，或承载非表单型的轻量内容浮层时使用。 | 确认与提示类操作使用 `confirm`、`info`、`success`、`warning`、`error` 等标准能力，并明确标题、正文、确认/取消回调。功能弹窗必须配置标题、可见状态、关闭回调和底部操作；承载表格时可使用 `paddingless="vertical"` 并在内容区组合工具栏与 `IxTable`。完整新增编辑表单优先改用 `IxProFormModal`。 | 不要用自定义遮罩、绝对定位容器或第三方浮层替代 `IxModal`；不要用 `IxModal` 手工拼装完整表单流程；不要遗漏确认后的 loading、关闭、数据刷新或回写；不要将复杂多步骤流程塞入普通弹窗。 |
| 抽屉 | `IxDrawer` | 页面要求在保留当前页面上下文的前提下打开详情、辅助配置或轻量编辑面板时使用。 | 明确 `visible`、标题、打开入口、方向、宽度、关闭回调和 footer 操作；关闭后保持来源页筛选、分页和滚动等已有状态。普通内容和详情使用 `IxDrawer`；表单默认使用弹窗承载，抽屉表单仅在用户额外说明或业务设计（product design）特别说明时使用。 | 不要用自定义侧滑容器替代 `IxDrawer`；不要在普通 `IxDrawer` 内重复实现完整表单容器逻辑；抽屉嵌套最多两层，禁止第三层；不要遗漏未保存提醒、提交后回写或列表刷新。 |
| 标签页 | `IxTabs` | 页面描述中出现视图切换、同层级内容切换或通过选项卡切换筛选维度时使用。 | 导航型 Tabs 使用 `type="line"`；作为筛选器时使用 `type="segment"`；默认 `size="md"`。绑定受控激活值和切换事件；切换后明确内容刷新、筛选重置或状态保留规则。 | 不要自行实现标签页样式；不要用普通按钮组替代 Tabs；不要在导航型与筛选型场景混用错误的 `type`；不要只切换视觉状态而未同步内容数据。 |
| 标签 | `IxTag` / `IxTagGroup` | 表格、详情、列表或表单回显中需要展示分类、状态、属性标记、等级标识、可移除条目或多个关联标签时使用。 | 状态类标签必须通过 `status` 使用组件预设语义色，并保持同一业务状态在全局的文案与状态映射一致；需要突出状态、风险等级或分类时使用 `filled`，边框型样式使用 `bordered`，不得手写颜色与边框。需要风险、告警、来源等图形语义时使用 `icon` 属性或 `#icon` 插槽；安全等级、风险等级、优先级等数字前缀使用 `number`，可与 `filled` 组合。可移除标签使用 `closable` 并处理 `close` 事件，同步更新表单值、筛选条件或数据源。多个关联标签使用 `IxTagGroup` 管理；组合标签设置 `gap="0"`，标签过多时通过 `maxCount` 省略，并用 `#rest`、`restRender` 配合 `IxPopover` 展示完整列表。仅对低风险、可逆的标记切换使用可变更标签，变更后同步数据并处理失败回滚。 | 不要用普通文本加自定义背景、边框或颜色模拟标签；不要在同一状态上混用不同的 `status`、颜色或文案；不要用多个 `IxTag` 加自定义 margin、负边距拼接组合标签；不要让过多标签无限换行撑高表格行；不要为只读状态增加 `closable`；不要将下线、删除、权限变更、策略生效等高影响操作设计为可变更标签。 |
| 徽标数 | `IxBadge` | 按钮、图标、文字旁需要展示数字或状态标记，或消息提醒、未读数量、告警计数等场景时使用。 | 通过 `dot` 在子元素右上角显示徽标点；通过 `count` 设置数字徽标，可包裹子元素显示在其右上角，也可独立展示。`count` 超过 `overflowCount` 时显示为 `${overflowCount}+`（如上限 99 时 100 显示为 99+）；默认 `count` 为 0 时隐藏，需要明确表达"当前为 0 条未读/告警"而非"无数据"时使用 `showZero`。自定义徽标内容有两种方式：将 `count` 设为任意字符串（如 HOT、NEW）显示文本徽标；或通过 `#count` 插槽完全接管徽标内容，可放置图标或短文本，插槽内容沿用徽标背景色（由 `status` 或 `--ix-badge-background-color` 决定）。`#count` 插槽仅在非 dot 模式下生效，`dot` 或 `dot="inline"` 走圆点分支并忽略该插槽。组件提供 4 种状态徽章，可使用 `--ix-badge-background-color` 自定义背景颜色。 | 不要用纯文本加自定义样式模拟徽标；不要遗漏 0 值隐藏与 `showZero` 的语义区分；不要在 dot 模式下依赖 `#count` 插槽；不要手写 `${overflowCount}+` 截断逻辑。 |
| 文本 | `IxText` | 定宽区域内展示可能溢出的名称、地址、规则、说明或多行文本，或需要提供纯文本复制能力时使用。 | 长文本使用 `ellipsis` 自动省略；多行文本通过 `<br />` 分行，并配合 `ellipsis.rows` 控制最大显示行数。需要展开查看完整内容时使用 `ellipsis.expandable`；需要复制时使用组件复制能力，复制内容必须是纯文本，并按需要配置 `trim` 控制是否清除多余空格和换行。 | 不要用 CSS 手写省略逻辑替代组件能力；不要让长文本撑破表格列、操作区或表单布局；不要把富文本或复杂节点作为复制内容；不要以截断文本作为唯一的信息访问方式。 |
| 单选框 | `IxRadio` / `IxRadioGroup` | 表单或筛选条件中出现一组选项互斥选择，如状态、动作、模式、类型等单选值时使用。 | 单个选项使用 `IxRadio`，一组互斥选项必须配合 `IxRadioGroup` 管理选中值。需要按钮样式时在 `IxRadioGroup` 上使用 `buttoned`；按钮样式尺寸使用 `size="sm"`、`size="md"`、`size="lg"`，默认 `md`，且仅在 `buttoned` 为 true 时生效。选项下方需要联动附加内容时使用 `fieldset` 插槽，并可通过 `showFieldsetArrow` 控制展开箭头。 | 不要用多个按钮、标签或普通文本模拟单选；不要让互斥选项脱离 `IxRadioGroup` 独立管理；不要在非 `buttoned` 场景强行配置按钮尺寸；不要把复杂多字段联动手写在组外而不跟随选中值切换。 |
| 选择器 | `IxSelect` | 表单、搜索或筛选中需要从候选项选择单个或多个值，或需要允许用户自由输入并回填为选项时使用。 | 单选默认使用 `IxSelect`；多选使用 `multiple`。多选需要确认后生效时使用 `needConfirm`；需要自由输入时使用 `allowInput`，单选可直接输入任意值，多选输入内容回填为新标签；需要校验搜索输入时使用 `searchValidator`。尺寸使用 `size="sm"`、`size="md"`、`size="lg"`，默认 `md`；可展开分组使用 `type: 'expandableGroup'`；需要扩展下拉菜单内容时使用 `overlayRender`。 | 不要用普通输入框或自定义下拉模拟选择器；不要用多个复选框替代复杂多选选择器；不要在需要确认的多选场景遗漏 `needConfirm`；不要在自由输入场景遗漏输入校验；不要手写分组展开收起或自定义下拉层逻辑替代组件能力。 |
| 级联选择 | `IxCascader` | 数据集合具有清晰的层级结构，需要逐级查看并选择（如组织、区域、分类、策略对象层级）时使用。 | 明确级联层级、默认展开层级、选中值结构与提交格式；支持多选，多选时注意 `fullPath` 开启后值类型的差异，提交前校验所选值格式与接口一致。 | 不要用多个 `IxSelect` 手工拼接级联；不要忽略多选与 `fullPath` 下的值类型差异；不要只展示层级而未同步选中值结构。 |
| 分页 | `IxPagination` | 数据列表、表格或可分页的搜索结果需要切换页码、页大小或定位当前页时使用。 | 绑定当前页、页大小、总数及其变更事件；页码或页大小变更后重新请求数据。筛选条件变化时重置到第一页；请求期间保持分页与数据的 loading 状态一致。 | 不要手写页码按钮或用普通按钮组模拟分页；不要只更新页码而不刷新数据；不要在筛选变更后保留可能失效的高页码；不要遗漏总数和空结果处理。 |
| 进度条 | `IxProgress` | 表格、卡片、任务详情或上传流程中需要展示完成率、使用率、容量占比、任务进度或异常进度状态时使用。 | 线性进度条默认使用 `IxProgress`；进行中使用 `status="active"`，完成态使用 `percent=100`，异常态使用 `status="exception"`。需要在文字后追加图标或自定义说明时使用 `#format` 插槽；需要按区间变色时使用 `strokeColor`。环形进度使用 `type="circle"`；卡片内微型状态指示使用较小 `stroke-width` 并配合 `hide-info`。尺寸使用 `size="sm"`、`size="md"`、`size="lg"`。 | 不要用自定义 div、宽度动画或硬编码色块模拟进度条；不要只展示百分比而遗漏状态语义；不要在表格或卡片内使用过大的进度条撑破布局；不要手写中心文字或尾随图标替代 `#format`。 |
| 加载中 | `IxSpin` | 查询、提交、局部操作处理中，需要展示加载状态或阻止重复操作时使用。 | 整页加载使用居中 Spin；局部加载用 `IxSpin` 包裹变化区域，保留表格结构与已有内容；提交类操作配合按钮 loading 防重复提交；预计短耗时（300ms 以内）操作使用轻量反馈或无需反馈，避免加载态闪烁。 | 不要用自定义旋转图标或 CSS 动画模拟加载；不要整页 Spin 导致已有内容闪空；不要遗漏操作中的重复点击保护。 |
| 骨架屏 | `IxSkeleton` | 页面、详情、弹窗或模块首次加载时，需要以占位结构降低等待焦虑时使用。 | 首次加载优先使用骨架屏；明确骨架结构数量与形状（行、头像、标题、按钮），与真实内容结构保持一致；加载完成后切换为真实内容；查询、刷新等局部变化不使用整页骨架。 | 不要用 Spin 或纯空白占位替代骨架屏；不要每次刷新都整页骨架导致闪烁；不要遗漏骨架与真实内容的结构一致性。 |
| 空状态 | `IxEmpty` | 列表、表格、筛选、搜索、树或详情内容为空时使用。 | 通过自定义插槽承载图形或图标、说明文案与操作按钮；空状态必须有出口（创建、导入、配置、清空搜索、重置筛选）；区分初始空、搜索无结果、筛选无结果与无权限导致的空，按场景配置文案与动作。 | 不要用无样式文本"暂无数据"替代组件；不要只展示空态而无下一步动作；不要将无权限导致的空态渲染为可创建引导。 |
| 结果页 | `IxResult` | 整页错误、无权限、操作完成或流程结束需要结果反馈时使用。 | 错误场景 `status` 使用 `error` 并提供重试或返回；无权限场景使用 403 语义或空态加权限说明；成功或完成场景使用 `success`、`info` 等状态并配置下一步动作。 | 不要用普通文本或自定义图标拼装结果页；不要只展示状态而无后续动作；不要将局部错误升级为整页 Result。 |
| 警告提示 | `IxAlert` | 局部模块错误、告警、提示信息需要内嵌展示时使用。 | error、warning 类型用于错误与告警，info、success 用于提示；支持可关闭与操作按钮；局部失败时展示失败说明与重试入口，不整页降级。 | 不要用 message 或 notification 承载需要持久展示的局部提示；不要用自定义样式色块模拟告警；不要将整页级错误降级为局部 Alert。 |
| 即时提示 | `IxMessage` | 单次操作成功、失败或轻量反馈需要即时提示时使用。 | 默认用于提交成功、单次操作失败等轻反馈；展示原因与可操作文案；短耗时操作避免重复触发；需要持久展示或批量通知时改用 `IxNotification`。 | 不要用弹窗或 Alert 替代轻提示；不要连续堆积多条 message；不要遗漏失败原因文案。 |
| 通知提示 | `IxNotification` | 需要持久展示或批量通知、告警、任务结果提醒时使用。 | 配置标题、内容、类型（success、error、warning、info）与持续时间；可提供查看详情或处理入口；批量失败可逐项列出失败明细。 | 不要用 message 承载需要用户处理的持久通知；不要用弹窗替代通知流；不要遗漏操作入口。 |
| 文字提示 | `IxTooltip` | 图标、按钮、标签或文字需要悬停补充说明、解释禁用原因或展示完整内容时使用。 | 配置内容与弹出方向；禁用态原因说明必须与禁用逻辑一致；内容应简短，长内容或需要交互操作时改用 `IxPopover`。 | 不要用原生 `title` 或自定义浮层替代；不要承载可交互操作（改用 `IxPopover`）；不要只依赖 tooltip 兜底解释而无其他方式。 |
| 气泡卡片 | `IxPopover` | 点击或鼠标移入对象后，需要展示气泡式卡片浮层，用于进一步描述对象或执行相关操作时使用。 | 默认显示指向触发元素的箭头，设置 `:show-arrow="false"` 可隐藏箭头仅展示纯气泡内容；通过 `content` 属性设置提示文字。通过 `closable` 在标题栏渲染关闭按钮，并用 `header` 设置标题；需要受控展示时使用 `trigger="manual"` 配合 `:visible.sync` 双向绑定。通过 `placement` 设置弹出位置，支持 12 个方向：上、下、左、右各方向及其起止位（如 `topStart`、`top`、`topEnd`、`leftStart` 等）。触发方式支持 `hover`、`focus`、`click`、`contextmenu`、`manual`。通过 `#header` 插槽可自定义头部内容（图标、状态标签等任意结构），比 `header` 字符串/对象属性更灵活；注意使用 `#header` 插槽时组件直接渲染插槽内容，`closable` 关闭按钮不会显示，需要关闭按钮时改用 `header` 属性配合 `closable`。 | 不要用自定义浮层或纯 CSS 模拟气泡卡片；不要遗漏 `placement`、触发方式与受控展示配置；不要在需要关闭按钮时使用 `#header` 插槽；不要将复杂表单流程塞入气泡卡片。 |
