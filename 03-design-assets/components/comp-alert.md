# 警告提示组件 (Alert)

## 使用声明

本规范只定义组件的视觉结构、布局关系、交互行为和验收标准，不提供具体框架代码实现。

生成代码时，必须以当前项目的技术栈 Skill 为准。

如果本规范与项目技术栈约束发生冲突，优先遵守项目技术栈约束。

本规范禁止包含：
- React / Vue / Angular 代码示例
- JSX / TSX
- TypeScript 示例
- import 语句
- className
- React state 写法
- 具体图标组件名
- 具体组件库 API

本规范中的组件名称仅表示设计语义，不代表必须使用某个框架或组件库的同名组件。

本组件遵循 [全局原子规范与间距规范](../global-styles/design-atomic-spacing.md) 中的设计原则。

Alert 用于页面内可见反馈，比 Message 更持久，比 Modal 更弱打断。

## 适用场景

- 页面内需要展示持续可见提示说明或告警信息
- 表单内需要解释的场景

## 强制数值规范

| 属性 | 值 |
|------|-----|
| 单行高度 | 最小 32px |
| 左右内边距 | 8px |
| 图标尺寸 | 16px（使用线性图标） |
| 图标与正文间距 | 8px |
| 圆角 | 普通 2px，banner 0px |
| 边框 | 无边框 |

## 普通提示条

- 图标颜色：var(--color-graphite-d10) (#6F7785)
- 文字颜色：var(--color-graphite-d10) (#6F7785)
- 背景颜色：#F7F7F8
- 文字字号：12px
- 文字字重：400

## 告警提示条

- 图标颜色：var(--color-bronze-d10) (#A35F40)
- 文字颜色：var(--color-bronze-d10) (#A35F40)
- 背景颜色：#FFFAF2
- 文字字号：12px
- 文字字重：400

## 链接规则

- 提示条内如有跳转链接，文字链接紧跟在提示文字右侧
- 链接与提示语间距：16px
- 多个链接文字之间用分割线分开
- 分割线高度：10px
- 分割线与链接文字间距：8px

## 关闭按钮

- 如果提示条可关闭，关闭 X 按钮右对齐

## 验收标准

- 提示条最小高度为 32px
- 普通提示条背景色和文字颜色正确
- 告警提示条背景色和文字颜色正确
- 图标尺寸和间距正确
- 链接与提示文字间距为 16px
- 多链接分割线样式和间距正确
- 可关闭提示条的关闭按钮右对齐
- 无边框

## 反例（禁止写法·已作废样例）

以下写法**不属于本产线规范**，禁止出现在说明书线框、映射清单与代码中：

| 反例 | 为什么禁止 | 正确写法 |
| :--- | :--- | :--- |
| 红色底 + 红字 + 红色边框的整块「影响警示」（`#FFF1F0` / `#D9363E` / `#FFA39E`） | 红色三元组只用于**文字级**错误提示与状态 Tag，不得作块级提示条底色；本组件只有普通条与告警条两档，没有红色档 | 影响说明用告警条 `#FFFAF2` / `#A35F40` |
| 橙底橙边块（`#FFFBE6` / `#FA8C16` / `#FFE58F`）当 Alert | 该三元组属于状态标签与指标高亮，不是提示条 | 同上；指标高亮保留在数字与标签上 |
| 蓝底蓝边「说明条」（`#E8F4FF` / `#BAE6FD`）当 Alert | 说明性内容不该借信息色抢注意力 | 普通提示条 `#F7F7F8` / `#6F7785` |
| 任何带 `border` 的提示条 | 本组件规范为无边框 | 去掉 border，用底色区分层级 |
| 大面积纯红卡片 / 红色渐变底 | 视觉噪点，压住正文对比度 | 见上表两档，禁止块级红色 |
