## 一、iDux 组件基线（A 级 · 来自 API 页原文）

```
组件：IxBarChart          类型：BarChartProps
说明：除下表外还支持 ECharts 全部配置 + AdditionalChartOption；
      下表配置即 ECharts BarSeriesOption 的部分配置。
函数：useBarOption(props, attrs) → ComputedRef<BarChartProps>
```

| Prop | 说明 | 类型 | 默认值 | ECharts 对应 |
| :--- | :--- | :--- | :--- | :--- |
| `data` | 数据内容 | Array | — | `series-bar.data` |
| **`barWidth`** | 柱条宽度 | number \| string | **10** | `series-bar.barWidth` |
| **`barGap`** | 不同系列柱间距离（**百分比**） | number \| string | **0.2** | `series-bar.barGap` |
| `label` | 图形上的文本标签 | SeriesLabelOption | — | `series-bar.label` |
| `name` | 系列名称（tooltip / 图例筛选） | string | — | `series-bar.name` |
| `markArea` | 图表标域（标记某段范围） | MarkAreaOption | — | `series-bar.markArea` |
| `stack` | 数据堆叠 | string | — | `series-bar.stack` |
| **`loading`** | 加载中态（**props 表未列，但 demo 模板实际使用** `:loading="loading"`） | boolean | — | 组件内置 |

> ⚠️ **单位差异（必读）**：设计源给的是「柱间距 **8px**、两端为半间距」，iDux 给的是 `barGap` **百分比 0.2**。
> 裁决：**以 iDux 为准**，即系列内柱距按 `barGap` 百分比计算；设计源的 8px 仅作**单系列**近似的参考值，不再作为强制值。

### 指南页给出的量化阈值（A 级 · 原文）

- 分类数据**不宜超过 20 条**；有多组分类数据时，**建议不超过 10 组**。
- 组件构成六件：`图形` / `坐标轴` / `提示信息` / `图例（可选）` / `数据标注（可选）` / `缩略轴（可选）`。
- 与其他图表分界：柱状＝多分类数值对比；折线＝连续或有序分类的趋势；饼图＝占比；玫瑰图＝半径对比（柱状是矩形长度对比）。

## 三、配色 Token（以设计源为准 · A 级）

柱体**不是纯色**，是「渐变 + 上阴影」两件套。重建必须成套给。
> 📌 **取值真源**：[`CHART-渐变与投影-token.md`](CHART-渐变与投影-token.md)（设计源 CSS 原文）。下表为索引，色值以该文件为准。

| 用途 | 命名样式 | 值 |
| :--- | :--- | :--- |
| 系列 1（如「服务器」） | `渐变色/蓝-竖` | `180deg` `#458FFF` → `#8FBFFF`（明亮端按横版同源推定 🚧） |
| 系列 2（如「终端」） | `渐变色/绿-竖` | `180deg` `#20CC94` → `#6EE6B6`（明亮端按横版同源推定 🚧） |
| 系列 3（如「分支」） | `渐变色/灰-竖` | `linear-gradient(180deg,#65779B 0%,#99ACD1 100%)` |
| 柱体阴影 | `投影/灰` | `0 -4px 10px rgba(101,119,155,.16)` |
| 柱体圆角·竖向 | — | `1px 1px 0 0`（上端圆角）｜ECharts `borderRadius:[1,1,0,0]` |
| 柱体圆角·横向 | — | **`0 1px 1px 0`**（右端圆角，左端贴轴不圆）｜ECharts `borderRadius:[0,1,1,0]` |
| 轴标签 / 图例文字 | `灰阶色/辅助文字（label）` | `#6F7785`（实现层 `--color-graphite-d10`） |
| 次级说明 | `灰阶色/提示文字` | `#A1A7B3` |
| 网格线 | `灰阶色/一级分割线` | `#E1E5EB` |
| 卡内分割 | `灰阶色/二级分割线` | `#D3D7DE` |
| 卡片 / 轨道底 | `灰阶色/二级背景颜色` | `#EDF1F7` |
| 禁用态文字 | `灰阶色/不可用文字` | `#BEC3CC` |

**文字规格（A 级实测）**

```
轴分类标签：苹方-简 / 12px / normal / line-height 12px / text-align center / letter-spacing normal / #6F7785
标题：16px 或 14px（iDux 侧按主题默认；设计源两档并存）
纵轴刻度行高：24px
```

## 四、逐亚型：结构 + 线框 + 实现

> 线框为**结构级**：给出层级、相对位置与必须存在的元素，不含像素级排版。
> 每个亚型的「实现」列中，未在 iDux demo 代码里核实过的配置项标 🚧（按 ECharts 语义推导，可用但需回归验证）。

### 4.1 `CHART-柱状图·基础-竖向`

```
┌ 图表卡片 ────────────────────────────────────────┐
│ 标题（16/14px）                                   │
│  ┌ 绘图区 ─────────────────────────────────────┐ │
│  │ 次 ‹单位›                                   │ │
│  │ 350 ┤                                        │ │
│  │ 250 ┤        ▉                               │ │
│  │ 150 ┤   ▉    ▉        ▉                      │ │
│  │  50 ┤   ▉    ▉    ▉   ▉    ▉                 │ │
│  │   0 └───┴────┴────┴───┴────┴──               │ │
│  │        周一  周二  周三 周四  周五   ‹分类轴› │ │
│  └──────────────────────────────────────────────┘ │
│ 图例（可选，单系列可省）                            │
└───────────────────────────────────────────────────┘
```
- 实现：`<IxBarChart :data>` 默认配置；`barWidth=10`、`barGap=0.2`
- 必备元素：Y 轴（数值 + 单位）、X 轴分类标签居中、横向网格线、柱体渐变 + 上阴影

### 4.2 `CHART-柱状图·基础-横向`

```
┌ 图表卡片 ────────────────────────────────────────┐
│ 标题                                              │
│  ┌ 绘图区 ─────────────────────────────────────┐ │
│  │ 分类A ▉▉▉▉▉▉▉▉                    123      │ │
│  │ 分类B ▉▉▉▉                45                │ │
│  │ 分类C ▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉  324           │ │
│  │        └──┬────┬────┬────┬──→ 数值轴        │ │
│  └──────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────┘
```
- 实现：轴互换（分类走 `yAxis`，数值走 `xAxis`）🚧
- 适用：分类名长（完整 IP / 长路径 / 长资产名），避免标签截断

### 4.3 `CHART-柱状图·基础-横向上方`（无轴排行条 · 对象名在柱上方）

> ⚠️ **此前的理解是错的**（2026-11-03 按设计源截图与 CSS 更正）：它不是「带数值轴的横向柱状图」，而是**没有坐标轴的排行条**——每一行由「对象名」+「柱体」上下两段组成，柱体下方还有一条**全宽浅灰轨道**。

**结构线框**

```text
服务器终端（200.200.101.123）          ← 对象名：12px / #6F7785 / 左对齐
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░      ← 柱体 10px 高；▓=渐变填充，░=轨道底
      ↕ 5px（对象名与柱体上下间隔）
服务器终端（200.200.1.2）
▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░
PC终端（196.168.10.15）
▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
```

**关键特征（全部来自设计源 CSS）**

| 项 | 值 | 依据 |
| :--- | :--- | :--- |
| **坐标轴** | **无**（不显示 X/Y 轴、无刻度、无网格） | 设计源截图 |
| **数值标签** | **不显示数字**（靠柱长表达） | 设计源截图 |
| 对象名位置 | 柱体**正上方**，与柱体左端对齐 | 设计源截图 |
| 对象名字体 | 苹方-简 12px / normal / line-height 12px / letter-spacing 0 / `#6F7785`（`--color-graphite-d10`） | CSS ① |
| **对象名与柱体间隔** | **5px** | CSS ④ |
| 柱体高度 | **10px** | CSS ②③（height: 10px） |
| 轨道底 | `#EDF1F7`（`--color-graphite-l40`，灰阶色/二级背景颜色），**全宽** | CSS ② |
| 填充条 | `linear-gradient(270deg, #ffc145 0%, #ffe396 100%)`（`渐变色/黄-横`） | CSS ③ |
| 填充条圆角 | `0px 1px 1px 0px`（右端圆角） | CSS ③ |
| 填充条投影 | `0px -4px 10px 0px rgba(255,193,69,0.16)`（`投影/黄`） | CSS ③ |
| 行距 | 设计源示例每行高 ≈ 22px（对象 12 + 间隔 5 + 柱 10，含行间 5） 🚧 待核 | 反推 |

**实现建议：这是 DOM/CSS 结构，不是 ECharts 轴线图**

```html
<!-- 单行 -->
<div class="rank-row">
  <div class="rank-name">服务器终端（200.200.101.123）</div>
  <div class="rank-track">
    <div class="rank-fill" style="width:72%"></div>
  </div>
</div>
```

```css
.rank-name{ font:12px/12px 'PingFang SC'; color:#6F7785; margin-bottom:5px; }
.rank-track{ position:relative; height:10px; background:#EDF1F7; }
.rank-fill{ position:absolute; left:0; top:0; height:10px;
  border-radius:0 1px 1px 0;
  background:linear-gradient(270deg,#ffc145 0%,#ffe396 100%);
  box-shadow:0 -4px 10px rgba(255,193,69,.16); }
```

> 📌 若强行用 `IxBarChart` 实现，需 `xAxis.show:false`、`yAxis.show:false`、`grid` 归零，且**无法把分类名放到柱体上方**（ECharts 的 `axisLabel` 只能垂直居中）——因此**推荐 DOM 实现**，或由业务侧封装成「排行条组件」。

**适用**：分类名很长（IP / 设备名 / 长路径）+ 需要一眼比长短、不需要读精确数值的场景。

### 4.4 `CHART-柱状图·分组-竖向`

```
│  ┌ 绘图区 ─────────────────────────────────────┐ │
│  │ 300 ┤                                       │ │
│  │ 200 ┤   ▉ ▤       ▉ ▤                       │ │

### 4.6 `CHART-柱状图·堆叠-竖向`

```
│  ┌ 绘图区 ─────────────────────────────────────┐ │
│  │ 500 ┤                                       │ │
│  │ 300 ┤   ▤▓▉       ▤▓▉      ▤▓▉             │ │ ← 段段相叠

- 适用：总量 + 内部构成（每日总告警 + 各级别构成）

## 七、正常态还原判据（照此验收）

1. 柱体是**渐变 + 上阴影**两件套，不是纯色；
2. `barWidth = 10`（iDux 默认），系列内柱距按 `barGap = 0.2` 计算；
3. 柱体上圆角 `1px 1px 0 0`；
4. 轴分类标签 `12px / #6F7785 / 居中`，纵轴刻度行高 `24px`；
5. 网格线只走横向，用 `灰阶色/一级分割线`；
6. 多系列**必须**有图例，图例在图表下方；
7. 分类数 > 20 或系列数 > 10 时应改型（换折线 / 下钻 / 分页），不得硬塞。

## 九、官方实现样例（源码级 · 点示例右上角 `<>` 取得）

> 包名：`@idux/charts`；组件 `<IxBarChart>`；外层统一 `style="height: 300px"`。
> 下面 8 段为**官方 demo 原样精简**（删去重复的标题/坐标轴样板），可直接当还原模板。

### 9.1 通用样板（所有亚型共用）

~~~vue
<script setup lang="ts">
import { type BarChartProps } from '@idux/charts'

const data = [123, 324, 156, 244, 188]

const barOption: BarChartProps = {
  label: { show: true },
  title: { text: '柱状图标题' },
  xAxis: { data: ['星期一', '星期二', '星期三', '星期四', '星期五'] },
  yAxis: { name: '次' },
  dataZoom: { type: 'slider' },   // ← 缩略轴（组件构成里的第 6 件）
}
</script>

<template>
  <IxBarChart style="height: 300px" :data="data" v-bind="barOption" />
</template>
~~~

### 9.2 横向（轴互换的确切写法）

~~~ts
xAxis: { name: '次', nameGap: 20, nameTextStyle: { verticalAlign: 'top', lineHeight: 26 } },
yAxis: { data: ['星期一', '星期二', '星期三', '星期四', '星期五'] },
~~~

> 要点：横向时**单位挂在 xAxis**，且用 `nameGap: 20` + `verticalAlign: 'top'` + `lineHeight: 26` 把单位顶到轴上方。

### 9.3 分组（多系列 + 上圆角）

~~~ts
series: [
  { data: [100,150,300,88,200], name: '到店靓仔', itemStyle: { borderRadius: [1,1,0,0] } },
  { data: [55,88,150,120,65],  name: '到店靓女', itemStyle: { borderRadius: [1,1,0,0] } },
]
~~~

> ✅ **与设计源互证**：`borderRadius: [1,1,0,0]` 正是设计源的「上圆角 1px 1px 0 0」。两边在这条上**完全一致**，可直接落。

### 9.4 堆叠

~~~ts
const barOption: BarChartProps = {
  stack: 'Total',          // ← 一个字符串即可，多系列共用
  xAxis: { data: [...] },
  series: [ { data: [...], name: '到店靓仔' }, { data: [...], name: '到店靓女' } ],
}
~~~

### 9.5 条纹（单系列）—— 用官方 hook，不要自己画纹理

~~~ts
import { seerColors, useStripeBarSeries, useStripeBarTooltip } from '@idux/charts'

tooltip: useStripeBarTooltip('次'),
series: [
  ...useStripeBarSeries({
    series: { name: '系列1', data },
    color: seerColors[0],   // ← 主题色数组，见 §9.8
    size: [7, 2],           // ← 条纹尺寸（实心 7 / 间隔 2）
  }),
]
~~~

### 9.6 条纹（多系列）—— 用 offset 错位

~~~ts
...useStripeBarSeries({ series: { name: '系列1', data },          color: seerColors[0], offset: [0, -6] }),
...useStripeBarSeries({ series: { name: '系列2', data: [120,34,136,204,198] }, color: seerColors[1], offset: [0, 6] }),
~~~

> 结论：**条纹不是纯 CSS，而是官方 hook 生成的 series**；`size` 控密度、`offset` 控多系列错位。这解决了之前“纹理怎么写”的空白。

### 9.7 自定义 tooltip

~~~ts
import { useTooltipsFormatter } from '@idux/charts'

tooltip: {
  trigger: 'axis',
  backgroundColor: '#FBFDFF',
  formatter (params) {
    const title = params[0].name
    const list = params.map(p => ({ name: p.seriesName, value: `${p.value} 个`, color: p.color }))
    return useTooltipsFormatter(title, list)
  },
}
~~~

> 官方默认 tooltip 底色：`#FBFDFF`；行内容用 `useTooltipsFormatter(title, list)` 统一格式。

### 9.8 加载中态

~~~vue
<IxBarChart style="height: 300px" :data="data" :loading="loading" v-bind="barOption" />
~~~

> `loading` 是**组件内置 prop**（API 表未列，源码里在用）。加载态无需自己画骨架。

### 9.9 配色覆盖方式（与“配色以设计源为准”的衔接）

官方通过 `seerColors` 主题色数组上色：`color: seerColors[0]`。设计源的三种渐变要落地，有两条路：

| 方案 | 做法 | 评价 |
| :--- | :--- | :--- |
| A｜组件透传 | 在 series 上给 `itemStyle.color` 传 ECharts 渐变对象（`{type:'linear',...}`） | 局部可控，逐图配置 |
| B｜主题覆盖 | 覆盖 `seerColors` 对应档位为设计源值 | 全局统一，但不支持“渐变色”这种非纯色 |
| **C｜推荐** | **渐变走 A（itemStyle.color 传 linear 渐变），纯色语义走 B** | 兼顾还原与一致 |

> 设计源柱体是**渐变 + 上阴影**，`seerColors` 只能给纯色 → **必须用方案 A 才能还原**。渐变对象按设计源取值：

~~~js
// 灰-竖（设计源 渐变色/灰-竖）
itemStyle: {
  color: { type: 'linear', x: 0, y: 0, x2: 0, y2: 1,
           colorStops: [{ offset: 0, color: '#65779B' }, { offset: 1, color: '#99ACD1' }] },
  borderRadius: [1, 1, 0, 0],
  shadowColor: 'rgba(101,119,155,0.16)', shadowBlur: 10, shadowOffsetY: -4,
}
~~~
