> 📌 **使用铁律**：**同档位颜色跨场景保持一致**。原文：“不同产品等级间颜色尽量保持一致，但由于部分定位不一样，故可通过字段进行微调，但只允许在该色系里微调，如果后一个等级需要弱化，可直接复用灰色。”
> —— 即：色阶顺序固定、色系固定，**允许在同色系内微调明度**，**不允许跨色系替换**；需要弱化时复用灰色。

## 二、八类业务场景 → 档位映射（同一套色阶，不同术语集）

| 场景 | 档位链（由重到轻） | 术语（图内原文，🚧 个别字迹待核） |
| :--- | :--- | :--- |
| 漏洞等级 | 7 档全用 | 严重 → 高危 → 中危 → 较低 → 信息 → 暂无风险 → 未绑定 |
| 严重等级 | 6 档 | 危重 → 高危 → 中危 → 较低 → 信息 → 安全 |
| 风险等级 | 5 档 | 已失陷 → 高危 → 中危 → 较低 → 安全 |
| 脆弱性等级 | 5 档 | 严重 → 高风险 → 中风险 → 低风险 → 安全 |
| 确定性等级 | 6 档 | 已失陷 → 高可疑 → 中可疑 → 低可疑 → 信息 → 安全 |
| 失陷等级 | 4 档 | 高风险 → 中风险 → 低风险 → 安全 |
| 威胁等级 | 4 档 | 高威胁 → 中威胁 → 低威胁 → 安全 |
| 设备状态 | 4 档 | 异常 → 告警 → 在线 → 离线 |

**关键结论**：这 8 个场景**共用同一套 7 档色阶**，只是各自取子集、换术语。所以落地时**不要为每个业务再造一套颜色**，只需选场景 + 套术语。

## 三、用法示例（原图给出的落地形态）

- **形态**：环形图 + **中心总数** + **两列图例带数值**
- 示例值：`340 总数` / `679 总数`，图例形如 `■ 严重 30  ■ 高危 60  ■ 中危 150 …`
- 用途：**占比 + 等级分布**一眼判读，适合安全事件 / 风险业务 / 资产分布

> 与柱状图规范的关系：这类"等级分布占比"首选**环形图**（`CHART-饼图·环形`）；若要跨对象比较数量，则用**堆叠柱状图**并按同一色阶上色。

## 四、与设计源的差异（必须知道）

| 项 | 设计源《柱状图》 | iDux 语义色板 |
| :--- | :--- | :--- |
| 语义色名 | `功能色/安全等级颜色/*`、`功能色/状态颜色/*` | 图表六/七档色阶（无命名样式） |
| 档位 | 信息/低危/中低危/中危/高危/失陷/安全（7 档） | 严重/高危/中危/低危/信息/未定级/暂无风险（7 档） |
| 取值 | 有 HEX 真值（如高危 `#CF171D`） | 仅图内色块 |
| 用途 | 通用状态表达 | **图表分类配色** |

**裁决**：图表内**分类配色**以本文语义色板为准；**状态图标/文字**仍用设计源的 `功能色/*`。两者不得在同一视图里混用同义色。

## 六、代码级用法（权威 · 来自《饼图》示例源码）

语义色板在代码里是一个**导出的数组**，直接赋给 `color`：

~~~ts
import { seerColorsForRisk, useTooltipsFormatter, type PieChartProps } from '@idux/charts'

const data = [
  { value: 30,  name: '严重' },
  { value: 60,  name: '高危' },
  { value: 120, name: '中危' },
  { value: 150, name: '低危' },
  { value: 50,  name: '信息' },
  { value: 40,  name: '未定级' },
  { value: 35,  name: '暂无风险' },
]

const pieOption: PieChartProps = {
  color: seerColorsForRisk,   // ← 语义色板入口，无需自己配颜色
  name: '风险总数',
  tooltip: {
    trigger: 'item',
    backgroundColor: '#FBFDFF',   // 官方 tooltip 底色
    formatter: (params) =>
      useTooltipsFormatter(params.name, [{
        name: params.seriesName, value: params.value, color: params.color,
      }]),
  },
}
~~~

### 6.1 两个 demo 的差别

| demo | 配置 |
| :--- | :--- |
| **风险等级颜色** | 只要 `color: seerColorsForRisk` + `name`，**不加 tooltip** —— 纯粹的配色规范演示 |
| **风险用户数** | 同配色 + **自定义 tooltip**（`trigger:'item'` + `useTooltipsFormatter`） |

### 6.2 落地铁律

1. **等级类图表一律用 `seerColorsForRisk`**，不要自己写 7 个 hex —— 数组本身即规范；
2. **数据顺序必须与七档一致**（严重→暂无风险），否则颜色错配；
3. 若某业务少于 7 档（如 4 档的设备状态），**取数组前 N 项**，不要跳着取；
4. 需要弱化某档时按规范“复用灰色”，不要自造浅色。
