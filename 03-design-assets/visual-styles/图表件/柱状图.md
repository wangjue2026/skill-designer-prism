## 三、尺寸 Token（A 级 · 设计源原文）

| Token | 值 | 出处原文 |
| :--- | :--- | :--- |
| 柱体最小宽 | **6px** | 「柱状图最细为6px」＋ 实测柱体 `W 6px` |
| 柱体最小高 | **1px** | 「默认状态：按比例显示高度，最小高度为1px」 |
| 柱间距 | **8px**（随横坐标宽度浮动） | 「柱状图的间距（根据底下横坐标宽度定）8px」 |
| 两端间距 | **柱间距的一半** | 「上下两个间距为几个柱子间距的一半」/「最左、最右两个间距为几个柱子间距的一半」 |
| 柱体上圆角 | **1px 1px 0 0** | 实测 CSS `border-radius: 1px 1px 0px 0px` |
| 纵轴刻度行高 | **24px** | 「纵坐标行高为24px」 |
| 标题字号 | **16px / 14px** | 「标题16PX」「标题14PX」（两档并存） |
| 柱体阴影 | `0 -4px 10px rgba(101,119,155,0.16)` | 实测，应用样式 `投影/灰` |
| 柱子容器（A 级） | `458 × 182`、`padding: 0`、`justify-content: space-between`；外间距四值 `22 / 37 / 11 / 48` | 研发模式「尺寸 + 布局」实测 |
| 图表实例整体（A 级） | `506 × 252`（`border-box`） | 研发模式「尺寸」实测 |

**自适应规则（原文）**

- 数据量少时「为保证视觉平衡，柱子宽度进行自适应调整」；
- 竖向：数据减少 60% 时**柱高不变、柱宽增加一半**；
- 横向：数据减少 60% 时**柱宽增至 10px、柱间距不变**；
- 「当只剩下一个种类的柱子时，跟基础柱状图的宽度保持一致」（分组/堆叠同规则）。

## 四、配色

### 4.1 柱体（A 级 · 属性面板实测，含命名样式）

| 项 | 值 | 命名样式 |
| :--- | :--- | :--- |
| 填充 | `linear-gradient(180deg, #65779B 0%, #99ACD1 100%)` | **`渐变色/灰-竖`** |
| 外阴影 | `0 -4px 10px rgba(101,119,155,0.16)` | **`投影/灰`** |

> 🔑 **关键发现**：柱体不是纯色，是**竖向渐变 + 上方外阴影**（阴影向上打，制造柱体"浮起"感）。重建时必须两件套一起给，只给纯色会明显失真。

### 4.2 系列色（A 级 · 研发模式「颜色」区实测）

柱体填充引用的就是三条**命名渐变样式**，不是裸色值：

| 系列 | 填充样式（命名） | 基色（常用色） | 渐变另一停靠点 |
| :--- | :--- | :--- | :--- |
| 系列 1（如「服务器」） | **`渐变色/蓝-竖`** | `常用色/蓝` `#458FFF` | 🚧 待展开 |
| 系列 2（如「终端」） | **`渐变色/绿-竖`** | `常用色/绿` `#20CC94` | 🚧 待展开 |
| 系列 3（如「分支」） | **`渐变色/灰-竖`** | `常用色/灰` `#65779B` | `#99ACD1`（已实测全段） |

> 📌 三条渐变同构：基色在底、按 ~40% 提亮的上停靠点收口；灰-竖的完整定义是 `linear-gradient(180deg,#65779B 0%,#99ACD1 100%)`，蓝/绿两条的明亮端色值因柱体位于组件实例内部、点选只能到容器层，**暂标 🚧**，不按比例推算。

## 六、图例

**位置**：「柱状图的图例通常放置在图表下方（极少情况放右侧）」。

**排布分档（按分类数量，原文）**

| 分类数 | 排布 |
| :--- | :--- |
| 少 | 优先**单列**排布，与图表高度大致对齐，保持视觉平稳 |
| 中 | 推荐**双列网格**排布，平衡宽高比，防止纵向过长 |
| 多 | 推荐**三列或多列**网格；超过容器承受范围时用**滚动条**或**翻页**（右侧左右箭头）收纳 |

> ⚖️ **口径裁决（2026-11-03）**：iDux 指南原文写「分类过多导致**超过两行**需翻页」——**本库不采用这条死规则**。改为：**先按容器可用高度排满行数**（2 列 × N 行，`N = floor((可用高 + 行距) / (行高 + 行距))`），**只有行数确实超出容器高度时才翻页**。理由：下方有空位却强制分页，是浪费空间并多一次交互。 |

**交互（原文）**

- 点击图例 → 全部变复选框，被点击项对应的柱子隐藏，其他柱子显示；
- 悬停时图例后出现复选框 hover 态；
- 图例若为固定值则显示固定值，若为变量则动态显示。

**两种增强形态**：`图例多列排列`、`图例带数值与百分比`（后者用于「需精确对比各系列数值与占比」）。

## 七、状态词表（各变体通用，原文顺序）

| # | 状态 | 语义 / 表达要求 |
| :---: | :--- | :--- |
| 1 | 正常 | 「展示带颜色的柱体、坐标轴及分类标签，鼠标悬浮展示具体数值」 |
| 2 | 极端场景 | 数据差距极大时的表现；规则「跟基础柱状图-竖向/横向一致」 |
| 3 | 数据已上报（全部值为 0） | 「明确告知当前分类已上报数据但数值均为零」；坐标轴保留，柱体高度为 0 |
| 4 | 加载中 | 「图表正在加载中，请稍后…」 |
| 5 | 数据未上报（单点值缺失） | 单点缺失不画柱，「可显示灰色虚线占位，悬浮提示」 |
| 6 | 带参考线 | 见 §五 参考线 |
| 7 | 空状态 | 「用于图表整体无数据或加载异常时，涵盖无权限、未配置、网络报错等情况，展示对应占位图与操作引导，避免图表区域完全空白」 |

**补充态（原文另有）**：`数据未上报（全部值缺失）`、`数据已上报（极限值：数据差距非常大）`、`加载失败，重新加载`、`数据缺失，xxxx缺失原因，xxxx处理方式`（占位文案模板）。

## 十、还原判据（怎么算做对了）

1. 柱体必须是**渐变 + 上阴影**两件套（`渐变色/灰-竖` + `投影/灰`），不是纯色；
2. 柱宽 ≥6px、柱间距 8px、两端间距 = 柱间距一半、最小高度 1px；
3. 上圆角 `1px 1px 0 0`；
4. 网格只走横向、轴标签居中、单位在数值轴顶部；
5. 图例默认在下方，按分类数量走「单列 / 双列 / 三列或翻页」；
6. 7 个状态逐态可切换，空态给占位图 + 操作引导，不能留白。
