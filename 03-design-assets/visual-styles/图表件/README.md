# 图表件（可视化图表） · `CHART-*`

> **定位**：`visual-styles/` 的**图表分块**。只回答"**图表里画什么图形、长什么样**"——柱 / 线 / 环、配色、轴与网格、图例、标注。
> **不是内容件**：内容件（`VIZ-*`，装什么信息、装在哪、多大、收不收）见 [`../内容件/`](../内容件/README.md)。两者组合使用，**不互相替代**：`CHART-*` 决定"柱、线、环"，`VIZ-*` 决定"装在哪"。
> **服务对象**：[D-11 母尺 ②.2「该用哪种局部图表可视化件？」](../../../01-system-solution-design/②设计思考与决策/通用设计决策/D-11-局部嵌入式可视化.md) 的候选答案空间；D-08 页面级卡片、D-03 表格内嵌迷你图的图形选型同源引用。
> **数据来源**：Seer 设计源文件《柱状图》`file/66349883742837` → 页面 **第三版**（第一/第二版作历史版本，不作依据）；结构、Props、间距规则、交互行为**以 iDux Charts 为准**，配色 / 文字色 / 分割线**以设计源为准**；柱宽取 `barWidth = 10`。
> **取数快照**：2026-11-02 ｜ 三个通道合用，证据等级逐项标注（见 §三）。本目录当前只做**正常态**。

## 一、与 D-11 ②.2 的接口（两步分流）

D-11 判图表可视化件时，**先选图形、再选容器**，本目录只管第一步：

```text
②  做内容可视化还是图表可视化？
   └─ 图表可视化
      → ②.2 该用哪种局部图表可视化件？
          ├─ 2a 选图形 → CHART-柱状图·<子类型>   ← 本目录（图表件/）
          └─ 2b 选容器 → 复用母尺 ③ 嵌入方式（列表顶通栏 / 卡片内 / 详情内嵌卡）→ 键落 内容件/
```

## 六、状态实现现状（当前只有「加载态」可落）

### 6.1 加载态：三个组件统一内置（A 级 · 来自示例源码）

柱状图 / 折线图 / 饼图的加载中 demo 均使用**组件内置 `loading` prop**，不需要自己画骨架：

~~~vue
<script setup lang="ts">
import { ref } from 'vue'
const loading = ref(true)
</script>

<template>
  <IxBarChart  style="height: 300px" :data="data"  :loading="loading" v-bind="barOption"  />
  <IxLineChart style="height: 300px" :data="data"  :loading="loading" v-bind="lineOption" />
  <IxPieChart  style="width:600px;height:300px" :data="data" :loading="loading" v-bind="pieOption" />
</template>
~~~

| 项 | 结论 |
| :--- | :--- |
| prop 名 | `loading`（**API 表未列，三个 demo 源码都在用**） |
| 类型 | boolean |
| 视觉表现 | 由组件内置，**无需自绘骨架**；具体图形（骨架条/转圈）由组件主题决定，🚧 未逐像素核对 |
| 时长与过渡 | 🚧 未知（不在文档页） |

### 6.2 其余四态：仍无依据

| 状态 | 现状 | 设计源怎么说 | iDux 有没有 demo |
| :--- | :--- | :--- | :--- |
| 空状态 | ✘ | 有规范（占位图 + 操作引导，涵盖无权限/未配置/网络报错） | 无 demo |
