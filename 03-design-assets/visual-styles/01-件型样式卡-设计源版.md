## 四、新需求复用链路（怎么做到"匹配后精准还原"）

```text
新需求需求描述
  → D-11 母尺 ① 判"要不要做局部可视化"
  → D-11 母尺 ② 判"用哪个件型" → 得到件型键（如 VIZ-01-A）
  → 打开本文件 §三 对应卡：拿到 解剖 / token 引用 / 度量 / 图形语言 / 退化
  → 打开 00 文件：把命名 token 换成具体值（色/字/阴影）
  → 写进《设计说明书》第四章《可视化件声明》的"风格规范"字段，直接引用
       见 visual-styles/01-件型样式卡-设计源版.md#31-viz-01-顶部统计概览
  → coding 照 token 画；任何裸 hex 都必须能反查到命名 token
```

**三条硬约束**

1. **不许绕过件型键**：说明书里出现"统计卡""概览条"这类口语名，必须落成 `VIZ-0x`。
2. **不许裸色值**：件型声明中的颜色一律写命名 token；写 `#EDF1F7` 必须同时写 `灰阶色/二级背景颜色`。
3. **不许拿产线值冒充设计源值**：卡里标 🚧 的字段，说明书中要么留空并列入待补，要么先补测再填。
