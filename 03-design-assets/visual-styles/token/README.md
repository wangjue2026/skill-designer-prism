# 值层 · token（色 / 字 / 阴影 / 渐变 / 语义）

> **定位**：`visual-styles/` 的**值层**。只回答"这个值是多少、叫什么名"，**不描述任何件型的解剖**。件型怎么拼看 [`../内容件/`](../内容件/README.md) 与 [`../图表件/`](../图表件/README.md)。
> **为什么单独成层**：原先 token 散在四处（根目录一份、`charts/` 两份、两个 json 分居两个子目录），来源还各不相同，读者无从判断"打架时听谁的"。现在集中在一层，并在此把优先级写死。

## 二、优先顺序（打架时听谁的）

> 🎨 **容器语气走哪个档？** 见 §六 —— **默认档 B（SASE：无框 / 白边 + 蓝调柔光 + r2）**，需要时整页切档 A。

同一个值在多处出现时的裁决顺序，**由高到低**：

| 顺位 | 来源 | 适用 | 说明 |
| :---: | :--- | :--- | :--- |
| 1 | **设计源命名 token** | 通用件型、图表填充渐变 | `基础-token.md` ＋ `图表-渐变与投影.md`；有 HEX 真值、有命名样式名 |
| 2 | **iDux 官方规范** | 图表**分类配色**（风险 / 等级） | `图表-语义色板.md`；图表场景下优先于设计源 `功能色/安全等级颜色/*` |
| 3 | **iDux 组件默认** | 组件行为与几何（`barWidth` / `radius` / `loading`） | 设计源无对应页面时的兜底 |
| 4 | **实现层 `tokens-cheatsheet.md`** | 线上实际值 | 仅作参照，**不得反推为规范** |

两条**分区裁决**（已落 `../图表件/裁决台账.md`）：

- **图表内的分类配色**以 `图表-语义色板.md` 为准；**状态图标 / 状态文字**仍用 `基础-token.md` 的 `功能色/*`。两者**不得在同一视图里混用同义色**。
- 设计源故障红 `#CF171D` 与实现层 `#D9363E` 系冲突 → **以设计源 `#CF171D` 为准**。

## 三、使用规则（写说明书时逐条遵守）

1. **只准引用命名 token**：写"灰阶色/二级背景颜色"，不写裸值；确需裸值时**命名与 HEX 同时给**（`#EDF1F7`＝二级背景颜色）。
2. **件容器底 / 页面底别混**：件容器底＝二级背景 `#EDF1F7`（l40），页面底＝一级背景 `#F7F9FC`（l50）；件内分割＝二级分割线（l20），容器外框＝一级分割线（l30）。
3. **状态色一律走语义名**：异常 `功能色/状态颜色/故障`、正常 `在线&健康`、中性 `离线`；禁止自造红 / 橙。
4. **色阶不跨组**：一个件里的色阶必须同组（如全用 `苍穹blue` 的 l50→d30）。
5. **阴影按风格档取**（见 §六）：**档 B（默认）** 件容器用 `glow-blue-s1`，扁平件可 `none`；**档 A** 用 `dropshadow-s1`。弹层 s2、抽屉 / 模态 s3 两档通用。**禁止自造第四个阴影。**
6. **字阶只有 12 / 14 两档命名**；概览卡 24px 数值为"**无命名档**"，须写死 `24px / 700` 并显式标注。
7. **图表两件套不可省**：柱体「竖向渐变 + 上阴影」，只给纯色即失真。

## 六、风格档（容器语气）· **默认档 B**

> 同一套结构（件型的解剖 / 几何）在不同产品里有**两种容器语气**。这不是对错，是"这一页想显得多轻"。**默认走档 B（SASE）**，需要时整页切档 A，**不得混档**。

| 项 | **档 B · SASE 款（默认）** | 档 A · 设计源款 |
| :--- | :--- | :--- |
| 出处 | SASE 产线实测（应用列表 / GPT 事件分析 / SSL 解密策略 / 软件统计） | Seer《预制菜》L1 |
| 卡片描边 | **`l50` 页底：白边 `1px #FFFFFF` 或完全无框；白底页：必须 `1px graphite-l30` 定界**（无框在白底上会"消失"，卡与页混成一片） | `graphite-l20 #D3D7DE` |
| 卡片阴影 | **蓝调柔光 `glow-blue-s1` ＝ `0 4px 20px rgba(117,157,218,.15)`**；扁平件可 `none` | `dropshadow-s1` `0 1px 4px rgba(31,35,43,.16)` |
| 圆角 | `2` | `4` |
| 面板 / 条目底 | `graphite-l50`；选中 `#FFFFFF` | `graphite-l40` |
| **装饰底（可选）** | **`bg-blue-wash` ＝ `linear-gradient(180deg,#E1EFFF 0%,#F2F8FF 40%,#F8FAFF 100%)`**（纵向三段，上深下浅；用于指引区 / 对象卡 / 面板底） | 无（设计源为纯平底） |
| 语气 | 轻、无框、靠柔光分层 | 稳、有框、靠描边分层 |

**切换规则**：① 整页同档，件与件之间不得一半 A 一半 B；② 切档只换上表这 6 项，**结构与几何不变**；③ 说明书里必须写明"本页采用档 B（默认）"或"档 A"，不能留空默认为设计源。

**新增登记（档 B 需要，已定名）**：

| Token 名 | 值 | 用途 |
| :--- | :--- | :--- |
| `glow-blue-s1` | `0 4px 20px rgba(117,157,218,.15)` | 卡片 / 指引卡浮起（替代 `dropshadow-s1`） |
| `border-ghost` | `1px solid #FFFFFF` | 白底页上的"隐形描边"，只用于把同色块与背景分开 |

> 仍待人工裁决的 2 项：`badge-step`（序号胶囊 `0 20px 20px 0`）、`glass-card`（毛玻璃卡）—— 它们是**件型级**材质，不是档位级。
