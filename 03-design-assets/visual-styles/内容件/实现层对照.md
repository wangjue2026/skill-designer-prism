> **定位**：本文件只记**实现层**（SASE / aTrust 实机页面量出来）的读数，用途是"设计源没覆盖时给 coding 一个参照"。

| 图形语言 | 三形态：**扁平单行**（3~5 指标横向排）/ **分组带维度树**（左组织树 + 右概览卡）/ **分析型双区**（图+数并置）；单卡 = 图标 + 值 + 标签；值选中 `24px bold`、其余 `14px` |
| 尺寸规格 | 扁平条项高 `≈72px`、左内距 `32px` / 右内距 `12px`；分组头 `h 130`、总数块宽 `16%`；带维度树概览卡 `pt 12 / pb 8`；分析型容器 `w 1176 · h 174` |
| Token 映射 | 值 `Metric LG 24px`；标签 `Caption 12px`；底 `graphite-l50 / primary-bg` |
| 反例 / 禁用 | 严禁高饱和纯色；指标 ≤2 个不应套概览条（退回纯文字） |
