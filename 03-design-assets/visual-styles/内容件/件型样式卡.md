### 3.8 `VIZ-08` 拓扑图（链路关系）

> **为什么单列**：拓扑既不是「配置逻辑图解」的子类，也不是「功能原理示意图」的附属。三者图可能长得像，但**回答的问题不同**：
> - ⑤ 配置逻辑图解 ＝ **介绍与指引**：左配置右图解，图只解释"这一项配置影响谁 / 生效范围"，随配置项整体切换；
> - ③ 功能原理示意图 ＝ **讲原理**：图文并茂的说明图，可收起，配文字讲"系统怎么工作"；
> - ⑧ 拓扑图 ＝ **承载链路关系本身**：节点与连线就是信息主体，读者顺着链路判断"数据经过哪几段 / 哪段不通 / 波及面多大"。
> 判据一句话：**把图里的文字说明全删掉，仍能靠节点与连线读出关系 → 拓扑；读不出 → 是③或⑤。**

#### 3.8.3 连线规范（矢量实测 · 可落地）

> 一条连线的完整构成。**关键结论：连线是「填充带」不是「描边线」**——用 `M/Q/L/Z` 闭合路径画出带宽与箭头，`fill` 走渐变，`stroke` 全程为空。

| 项 | 实测值 |
| :--- | :--- |

| 端点 | 圆头：半径 = 带宽一半（`Q` 收口），不是方头 |
| 箭头 | 同一个 path 内闭合三角：**长 5.0、全高 5.8**（相对线中心 ±2.9），尖端抵节点边缘 |
| 填充 | `linear-gradient` 近水平方向（`x1 0.26 → x2 1.08`，y 恒定）：`#AEB4BD → #5E6573`（左浅右深） |

**连线曲率（可落地结论）**

- 走线是**三次贝塞尔 `C`**，不是折线：同层实测 `M 56 16 C 105 16 105 16 154 16`——两个控制点与端点共线，**退化为直线**；
- 跨层为**3 段 `C` 串联**：每段控制点落在段内约 **1/3、2/3** 处，相邻段在连接点相切，视觉上无拐角；
- 因此**没有"固定曲率半径"参数**：曲率由两端端口位置与层间距算出。重建时用同类路由算法（manhattan + 圆角，或"端口切线水平"的贝塞尔）即可得到同款；**禁止**照抄某条 path 的坐标写死；
- 端点与节点边缘留 ≈`8`，箭头 `5×5` 贴端点。

### 3.10 `VIZ-10` 状态分布条（类目 × 状态构成）
