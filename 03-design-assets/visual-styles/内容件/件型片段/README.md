# 件型片段（可直接粘进说明书线框的 HTML）

> **定位**：本目录**只留 2 个样例**（`VIZ-01-A2` / `VIZ-10-A`），作用是示范"线框原语怎么组合"，**不再扩全量**。全量件型的结构与取值以 [`件型落地契约.json`](../件型落地契约.json) 为唯一出处（`root_class` / `required` / `tokens`）；片段不是资产清单，删掉也不影响门禁。
> **为什么不再扩**：片段里的 `<style>` 是 5.0 模板原语的副本，每加一个件就多一份要同步的 CSS——20 多个件就是 20 多份负债，而它提供的样式信息与 token 完全重复。
> **契约**：[`件型落地契约.json`](../件型落地契约.json) 里 `snippet` 字段指向本目录；`required` 类名就是片段里的类名。
> **依赖**：5.0 模板 `<style>` 的 `.wf-kpi*` / `.wf-segbar*` 等原语（片段自带一份"预览壳"，仅为单开可见）。

## 二、怎么用（两个动作，别搞混）

1. **看**：直接双击片段 → 打开就是该件的真实形态。若只看到几行字，说明 `<style>` 段被删了（片段是自包含的，不靠外部 CSS）。
2. **粘**：只复制 `▼ 复制起点 / ▲ 复制终点` 之间的那一段（件根元素 + 内部结构），**不要复制 `<style>`**——5.0 模板自带同名原语。示例数据可整块替换，结构不动。

> 🛑 **片段必须"自证"**：单独打开看不出形态的片段 = 废件（用户无法判断对不对，模型也无法照抄）。所以每个片段都自带预览壳，并用注释标出复制边界。

## 三、加片段的规矩

1. 数值只能来自 `件型线框.md` 的几何表 / 状态矩阵，**不许自造**；表中 🚧 的项须在注释里标 🚧 并写"建议值"。
2. 示例数据必须**跨行自洽**（各段之和 = 合计），并在注释首行声明"可整块替换"。
3. 根元素必须带 `data-viz="VIZ-xx-<形态>"`，否则 `SP-W-12` 判"未打标"。
4. **结构写两遍**：`<style>` 里的预览壳 + 复制区里的 DOM。预览壳的 `.wf-*` 规则与 5.0 模板保持逐字一致；**模板改，这里跟改**（校验 `SP-W-12` 只看类名，样式漂移靠人守）。
5. 复制边界注释固定写 `<!-- ▼▼ 复制起点 … ▼▼ -->` / `<!-- ▲▲ 复制终点 ▲▲ -->`，缺了等于没有可粘贴区。
