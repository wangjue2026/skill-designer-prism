# 内容件 · 件型线框与几何（可还原版）

> **定位**：`内容件/` 的**落地层**。每个件型给「结构线框 + 几何表 + 状态矩阵 + 还原判据」四件套——[`件型样式卡.md`](件型样式卡.md) 回答"这个件由哪几层组成、用哪条 token"，本文件回答"**每一层多大、间距多少、什么态下长什么样**"。对齐 `../图表件/柱状图-亚型规范.md` 的线框做法。
> **为什么要有这份**：样式卡只有文字解剖（`容器 ▸ [指标项 × N] ▸ …`），没有线框与数字，coding 只能猜；本文件补的正是这一层。
> **配色口径**：颜色一律写 [`../../global-styles/design-color.md`](../../global-styles/design-color.md) 的命名 token（`graphite-*` / `blue-*` / `red-d10`…），不写裸 hex；示例稿原值见 §二 映射表。

## 一、通用约定

| 项 | 约定 |
| :--- | :--- |
| 单位 | 全部 `px`（逻辑像素，1×） |
| 颜色写法 | 命名 token，**不写裸 hex** |
| 数字字体 | 计数 / 规模 / 指标值一律等宽数字，右对齐（保证竖排成列） |
| 行即卡 | 摘要行、分布行统一「浅底 + 4px 圆角 + 无边框」，hover 才出描边——避免一屏全是框 |
| 截断方向 | **标识与计数不截断，说明文案可截断**（读数优先级：是谁 > 多少 > 为什么） |
| 容器 | 件容器底 `graphite-l40`（设计源）／`graphite-l50`（部分实现层），描边 `graphite-l20`，圆角 `4`，阴影 `dropshadow-s1` |
| 视觉权重 | 件弱于主内容：件内最大字号不超过主内容标题一档 |
| 证据列 | `A-实现层`／`A-示例`／`设计源`／`🚧` 逐项标注 |

**位图件的特殊约定**（③⑤⑧A）：这类件**不靠"画"还原**，靠"带走素材"。线框只定义**容器位**（宽高、内距、是否可收起），图本体按素材原样贴入，**禁止 DOM 重绘**。素材登记见 §十三。

## 二、示例稿色值 → 命名 token 映射（沉淀前必经）

> 映射目标 = [`03-design-assets/global-styles/design-color.md`](../../global-styles/design-color.md)（**全局样式库命名**：`graphite-*` / `blue-*` / `red-d10`…）。它与 [`../token/基础-token.md`](../token/基础-token.md) 的**设计源命名**是同一套色的两种叫法，一一对应，例：`graphite-l40` ＝ `灰阶色/二级背景颜色`、`graphite-d40` ＝ `灰阶色/正文&标题`、`turquoise-d10` ＝ `在线&健康`。写规范时**优先用全局样式库名**，需要溯源设计源时再补设计源名。
> 规则：**能对上语义就归位，对不上就列缺口**，禁止把示例稿 hex 直接写进规范。✅ ＝ 与色板同值；🟡 ＝ 语义归位（值有偏差）；🚧 ＝ 色板无对应，需人工裁决。

**待裁决（🚧 3 条）**：① `#FF5752` 同时被用作"差"状态与"异常圆点"，是否需要更弱的点色；② 紧急数字是否允许用 `red-d10` 而非 `red` 主色；③ `#262626` 归位到 `graphite-d40` 后需复核对比度 ≥ 4.5:1。

### 3.5 状态矩阵

| 态 | 表现 |
| :--- | :--- |
| 默认 | 常驻展开，**不提供收起**（它是主内容入口读数，D-11 EP-04） |
| 异常指标 | 图标 + 数值同时转语义色，**不另开告警区**（EP-08） |
| 随主内容筛选 | 同源刷新：改维度树节点 → 概览 + 列表同步重算（EP-05） |
| 指标 ≤2 | **不渲染本件**，退回纯文字（EP-01） |
| 空 / 无权限 / 加载 | 🚧 设计源未覆盖（建议：保留容器 + 每项显示 `—` + 灰色图标，不隐藏项） |
| 窄屏 | 🚧（建议：横向滚动优于折行，保持一行可比） |

### 3.6 还原判据

1. 项高 `72±2`、左内距 `32`、右内距 `12`（A-实现层口径，引用时须标明）；
2. 数值 `24/700`、标签 `12/20`；数值与标签的**字重差不低于 300**，形成"值先行"；
3. 异常指标**图标与数值同色**，不得只改一项；
4. 容器底与页面底必须不同层（`l40` vs `l50`），否则件"浮不起来"；
5. 三档形态不得混用：扁平条不带维度树、分组卡必须有树、分析型必须有图；
6. 指标 ≤2 时必须退回文字（这是上游判据，不是样式选择）。

### 3.7 反例

- 指标只有 2 个还套概览条 → 版面浪费，读数变慢；
- 用高饱和纯色做指标值 → 违反状态三元组；
- 异常只改数字颜色、图标仍是常态色 → 语义不一致；
- 分组卡里再嵌一层卡片（卡套卡）→ 层级过深；
- 把"分析型双区"的图画成位图 → 图应来自图表件，须可随数据变。

## 五、`VIZ-03` 功能原理示意图（含 `VIZ-03-T` 时间线变体）

> 判据：**讲系统怎么工作**，且关系必须图形化才判读（D-11 EP-01①）。**位图保留件**：图本体是业务定制素材，禁 DOM 重绘。
> 与 ⑧ 的分界：③ 是"说明图"（可收起、贴模块入口、配文字讲原理）；⑧ 是"关系载体"（删掉文字仍能靠节点连线读出链路）。

### 5.1 线框

```text
┌ 通栏 · 图区 1200 × 176（位图 <img>，原样贴入）───────────────────┐
│ ┌──────────────────────────────────────────────────────────────┐ │
│ │   终端 ──────────▶ 网关 ──────────▶ 云端   （位图内绘制）    │ │
│ │   语义分区标签 / 域名 / 属性小标注（位图内嵌，不独立调色）    │ │
│ └──────────────────────────────────────────────────────────────┘ │
│ 收起态：只留标题行（可再展开）                                     │
└──────────────────────────────────────────────────────────────────┘

VIZ-03-T 时间线变体（可参数化重绘，几何 🚧）：
┌ 时间轴 ─┬──────┬──────┬──────┬────────────────────────────────────┐
│         ●──────●──────●──────●   事件节点 + 阶段分组（12/20 副标）  │
└──────────────────────────────────────────────────────────────────┘
```

### 5.2 几何表

| 项 | 值 | 证据 |
| :--- | :--- | :--- |
| 图区尺寸 | `1200 × 176`（通栏位图） | A-实现层 |
| 图区宽度 | 随主内容通栏铺满，不缩放位图以免糊 | 约定 |
| 收起态 | 只留标题行，可再展开 | D-11 EP-04 |
| 内距 | 图区与容器边 0（图自带留白） | A-实现层 |
| 时间线变体尺寸 | 🚧 | 待实测 |
| 节点标题 / 副标（T） | `14px / 22px`、`12px / 20px` | 样式库命名档 |

### 5.3 状态矩阵

| 态 | 表现 |
| :--- | :--- |
| 默认 | 展开；说明类件提供收起（EP-04） |
| 收起 | 只留标题行；**收起后必须能再展开** |
| 素材缺失 | 🚧 建议：留标题 + "示意图缺失"占位，**不得用全灰假图** |
| 无权限 | 🚧 |
| 加载 | 🚧 |

### 5.4 还原判据

1. 图是**位图原样贴入**，禁止用 DOM 节点 + 连线重画；
2. 位图按原尺寸贴入，**不做缩放拉伸**（缩放即失真）；
3. 收起/展开必须成对可用；
4. 图内文字不独立改色（随素材）；
5. 通栏件贴模块入口，不塞进卡片内层。

### 5.5 反例

- 用 SVG/DOM 重绘业务链路图（画不出，且后续无法维护）；

| 空（无异常） | 🚧 建议：单行 `12px graphite-d10`「暂无异常对象」，不画空行底 | 🚧 同左 |
| 长文本 | **风险**：主文与说明均 `nowrap` 且不收缩 → 会挤出列宽（示例稿注释明说"优先保障用户名完整"）；建议**说明区加 truncate**，主文保留 | 已 `truncate` |
| 计数 = 1 | 示例稿用 `x-if degradedCount > 1` 隐藏"等 N 个" → **单数不显示计数** | 规模固定显示 |
| 加载 | 🚧 未覆盖 | 🚧 |
| 无权限 | 🚧 未覆盖 | 🚧 |

### 11.5 还原判据（照此验收）

1. 行高 `30` / 行距 `4` / 行底 `graphite-l50` / 圆角 `4`，三者偏差 >1px 判不合格；
2. 状态点 `6×6`，点与主文间距 `6`；
3. **读数优先级**成立：主文（500）> 值（d20）> 说明（d10）；计数用语义红 `red-l10` 而非主文色；
4. 数字用等宽并右对齐，两列数字竖直对齐；
5. 每行整行可点，hover 三件套（白底 + `blue/40` 描边 + 主文转 `blue`）到位；
6. 行数 ≤4，超出**翻页不滚动**；
7. 截断方向正确：**标识与计数不截断，说明可截断**；
8. 颜色不得出现 ⓐ 示例稿原 hex、ⓑ 高饱和纯色（如 `#F53F3F`）。

### 11.6 反例

- 把摘要行做成表格（加表头、列宽、排序）→ 这是表格，不是本件；
- 行内塞 ≥3 个字段或换行 → 失去"一行一次决策"；
- 用 `red` 主色 `#F52727` 当异常点 → 过饱和，应 `red-l10`；
- 行高随内容撑开（`min-h` 而非 `h`）→ 多行高度不齐，竖排扫读失效；
- 空态画一堆灰色占位行 → 应明确说"暂无异常"。

## 十二、`VIZ-10` 状态分布条（类目 × 状态构成）

> 判据：**多类目 × 互斥状态**，且要在 ≤36px/行 内同时给「总量 + 构成比例 + 各状态数」。它是**多环饼图的替代品**：饼图一行只能表达一个类目的构成，多类目要 N 个环；横向分段条天然一行一类目，`4px` 高就够。

### 12.5 还原判据（照此验收）

1. **比例自洽**：段宽 = 各状态数 / 总数；Σ各状态数 = 总数 = 类目区显示的总数。**三者任一不等即判错**（示例稿分支行 24 vs 22+2+2=26 就是错例，见 §12.6）；
2. 条 `h4`、整条 `r full`、**段间无 gap 无圆角**；条高 >6px 判抢主内容；
3. 状态色固定有序：`green` → `orange-l10` → `red-l10`（B 形态 `turquoise-d10` → `red-d10`），不因占比大小换色；
4. 数值行在条**上方**，状态名左对齐、数字右对齐，三段定宽 `70/52/44`，竖排数字能对齐成列；
5. 层级成立：类目 `graphite-d40` > 状态数 `graphite-d20` > 总数 `graphite-d10`；
6. 行高 `36` / 行距 `8` / 行底 `graphite-l50` / 圆角 `4`（B 形态行高 `24`、无底）；
7. 点击粒度到「维度 × 状态」，不是只到维度；
8. `0` 值得弱化不隐藏；`未上报` 与 `0` 必须是两种不同表达。

### 12.6 反例

- **用环/饼替它**：多类目要 N 个环，横向比长短比比角度更准；
- **段间留白或加圆角**：比例失真，且视觉上出现"假间隙"；
- **条宽按"数值/最大值"归一**：必须 `100%` 堆叠，否则类目之间不可比；
- **状态数之和 ≠ 总数**：示例稿「分支 24 个 / 22 + 2 + 2」自相矛盾，且条宽写死 `70/15/15` 与数值不符 → 录入错误，**不复刻**；
- **用红色表示「0 异常」**：制造虚假告警，`0` 必须弱化；
- **三段以上仍用横条**：状态 >4 → 换堆叠柱 / 100% 堆叠图表件；
- **把条做成可拖拽/可悬停 tooltip 才能读数**：紧凑件要求"不用交互就能读"，数值必须常显。
