# 内容件（可视化内容） · `VIZ-*`

> **定位**：`visual-styles/` 的**内容分块**。只回答"这一块**装什么信息**、装在哪、多大、怎么退化"——指标概览、对象身份、原理说明、步骤引导、配置图解、实时预览、状态流程、**链路拓扑**。
> **不是图表**：图表（柱 / 线 / 环怎么画）见 [`../图表件/`](../图表件/README.md)。两者共存不互替：内容件给**容器与信息位**，图表件给**图形**；`VIZ-01-C`（分析型双区）就是"内容件容器 ＋ `CHART-*` 图形"的组合。
> **上游判型**：[D-11](../../../01-system-solution-design/②设计思考与决策/通用设计决策/D-11-局部嵌入式可视化.md) 母尺 ①（要不要做局部可视化）→ ②.1（用哪个内容件型）。
> **取数来源**：Seer 设计源文件《预制菜》→「可视化的规范」→ L1 / L2，快照 2026-11-02。
> **口径修正（2026-11-03）**：**拓扑不再属于 ⑤ 配置逻辑图解**，也不再是 ③ 的变体，已独立为 `VIZ-08`（见样式卡 §3.8）。⑤ 只做介绍与指引；③ 只做原理说明。

## 三、新需求复用链路

```text
需求描述
  → D-11 母尺 ①：要不要做局部可视化
  → D-11 母尺 ②.1：用哪个内容件型 → 得件型键（如 VIZ-01-A）
  → 本目录 §二 查键 → 打开 件型样式卡.md §3.x：拿 解剖 / token 引用 / 度量 / 图形语言 / 退化
  → 打开 ../token/基础-token.md：把命名 token 换成具体值（色 / 字 / 阴影）
  → 若这件里要画图：转 ../图表件/README.md 选 CHART-* 键
  → 写进《设计说明书》第四章《可视化件声明》的「风格规范」字段，直接引用
       见 visual-styles/内容件/件型样式卡.md#31-viz-01-顶部统计概览
  → coding 照 token 画；任何裸 hex 都必须能反查到命名 token
```

**三条硬约束**

1. **不许绕过件型键**：说明书里出现"统计卡""概览条"这类口语名，必须落成 `VIZ-0x`。
2. **不许裸色值**：件型声明中的颜色一律写命名 token；写 `#EDF1F7` 必须同时写 `灰阶色/二级背景颜色`。
3. **不许拿产线值冒充设计源值**：样式卡里标 🚧 的字段，说明书中要么留空并列入待补，要么先补测再填。
