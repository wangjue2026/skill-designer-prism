# 件型参考实现（`VIZ-*` 的落地样板）

> **定位**：D-11 判型拿到 `VIZ-xx-<形态>` 之后，**代码从这里取**——6 个可双击打开的整页样板，每页覆盖若干件型。
> **不是新规范**：规范仍是 [`件型样式卡.md`](../件型样式卡.md)（长什么样）＋ [`件型线框.md`](../件型线框.md)（多大、什么态）＋ [`件型落地契约.json`](../件型落地契约.json)（结构类名 + 取值）。本目录回答的是"**具体怎么写出来**"。
> **冲突时以契约为准**：参考实现与契约/线框不一致 → 改本目录的页，不许反过来改契约去迁就实现。
> **业务内容一律是示例**：页面里的"在线用户 / 在线终端 / PC-DEV-001 / 研发一部"只为把版式撑满，**全部可整块替换**，不构成任何业务规则。

## 一、目录

```
参考实现/
├── 参考实现索引.json      # 键 → 页 + 选择器 + 填空槽位（本目录的唯一台账）
├── pages/                # 6 个整页样板（自包含 HTML，双击即开）
├── 建造与校准记录.md      # 这 6 页是怎么按内容件逐件校准出来的（证据）
└── 判型记录.md            # 白板需求的 D-11 判型过程（证据）
```

> **为什么是 6 个整页，不是 22 个按键片段**：按键拆片段会让同一套 CSS 复制 22 份，模板一改就 22 处漂移（历史上 `件型片段/` 就是因此废弃）。整页只维护 6 份 CSS，取用时由工具**现场抽取**该件命中的规则，不产生第二份真源。

## 三、取用三步（不许跳）

```bash
# ① 判型取键（D-11 母尺 ②.1）→ 拿到 VIZ-xx-<形态>
# ② 抽代码（填空清单 + 本件命中的 CSS + DOM）
node tools/viz-ref.js VIZ-08-C
#    只要结构 / 只要样式
node tools/viz-ref.js VIZ-08-C --html
node tools/viz-ref.js VIZ-08-C --css
# ③ 填空 + 重画图标 → 落进说明书线框，并写《可视化件声明》
```

**填空只动内容，不动这三样**：结构（类名与嵌套）、几何（元素尺寸 / 间距 / 圆角）、配色（token 与状态色归位）。

| 必须换 | 不许改 |
| :--- | :--- |
| 对象名、组织名、应用名、终端名 | `data-viz` 与 `wf-*` 类名（结构对账靠它） |
| 所有数值、百分比、时延、总量 | 元素尺寸（项高 / 行高 / 圆角 / 定宽区） |
| 状态词（正常 / 告警 / 离线 …） | 容器与行底的分层关系（l50 / 白底谁在谁上） |
| 指标名、类目名、字段名、阶段名 | 状态编码方式（色 + 形双重编码，不只换色） |
| 标题、说明、时间与时长 | 同页不得混用两套口径（球径 40 配角标 14 这类） |
| **图标形状**（见 §四） | 图标尺寸 / 线宽 / 底色 / 色阶 |

## 四、图标：语义重画，不搬示例形状

参考页里的图标（显示器 / 文档 / 服务器 / 三角 / 叉圆）只是**把示例撑满**，落到新需求必须**按新对象的语义重画**，否则就是"在线用户 / 在线终端"的痕迹。

| 图标族 | 画法（尺寸与配色沿用参考页） | 换业务时怎么改 |
| :--- | :--- | :--- |
| **对象 / 身份类**（24 或 32） | 圆角方块浅底 `#E8F4FF` + 1.8 线性描边 `#1C6EFF`；`VIZ-01-*` 的主指标图标用渐变素材型（`#1CBFFF → #1C6EFF`） | 换**图形语义**：设备就画设备、账号画账号、策略画策略；不换尺寸与底色 |
| **状态类**（16 或 12） | 正常＝对勾圆 `#12A679`／告警＝三角感叹 `#FA721B`／严重＝叉圆 `#D9363E`／中性＝空心圆 `#A1A7B3`／未纳管＝虚线圆 `#BEC3CC` | **不换**，这是状态编码本身；只换它标注的对象 |
| **类目 / 节点类**（14 / 20 / 44） | 线性 1.8 描边，按对象语义自绘，圆/方底走容器口径 | 换语义形状，保留线宽与容器口径 |

判据一句话：**把图标换成另一个业务的对象后，尺寸、底色、线宽、状态色都还得对得上**——对得上说明只换了语义；连尺寸都改，说明在重画规范，退回去看样式卡。

## 五、反例（直接判"没还原"）

- **整页照搬**：把 `body` 的 24px 外距、演示用 `wf-container`、别的件型的 CSS 一起抄进说明书。
- **示例残留**：新页面里还出现"在线用户 / 在线终端 / PC-DEV-001 / 研发一部"。
- **图标不换**：新需求是"策略 / 应用 / 组织"，图标还是显示器和文档。
- **改尺寸凑版面**：为了让内容放下，把 44 的节点缩成 32、把 40 的间距压成 16——应改容器宽度或换形态键。
- **手抄样式**：不跑 `viz-ref` 自己凭记忆写，漏 `:root` token 或漏 hover / 状态规则。
