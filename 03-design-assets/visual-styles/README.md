## 填充机制（由蒸馏填充，非纯人工）

> 本文件与 [D-11 经验库](../../01-system-solution-design/②设计思考与决策/通用设计决策/D-11-局部嵌入式可视化.md) **同源同批**：一次蒸馏取证，产出**两份**——① **经验**（选哪种件、怎么嵌 / 联动 / 退化）落 D-11；② **风格规范**（这个件长什么样）落本文件。

| # | 规则 | 说明 |
| :---: | :--- | :--- |
| 1 | **有样本才填** | 只写从真实页面 / 截图 / DOM **实测**到的读数（色值 / 线宽 / 圆角 / 间距 / 图标形态 / Token）；**无样本一律标 🚧 待取证，严禁脑补** |
| 2 | **实测 + 归纳** | 可测项（配色 / 尺寸 / Token 映射）直接取数；判断项（线性 or 面性、是否统一、图形语言）由多产线样本**归纳** |
| 3 | **多风格 → 人工指定 / 分叉** | 多产线风格不一致时，先收敛为「统一基线」；若确有两种以上正当风格，分叉为「风格档 ① / ②…」并**由规划人员指定默认档** |
| 4 | **与经验同锚** | 每条风格规范须挂到 D-11 对应决策场景的样本行，与经验证据互为佐证 |

## 通用约束（所有件型共同遵守）

- 配色必须落在 [`tokens-cheatsheet.md`](../tokens-cheatsheet.md) 白名单内，**严禁自造色值**；
- 状态一律「浅底 + 深字 + 浅边框」三元组；
- 图标风格须全局统一（线性 / 面性、线宽、圆角一致）；
- 视觉权重默认**弱于主内容**（参见 D-11 母尺 ⑪）。

## ① 顶部统计概览

| 字段 | 规范内容 |
| :--- | :--- |
| 适用件型 | 列表页顶部汇总统计（扁平指标条 / 分组统计概览 / 分析型双区 三形态） |
| 配色 | 指标值 `#2F3540`（graphite-d40）；容器底 `#F7F9FC`（graphite-l50）或主色浅底 `primary-bg`（部署统计实测）；异常用语义深色（未安装=红 `#D9363E`、正常=绿 `#12A679`、信息=蓝 `#1C6EFF`） |
| 图标风格 | `24×24`；业务专属图标为**渐变 SVG 素材型** → **需按风格绘制**（不套通用线性 icon，见 `icon-map.md`） |
| 图形语言 | 三形态：**扁平单行**（3~5 指标横向排）/ **分组带维度树**（左组织树 + 右概览卡）/ **分析型双区**（图+数并置）；单卡 = 图标 + 值 + 标签；值选中 `24px bold`、其余 `14px` |
| 尺寸规格 | 扁平条项高 `≈72px`、左内距 `32px` / 右内距 `12px`；分组头 `h 130`、总数块宽 `16%`；带维度树概览卡 `pt 12 / pb 8`；分析型容器 `w 1176 · h 174` |
| Token 映射 | 值 `Metric LG 24px`；标签 `Caption 12px`；底 `graphite-l50 / primary-bg` |
| 反例 / 禁用 | 严禁高饱和纯色；指标 ≤2 个不应套概览条（退回纯文字） |

## ③ 功能原理示意图

| 字段 | 规范内容 |
| :--- | :--- |
| 适用件型 | 讲"系统怎么工作"的图文说明图（链路原理 / 状态对比 两形态） |
| 配色 | 图本体为**位图素材**，配色随素材归保留件，**不重绘、无独立 Token** |
| 图标风格 | 节点图标（设备 / 服务 / 网关 / 云）为位图内嵌，不独立调色 |
| 图形语言 | 链路原理图文并茂；语义分区标签 + 域名 / 属性小标注；可收起 |

| Token 映射 | 无（位图保留件，连素材带走） |
| 反例 / 禁用 | 严禁用 DOM 节点 + 连线重绘原理图（业务定制、画不出来） |

## ④ 顶部帮助指引卡

| 字段 | 规范内容 |
| :--- | :--- |
| 适用件型 | 引导用户完成前置操作的图文卡（编号步骤 + 说明 + 跳转路径） |
| 配色 | 编号方块用浅底 `#F1F5F9`（graphite-l40 系）+ 深字 `#2F3540`；步骤分隔符 `»` 用中性灰 `#A1A7B3` |
| 图标风格 | 可选小图示（引导场景配步骤小图，非强约束） |
| 图形语言 | 编号步骤 + `»` 分隔符 + 跳转路径；可收起 |
| 尺寸规格 | 竖排 `gap 8px`；外层 `pt/pb 8px · min-w 400px`；步骤标题 `14px / 24px` bold |
| Token 映射 | 步骤标题 `Body 14px`；说明 `Caption 12px` |
| 反例 / 禁用 | 步骤超过 4 步时应分组或收起，勿硬撑一长条 |

## ⑤ 配置逻辑图解

| 字段 | 规范内容 |
| :--- | :--- |
| 适用件型 | 配置表单里的逻辑示意图（左配置项、右图解） |
| 配色 | 图本体为**位图素材**（拓扑 / 生效范围），配色随素材保留，不重绘 |

| 图形语言 | 左配置右图解；节点 / 连线 / 箭头语义在位图内；表达条件与生效范围 / 拓扑；图随配置项整体切换（单向解释） |
| 尺寸规格 | 容器 `w 1044×138` / `w 1092×132`；图 `373×378 ~ 868×416` |
| Token 映射 | 无（位图保留件，连素材带走） |
| 反例 / 禁用 | 严禁 DOM 重绘拓扑图；勿做"点图内节点定位字段"双向定位（首轮三产线未见） |
