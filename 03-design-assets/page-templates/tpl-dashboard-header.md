# 页面模板：监控大盘标准套头规范 (TPL-01 Dashboard Header)

## 1. 适用场景
适用于云原生网络监控、系统健康度大盘、安全态势大屏等运维监控类场景。

## 2. 页面套头标准骨架 (DOM / Flex 构成)
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [左侧: 页面主标题 + 状态指示绿点]       [右侧: 时间切片选择器 | 自动刷新(30s) | 导出] │
├────────────────────────────────────────────────────────────────────────┤
│ [KPI 4联胶囊栏: 核心指标A (环比) | 核心指标B (趋势) | 核心指标C | 核心指标D] │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. 核心客观约束 (Tokens & Spacing)
* **主标题区高度**：固定 48px，标题字号 `16px font-semibold text-[#1F2937]`，状态脉冲圆点 `w-2 h-2 rounded-full bg-[#52C41A]`；
* **右侧控制组**：高度统一采用 32px，时间切片选择器背景白底带轻微边框 `border-[#E5E7EB]`，操作间距 `gap-2 (8px)`；
* **KPI 胶囊栏**：与标题区垂直间距 `mt-4 (16px)`，采用 4 栅格平铺，卡片内 padding `p-3 (12px)`，底色 `bg-[#F8FAFC]`，无粗重边框。
