## 页面模板匹配前置判断

生成以下页面类型时，必须先识别页面类型和导航类型，再读取对应页面结构线框：基础表格页、左树表格页、概览表格页、概览左树表格页、配置表单页、下钻步骤条配置页、Dashboard。导航类型只影响这些页面的布局，不改变组件名称或组件调用方式；其他页面不区分导航类型。

仅对需要区分导航的页面，页面结构标题保留英文标识：`页面结构：左侧导航（left-shaped）` 或 `页面结构：L 型导航（l-shaped）`。AI 确认导航类型后，只读取同名结构标题下的线框；其他页面使用统一页面结构。

### 导航类型

| 导航类型 | 页面结构特征 | 标题栏与内容区关系 |
| --- | --- | --- |
| `left-shaped` | 左侧为独立深色导航，页面主体位于右侧 | 页面标题栏独立位于右侧内容区顶部，页面内容位于标题栏下方；页面结构标识为“页面结构：左侧导航（left-shaped）” |
| `l-shaped` | 左侧导航与顶部导航形成 L 型框架 | 页面标题栏与页面内容共同位于同一个内容卡片内；页面结构标识为“页面结构：L 型导航（l-shaped）” |

### 匹配规则

1. 优先读取当前产品或已有页面明确声明的导航类型。
2. 如果用户提供参考页面、截图或现有代码，依据整体导航结构判断，不仅根据页面内容猜测。
3. 如果导航类型未明确，默认使用 `left-shaped`，并标记导航类型待确认。
4. 对上述七个页面确定导航类型后，只读取对应页面结构线框，不得混用两种导航结构。
5. 其他页面不读取导航变体，沿用各自默认页面结构；弹窗和抽屉自身结构与组件信息不因导航类型变化。

### 页面模板元信息

页面级模板使用以下字段标识导航适配范围：`页面类型 ID`、`默认导航类型`、`支持导航类型`、`导航影响`。

## 1. 页面类型

页面类型用于判断页面整体骨架、入口层级和内容承载方式。线框图中的“页面标题栏”是标题区域占位，实际生成时必须按“2.1 页面标题栏”选择对应标题栏结构。

### 列表类

### 1.1 基础表格页

- 页面类型 ID：`page-table-basic`
- 默认导航类型：`left-shaped`
- 支持导航类型：`left-shaped`、`l-shaped`
- 导航影响：标题栏与内容卡片的组合方式不同。

用于对同一类型对象进行集中查询和管理，通常包含搜索、筛选、排序、分页、新增、编辑、删除、导入导出及批量操作，例如资产列表、用户列表、策略列表、漏洞列表和白名单列表。配置单条规则或全局参数时使用配置表单页或弹窗表单页承载，不使用基础表格页。

#### 页面结构：左侧导航（left-shaped）

```text
┌──────────┬───────────────────────────────────────────────────┐
│          │ 页面标题栏 (48px，紧贴左侧导航)                   │
│  左侧    ├───────────────────────────────────────────────────┤
│  深色    │ ↓ 间距 8px                                        │
│  导航    │ ┌─────────────────────────────────────────────┐  │
│          │ │ Toolbar (上边距 8px, 无左右内间距)           │  │
│          │ │ ↓ 间距 8px                                  │  │
│          │ │ Table                                          │  │
│          │ │ Pagination (吸附底部, 40px, 顶部分割线 1px) │  │
│          │ └─────────────────────────────────────────────┘  │
│          │         ← 12px →                    ← 12px →     │
└──────────┴───────────────────────────────────────────────────┘
```

#### 页面结构：L 型导航（l-shaped）

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 顶部导航（Top Navigation，固定高度 56px）                            │
├────────────┬─────────────────────────────────────────────────────────┤
│ 左侧导航   │ 页面内容区                                              │
│            │ ┌─────────────────────────────────────────────────────┐ │
│            │ │ 页面标题/页头（Page Title，48px）                   │ │
│            │ ├─────────────────────────────────────────────────────┤ │
│            │ │ Toolbar                                                 │ │
│            │ │ ↓ 间距 8px                                                │ │
│            │ │ Table                                                   │ │
│            │ │ Pagination（吸附底部）                                        │ │
│            │ └─────────────────────────────────────────────────────┘ │
└────────────┴─────────────────────────────────────────────────────────┘
```

- `l-shaped` 下，顶部导航横向拉通；左侧导航位于顶部导航下方；页面标题和具体内容位于右侧页面内容区。组件信息不变。
- 工具栏（Toolbar）样式与排布规则参考 2.3 表格工具栏。
#### 组件信息

- 标题栏：基础标题栏，使用 `IxHeader`。
- 表格：使用 `IxProTable`。
- 分页：使用 `IxPagination`。

### 1.5 弹窗列表页

- 页面类型 ID：`page-list-modal`

用于在当前操作过程中临时查询并选择一项或多项已有数据，通常包含搜索、筛选、勾选和关闭操作，例如选择资产、选择用户、选择策略模板、选择通知对象和选择关联告警。

#### 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 Header                                                × │
│ 标题文字左对齐，关闭 icon 在右侧，距右边缘 16px              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                           Body 内容区                         │
│                                                              │
│  ┌───────────────────────────────────────────────────────┐   │
│  │ Toolbar                                               │   │
│  │ [按钮区]                    [选择器] [搜索框] [刷新]  │   │
│  │ ↓ 间距 8px                                            │   │
│  │ Table                                                 │   │
│  │ □ 名称       类型       状态       更新时间     操作   │   │
│  │ □ 示例对象A  设备       在线       2026-08-01   查看   │   │
│  │ □ 示例对象B  策略       启用       2026-08-02   查看   │   │
│  │ Pagination                                            │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                                                       [关闭] │
│                              Footer 按钮栏                    │
└──────────────────────────────────────────────────────────────┘
```

#### 组件信息

- 弹窗：使用 `IxModal`。
- 表格：使用 `IxProTable`。
- 分页：使用 `IxPagination`。

#### 内容区说明

- 内容区放置一个“工具栏 + 表格”结构，工具栏规则参考“2.3 表格工具栏”。
- 表格用于展示可查询、可选择或可查看的对象列表，可按场景决定是否展示勾选列。
- 弹窗列表页底部按钮通常只保留“关闭”，不使用主按钮和取消按钮组合。
- 数据量小（正常场景少于 20 个）的列表优先使用弹窗列表页；如果列表数据量较大（可达 20 个以上、几十或几百）、需要复杂筛选、长时间浏览或承载较多行内操作，优先改用抽屉列表页（判定见 [页面类型选择决策链](../03-patterns/01-navigation-and-hierarchy.md#25-页面类型选择决策链)）。

```text
│  │ Pagination                                            │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [上一个] [下一个] [关闭]                                      │

```

#### 组件信息

- 抽屉：使用 `IxDrawer`。
- 表格：使用 `IxProTable`。
- 分页：使用 `IxPagination`。

#### 内容区说明

- 内容区放置一个“工具栏 + 表格”结构，工具栏规则参考“2.3 表格工具栏”。
- 表格用于展示当前对象关联的数据列表，可支持筛选、搜索、分页、查看详情或简单行内操作。
- 抽屉列表页底部按钮通常只保留“关闭”，按钮左对齐排列，右侧不设置按钮位。
- 数据量较大（可达 20 个以上、几十或几百）的关联数据列表或字段展开列表优先使用抽屉列表页；数据量小（正常场景少于 20 个）的轻量列表优先使用弹窗列表页（判定见 [页面类型选择决策链](../03-patterns/01-navigation-and-hierarchy.md#25-页面类型选择决策链)）。

### 详情类

### 1.7 下钻详情页

- 页面类型 ID：`page-detail-drilldown`
- 默认导航类型：`left-shaped`
- 支持导航类型：`left-shaped`、`l-shaped`
- 导航影响：标题栏与内容卡片的组合方式不同。

用于承载单个对象的完整信息和深度分析，通常由列表或图表点击进入。展示详情时优先使用抽屉详情页，慎用完整下钻页面。只有当详情信息量很大、包含多个Tab或还需要继续下钻查看详情时，才采用下钻详情页。

- 标题栏：下钻页标题栏，使用 `IxHeader-prefix`。
- 描述列表：对象字段与只读详情使用 `IxProDesc`。
- Tab 标签页：详情内嵌 Tab 使用 `IxTabs`，`type="line"`。
- 表格：关联对象列表使用 `IxProTable`；存在分页时使用 `IxPagination`。

- 内容卡片承载概览卡片未覆盖的对象字段与关联信息，形式可以是描述列表（`IxProDesc`）、详情分区、表格、图表或关联列表。

#### 组件信息

- 抽屉：使用 `IxDrawer`。

- Tab 标签页：详情内嵌 Tab 使用 `IxTabs`，`type="line"`。
- 表格：关联对象列表使用 `IxProTable`；存在分页时使用 `IxPagination`。

#### 内容区说明

- 内容区参考抽屉列表页的容器结构，但不使用工具栏和表格作为默认主结构。
- 抽屉详情页应以“单对象详情概览卡片 + Tab页（可选）+ 内容卡片”的结构组织内容。
- 单对象详情概览卡片是独立卡片，与下方内容卡片之间保留 8px 间距。
- 单对象详情概览卡片的核心信息区分为两行：第一行是 14 号加粗的对象名称标题，第二行是辅助信息，例如设备类型、所属分组、地理位置。

- 顶部单对象详情概览卡片已展示的字段（含对象名称标题与辅助信息行字段），下方内容卡片的描述列表（`IxProDesc`）中不再重复展示；去重口径见 [2.1 单对象详情概览卡片](#21-单对象详情概览卡片)的“与下方详情的字段去重规则”。
- Footer 按钮栏通常只保留“关闭”，按钮左对齐排列。

### 配置类

#### 配置页容器选择规则

配置类能力不因对象名词（规则、策略、参数等）可列表化就套用列表类页面；仅当需求明确为维护多条同类对象（可枚举，含搜索、批量操作、新增/删除管理）时才使用列表类页面承载。单条配置类需求按以下规则选择表单容器：

表单容器按页面层级和配置复杂度选择：

| 需求识别信号 | 具体模板 |
| --- | --- |
| 配置任务识别为主页面；或配置项超过 20 项；或包含规则编辑器等复杂配置 | 页面表单页（[配置表单页](#110-配置表单页)） |
| 非主页面、配置项不超过 20 项且不包含规则编辑器等复杂配置 | 弹窗表单页（[弹窗表单页](#112-弹窗表单页)） |

- 判定优先级：用户明确要求 > 业务设计 Skill > 本规则；未命中上表任一信号时，默认使用弹窗表单页。
- 容器确定后，必须读取表单字段配置（字段组件与校验规则见 [../03-patterns/03-form-patterns.md](../03-patterns/03-form-patterns.md)）。复杂表单内部的信息分组、分区和局部 Tab 继续依据 [页面信息层级决策指南](../03-patterns/01-navigation-and-hierarchy.md#3-信息层级组织) 决定，不在页面模板中提前决定。
- 需要步骤条、分步校验、预览确认或多阶段提交的配置流程，使用 [下钻步骤条配置页](#111-下钻步骤条配置页)。
- 抽屉表单页默认不使用，仅在用户额外说明或业务设计（product design）特别说明使用抽屉承载时才使用（见 [1.13 抽屉表单页](#113-抽屉表单页)）。

- 步骤条默认是横向步骤条；如果有特殊说明需要纵向步骤条，则纵向步骤条默认位于页面内容区左侧。
- 下钻步骤条配置页属于同一页面内的内容切换，步骤间切换时保留页面外壳与公共区域，不要拆成独立页面。
- 同一页面多个步骤时，HTML 线框图按“1 张主结构图 + 每个步骤 1 张完整变体图”绘制。

### 1.14 Dashboard

## 2. 页面元素说明

页面元素说明用于补充页面类型中的通用部件布局。生成页面内容描述和线框图时，优先复用本节规则。

### 2.1 单对象详情概览卡片

单对象详情概览卡片用于承载一个对象的身份识别、核心状态和快捷操作，常用于下钻详情页、抽屉详情页等对象详情场景，默认使用 `IxCard`，结构如下：

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [图标]  设备名称 AF-1000                                      [启用][编辑][更多▼] │
│         设备类型 AF   所属分组 广州办事处   地理位置 广东省/广州市/番禺区          │
└──────────────────────────────────────────────────────────────────────────────┘
```

结构规则：

- 左侧为对象图标；中间为核心信息区，两行合并展示在卡片主体内：第一行是 14 号加粗对象名称标题，第二行是辅助信息、分类标签、归属范围或地理位置等摘要信息。
- 右侧为操作按钮，通常放 1 个主按钮 + 1 个普通按钮；如果还有其他按钮，则第三个按钮使用“更多”按钮，点击后以下拉形式展示其他按钮。
- 单对象详情概览卡片应作为独立卡片使用；当下方还有内容卡片时，两者之间固定 8px 间距。

#### 与下方详情的字段去重规则

概览卡片承载对象身份与摘要字段，下方内容卡片不再重复展示同一字段，避免同一信息在页面上出现两次。

- 已展示字段识别：概览卡片中出现的所有字段都视为已展示，包含第一行对象名称标题、第二行辅助信息字段（如设备类型、所属分组、地理位置）以及右侧操作区已表达的状态或动作。
- 去重范围：下方描述列表（`IxProDesc`）、详情分区、Tab 内内容、关联表格列都必须剔除已展示字段，不重复出现。
- 判定口径：按字段语义判定，不只看字段名是否完全一致；例如概览卡片已展示“所属分组”，下方详情的“分组”“归属分组”等同义字段同样不再展示。
- 只去重不丢信息：概览卡片未展示的字段必须完整保留在下方内容卡片中，不得因为去重而遗漏字段。
- 字段分配：辅助信息行只放最关键的摘要字段，其余字段下沉到下方详情；同一字段在详情中还有更细粒度内容（如明细、变更记录）时，只在详情承载该明细，不重复字段标题。
- 取值一致性：概览卡片与下方详情对同一字段的取值必须一致，不出现两处同名不同值的情况。

### 2.2 页面标题栏

页面标题栏根据页面进入方式和页面层级选择对应结构。

#### 基础标题栏

适用于一级导航页面、普通列表页、普通配置页、普通详情页。

结构：`[页面标题]`

#### 下钻页标题栏

适用于从列表、详情、对象卡片、按钮入口进入的二级或三级页面。

结构：`[返回入口] [页面标题]`

要求：

- 返回入口位于标题左侧。
- 页面标题表达当前对象或当前任务。
- 返回入口回到上一级页面或来源页面。

#### 分层 Tabs 页标题

适用于页面标题下存在同级Tab分区的页面。

结构：`[页面标题] [纵向分割线] [Tab1] [Tab2]`

要求：

- 页面标题、纵向分割线和Tab在同一行展示完整。
- 分割线为纵向分割线，用于分隔页面标题与Tab组。
- 分层 Tabs 页标题中的Tab必须作为标题栏的一部分展示，不得下沉为内容区Tab。
- Tab行不是内容区的一部分。
- 如果同一页面还有多个内容切换Tab，HTML线框图应先绘制1张页面主结构图，再为每个Tab绘制1张对应的完整页面变体图；每张变体图必须保留相同的页面外壳、标题栏和公共区域，只允许当前Tab对应的内容区块发生变化。
- 如果同一页面同时存在步骤条等内容切换控件，也按同样方式处理：先绘制1张页面主结构图，再按每个步骤绘制1张完整页面变体图；步骤条与内容区属于同一个页面的内容切换，不要画成独立页面。
- 变体图中的不变区域应与主图保持一致，不要重新发散绘制。
- Tab下方内容区是独立容器。
- 不要把Tab写成标题右侧操作。

### 2.3 表格工具栏

表格工具栏用于承载表格上方的新增、批量操作、筛选、搜索、刷新等操作。适用于基础表格页、左树表格页、概览表格页、概览左树表格页，以及弹窗列表页、抽屉列表页中的表格区域。

#### 结构

Toolbar 由按钮区与搜索筛选区组合而成，按筛选与搜索项数量分为 3 种结构：

**结构一：筛选与搜索项在 4 个及 4 个以内（单行平铺）**

```text
┌──────────────────────────────────────────────────────────────────────┐
│ [按钮区]                               [搜索筛选区]                │
│  主按钮 普通按钮 ... 更多▼      [复合日期] [选择器] [搜索框] [刷新icon按钮] │
└──────────────────────────────────────────────────────────────────────┘
```

- 组件平铺排布，顺序为：复合日期、选择器、搜索框、刷新 icon 按钮。

**结构二：筛选与搜索项超过 4 个（单行高级搜索）**

```text
┌──────────────────────────────────────────────────────────────────────┐
│ [按钮区]                                    [高级搜索] [刷新 icon]  │
│  主按钮 普通按钮 ... 更多▼                                            │
└──────────────────────────────────────────────────────────────────────┘
```

- 默认右侧只有一个高级搜索框和刷新 icon 按钮。

**结构三：高级搜索内筛选与搜索项合计 10 个及以上（两行）**

```text
┌──────────────────────────────────────────────────────────────────────┐
│ [高级搜索框（单独一行）]                                              │
├──────────────────────────────────────────────────────────────────────┤
│ [按钮区]                                               [刷新icon按钮] │
│  主按钮 普通按钮 ... 更多▼                                            │
└──────────────────────────────────────────────────────────────────────┘
```

- 高级搜索框单独一行，置于按钮区上方。

#### 布局规则

- 左侧为按钮区，优先放主按钮、普通按钮、批量操作和更多操作。
- 左侧按钮数量最多 7 个，超过 7 个时将低频按钮收纳到“更多”按钮中。
- 右侧为搜索筛选区，用于承载筛选与检索条件。
- 搜索筛选区组件排序顺序依次为：复合日期筛选器、选择器、搜索框；日期筛选器使用 `IxDatePicker`。
- 当筛选和搜索项数量在 4 个及 4 个以内时，优先平铺为单个筛选条件，不使用高级搜索。
- 当筛选和搜索项数量超过 4 个时，改用 idux 高级搜索组件，默认右侧只保留一个高级搜索框和刷新 icon 按钮。
- 高级搜索组件的视觉样式可视为一个搜索框，内部集成多个条件筛选与搜索能力。
- 当高级搜索内的筛选和搜索项合计达到 10 个及以上时，高级搜索框单独一行置于按钮区上方，Toolbar 为两行高度。
- 结构一与结构二严格保持单行，不换行。
- 当同时存在按钮区和搜索筛选区时，按钮区靠左，搜索筛选区靠右，中间留出弹性空白。
- 搜索框通常靠近刷新入口；刷新入口通常位于最右侧。
- 表格工具栏属于表格区的一部分，不要单独拆成独立页面区块。
