## 1. 定位与适用范围

- 本文是跨页面类型的通用状态设计总纲，覆盖列表、详情、配置、弹窗、抽屉、概览等页面类型的状态设计。
- 表格场景的状态细则见 [02-table-patterns.md](02-table-patterns.md) 第 12 节，表单场景的状态细则见 [03-form-patterns.md](03-form-patterns.md) 第 10 节。本文只做通用定义与衔接，不重复场景细节。
- 状态组件的实现能力以 idux 组件库为准，业务组件选型映射见 [../05-components/idux-component-map.md](../05-components/idux-component-map.md)。
- 状态说明文案与术语须与 [06-copywriting-terminology.md](06-copywriting-terminology.md) 保持一致。

## 2. 状态全景清单

设计任何页面时，先按下表核对需要覆盖的状态。触发场景命中即按"默认展示方式"落地，并给出用户可执行动作。

| 状态类型 | 触发场景 | 默认展示方式 | 用户可执行动作 |
| --- | --- | --- | --- |
| 加载中 | 首次打开、查询、刷新、提交处理中 | 骨架屏或 Spin | 等待或取消 |
| 空状态 | 初始无数据 | 引导创建、导入或配置 | 创建、导入、配置 |
| 搜索无结果 | 搜索无匹配 | 未找到匹配结果 + 清空搜索入口 | 清空或调整搜索 |
| 筛选无结果 | 筛选无匹配 | 当前筛选无结果 + 重置筛选入口 | 重置筛选 |
| 错误 | 查询或操作失败 | 错误提示 + 重试入口 | 重试或返回 |
| 无权限 | 无查看或操作权限 | 隐藏，或禁用并说明原因 | 申请权限或返回 |
| 提交中 | 保存处理中 | 按钮 loading，防重复提交 | 等待 |
| 提交成功 | 保存成功 | 轻提示，或结果反馈 | 继续或关闭 |
| 提交失败 | 保存失败 | 失败原因 + 重试入口 | 修改后重试 |
| 禁用 | 不可编辑或不可操作 | 禁用态并说明原因 | 无，或了解原因 |
| 只读 | 查看或受限场景 | 可读展示，不保留不可用控件 | 无 |
| 数据过期 | 数据已变更失效 | 提示刷新，或自动回到有效页 | 刷新 |

## 3. 加载态

- 首次加载页面或模块时，优先使用骨架屏，其次使用 Spin；详情、弹窗初始化可用内容区骨架或 Spin。
- 查询、搜索、筛选、排序、分页切换时保留表格结构或已有内容，仅对变化区域反馈加载，避免整页闪动（衔接 [02-table-patterns.md](02-table-patterns.md) 12.1）。
- 手动刷新期间保留已有数据，避免闪空。
- 局部字段或模块加载失败时，保留行数据并在该位置展示失败或空值说明，避免整体不可用。
- 提交处理中按钮进入 loading 并禁止重复点击，同时禁用关联操作（衔接 [03-form-patterns.md](03-form-patterns.md) 第 10 节保存中）。
- 预计耗时极短（300ms 以内）的操作使用轻量反馈或无需反馈，避免加载态闪烁。

## 4. 空状态

- 初始无数据时，展示创建、导入、配置或接入引导入口（衔接 [02-table-patterns.md](02-table-patterns.md) 12.2）。
- 搜索无结果时，展示"未找到匹配结果"，并提供清空搜索或调整筛选入口。
- 筛选无结果时，说明当前筛选条件导致无结果，并提供重置筛选入口。
- 左树或范围为空时，说明当前范围没有数据，而不是全局没有数据。
- 无权限导致数据为空时，提示权限范围限制，不引导创建数据。
- 空状态由图形或图标、说明文案、操作按钮组成；操作按钮按场景可选，文案写法见 [06-copywriting-terminology.md](06-copywriting-terminology.md)。
- 空状态必须有出口：不能只展示"暂无数据"而没有下一步动作，除非确实无动作可做。

## 5. 错误与异常态

- 查询失败时保留当前查询条件，提供重试入口，不重置页面（衔接 [02-table-patterns.md](02-table-patterns.md) 12.3）。
- 分页请求失败时不得清空已有查询状态。
- 局部字段或模块加载失败时，保留已有内容并在该位置展示失败说明与重试，不整页降级。
- 错误分级展示：
  - 整页不可用（页面级崩溃或无数据源）：使用 Result 页或整页错误态，提供重试。
  - 局部模块失败：使用模块内 Alert 或内嵌提示，提供重试。
  - 单次操作失败：使用 message 或 notification 轻提示，展示失败原因。
- 失败原因优先使用接口返回；原因可操作时使用可操作语言，例如"请检查网络后重试"，避免只写"操作失败"。
- 批量操作失败必须展示失败明细与原因，部分对象失败时逐项说明（衔接 [02-table-patterns.md](02-table-patterns.md) 12.3、12.4）。
- 当前页因数据变化失效时，自动回到最后有效页。

## 6. 无权限态

- 无权限查看的数据字段不展示，不占位。
- 页面级无权限：页面、菜单、入口隐藏，用户不可见，无法进入该页面。
- 操作级无权限：按钮正常展示、可点击，点击后提示"暂无权限"，不隐藏、不禁用；需要引导时可弹窗"暂无权限，如需使用请联系管理员"。
- 批量操作中部分对象无权限：自动跳过无权限对象，其余对象继续执行，执行结果必须展示无权限对象及原因。
- 行操作与批量操作的权限判断必须一致；操作按钮的权限判断与页面数据权限保持一致。
- 表单字段因权限不可编辑时，禁用并说明原因，或转为只读展示（衔接 [03-form-patterns.md](03-form-patterns.md) 第 10 节禁用态、只读态）。

## 7. 操作过程状态

- 提交中：按钮进入 loading，防止重复提交，同时禁用关联操作。
- 提交成功：默认使用轻提示；高影响操作或需要引导下一步时使用 Result 或跳转，避免过度反馈。
- 提交失败：展示失败原因与可操作入口（修改后重试、重新提交）；分步表单须能定位到具体步骤和字段（衔接 [03-form-patterns.md](03-form-patterns.md) 第 9 节、第 10 节）。
- 提交成功后：关闭弹窗或抽屉并刷新来源数据，或回写详情；离开前处理未保存提醒。
- 高风险操作（删除、下线、权限变更、策略生效等）先二次确认，再进入提交中状态。

## 8. 状态组件选择

按状态场景选择组件，组件具体能力与参数以 idux 组件库为准；业务组件选型映射见 [../05-components/idux-component-map.md](../05-components/idux-component-map.md)。

| 状态场景 | 推荐组件 | 说明 |
| --- | --- | --- |
| 整页加载 | IxSkeleton 或 IxSpin | 首次加载优先骨架屏 |
| 局部加载 | IxSpin | 包裹局部变化区域 |
| 空状态 | IxEmpty | 自定义插槽承载图形、文案与操作按钮 |
| 整页错误 | IxResult | status 使用 error，配合重试按钮 |
| 无权限整页 | IxResult | 403 语义，或空态 + 权限说明 |
| 局部错误或告警 | IxAlert | error、warning 类型 |
| 轻提示 | IxMessage | 单次操作反馈 |
| 通知类 | IxNotification | 需要持久或批量通知时 |
| 状态标记 | IxTag、IxBadge | 状态色须使用组件预设语义，不手写颜色 |
| 解释说明 | IxTooltip、IxPopover | 补充原因或操作说明 |

## 9. 状态组合与切换

- 状态转换顺序：加载中 → 数据、空、错误或无权限；加载完成后只呈现一种终态。
- 刷新与重试：保留当前查询条件、分页、筛选与滚动位置，重试不重置页面。
- 多状态叠加时的优先级：错误 > 无权限 > 空 > 数据；局部状态与全局状态并存时，局部状态不得掩盖全局错误。
- 无权限与空叠加时，优先展示无权限原因，不展示空态引导。
- 禁用与只读叠加时，只读优先于禁用展示；禁用须说明原因。
- 弹窗、抽屉关闭后恢复来源页状态（筛选、分页、滚动、选中），不重置来源页。
- 返回列表时恢复搜索、筛选、排序、页码、左树范围与纵向滚动位置（衔接 [02-table-patterns.md](02-table-patterns.md) 第 13 节）。

## 10. 状态文案规范

- 状态说明使用客观、可操作的短句：说明现状 + 原因（如已知）+ 下一步动作。
- 空状态文案：说明"当前没有 X"并引导"创建、导入或配置 X"；无动作时说明原因而非只写"暂无数据"。
- 错误文案：说明失败对象与原因，给出重试或返回动作；使用可操作语言，避免仅写"操作失败"。
- 无权限文案：说明权限限制，提供申请或联系管理员入口。
- 禁用文案：说明禁用原因（权限、依赖、策略锁定），不只用 tooltip 兜底。
- 状态标记文案与全局术语保持一致，同一业务状态全局不得出现不同文案（衔接 [06-copywriting-terminology.md](06-copywriting-terminology.md)）。

## 11. 自检清单

- 是否覆盖加载、空、搜索无结果、筛选无结果、错误、无权限、提交中、提交成功、提交失败、禁用、只读状态。
- 空状态是否有下一步动作出口。
- 错误后是否保留已有数据与查询条件，并可重试。
- 提交中是否防重复提交，提交成功后是否刷新来源数据。
- 无权限是否按页面级隐藏、操作级点击提示"暂无权限"处理，行级与批量权限是否一致。
- 状态组件是否使用 idux 组件（Skeleton、Spin、Empty、Result、Alert、Message、Notification、Tag、Badge）。
- 状态文案是否与全局术语一致。
- 弹窗、抽屉关闭与返回列表时是否恢复来源页状态。
