# P-05 多维下钻联动排障范式 (Drill-down Correlation Pattern)

> 💡 **范式定位**：从宏观大盘一路下钻到微观明细，用**三级联动**把“指标异常 → 受影响对象 → 根因日志”串成可信任的因果链。
> 📂 **资产类别**：专家范式（机制库） · `03-design-assets/patterns/`　|　🔗 索引：[patterns-cheatsheet.md](patterns-cheatsheet.md)

---

## 1. 适用场景与业务本质 (JTBD)

| 维度 | 说明 |
| :--- | :--- |
| **业务本质** | 数据分散在多处，用户难以建立“什么导致了什么”的因果链 |
| **典型场景** | 监控大盘下钻排障、调用链追踪、多维资源影响面分析 |
| **适用产品线** | 云原生网络线（极高严肃度） |
| **不适用** | 单一维度的简单查询（普通表格筛选即可） |

---

## 2. 核心解题机制

* **三级联动**：上层（时间轴/大盘）框选 ➔ 中层（拓扑/图表）高亮 ➔ 下层（明细表）过滤；
* **上下文透传**：上层选择自动同步为下层筛选模型，并重置分页；
* **联动生效提示条**：明确告知“当前已联动过滤：X · 共 N 条”，并提供一键清除。

---

## 3. 结构骨架

```text
┌ 第一级：时间轴 / KPI 大盘 ──── 框选异常时间范围 ─────┐
│                       ▼ 联动                        │
├ 第二级：拓扑 / 趋势图 ──── 受波及对象高亮呼吸 ────────┤
│                       ▼ 联动                        │
├ 第三级：明细表 ──── 自动过滤为该对象的近端日志/调用链 ─┤
│  [当前已联动过滤：深圳POP · 共 3 条]        [清除 ×]  │
└────────────────────────────────────────────────────┘
```

---

## 4. 交互闭环关键点

* 每级选择都必须**就地**改变下一级，不新开页面；
* 联动提示条清晰可清除，避免“筛没了不知道为什么”；
* 上层改动需重置下层分页，防止空页错觉。

---

## 5. 常见发力方向（方向级，供步骤 2 挂靠）

| 发力方向 | 体验维度 |
| :--- | :--- |
| 让用户顺着一条因果链一路看清根因 | 可解释 / 信任感 |
| 让下钻全程不跳出当前上下文 | 低摩擦 / 最简闭环 |

## 7. 反模式与禁忌

* 🛑 严禁“点一下跳一个新页面”式下钻，破坏上下文；
* 🛑 严禁只给黑盒结论，必须同步呈现联动依据；
* 🛑 严禁联动过滤后不给生效提示与清除入口。
