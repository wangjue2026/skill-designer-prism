# P-02 KPI 四联驾驶舱范式 (KPI Cockpit Pattern)

> 💡 **范式定位**：用 4 联关键指标卡让用户**秒级感知全局健康度**，并带环比趋势与告警脉冲。
> 📂 **资产类别**：专家范式（机制库） · `03-design-assets/patterns/`　|　🔗 索引：[patterns-cheatsheet.md](patterns-cheatsheet.md)

---

## 1. 适用场景与业务本质 (JTBD)

| 维度 | 说明 |
| :--- | :--- |
| **业务本质** | 需要在页面顶部一屏内感知 3~5 个核心指标的健康度与变化趋势 |
| **典型场景** | 监控大盘、成本/流量总览、SLA 达标概览、告警态势 |
| **适用产品线** | 云原生网络线 / 计费运营线 |
| **不适用** | 需要精确逐行核对明细的场景（应下钻到 P-05 + 表格） |

---

## 2. 核心解题机制

* **4 联栅格**：固定 4 列平铺，指标之间**同权同级**，避免大小不一干扰扫描；
* **主数值 + 环比趋势**：主数值用等宽数字字体，配“较上期 ↑/↓ 百分比”胶囊；
* **状态脉冲圆点**：健康用一个脉冲点表达（正常绿 / 告警红），不做大面积染色。

---

## 4. 交互闭环关键点

* 卡片底部用细分隔线承载趋势行，主次层级清晰；
* 主数值与单位之间留半角空格（如 `68 ms`）；
* 点击卡片可就地联动下方明细（配合 P-05），不做无意义跳转。

---

## 5. 常见发力方向（方向级，供步骤 2 挂靠）

| 发力方向 | 体验维度 |
| :--- | :--- |
| 让全局健康度一屏看清、无需下钻 | 可见性 / 掌控感 |
| 让“变好还是变坏”一眼可判 | 可解释 / 专业 |

## 7. 反模式与禁忌

* 🛑 严禁大面积纯红/纯绿卡片底色，只允许浅底 + 深字 + 脉冲点；
* 🛑 严禁指标卡数量随意扩张到 6 张以上导致视线发散；
* 🛑 严禁只有静态绝对值、缺少同环比趋势。
