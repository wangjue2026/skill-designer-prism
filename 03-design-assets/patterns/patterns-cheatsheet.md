## 二、按「要解决的业务本质」反查

| 你要解决的问题 | 推荐范式 |
| :--- | :--- |
| 资源链路相互依赖，要定位哪条线坏了 | **P-01**（常配 P-05 联动） |
| 要一屏感知全局核心指标健康度 | **P-02** |
| 要在时间轴上找异常尖刺 / 拐点 / 阈值越界 | **P-03** |
| 高风险、多前置条件的配置，怕配错 | **P-04** |
| 要从大盘一路下钻到明细日志，形成因果链 | **P-05** |
| 同源条目太多、散落，需归拢后批量处理 | **P-06** |
| 要看某个对象从创建到销毁的状态演进 | **P-07** |
| 要还原攻击链并完成处置闭环 | **P-08** |

## 三、常用组合套路（范式常成对出现）

| 组合 | 典型用途 |
| :--- | :--- |
| **P-02 + P-05** | 大盘定界 → 下钻联动明细（监控排障主链路） |
| **P-01 + P-05** | 拓扑定位 → 关联表格/日志联动过滤 |
| **P-03 + P-01** | 时间切片定位异常时刻 → 穿越到该时刻拓扑 |
| **P-06 + P-04** | 同源聚合 → 批量配额划拨与防呆下发 |
| **P-08 + P-03** | 攻击链阶段还原 → 事发时段时序回放 |

```mermaid
graph LR
    D["步骤 2 产出<br>设计发力方向（L1）"] --> Q["本表检索<br>（按业务本质反查 / 索引）"]
```

## 五、维护规则

1. **编号顺延**：新增范式编号顺延（P-09、P-10…），不得复用或跳号改写旧号；
2. **单文件承载**：每个范式一个 `pattern-pXX-*.md`，本表只做索引，不复制机制细节；
3. **字段一致**：每个范式文件须包含——适用场景与业务本质、核心解题机制、结构骨架、交互闭环关键点、常见发力方向、关联资产、反模式与禁忌；
4. **资产归口**：所有设计资产（范式 / 组件 / 套头 / Tokens）统一存放于 `03-design-assets/`；思考类文档（步骤 2 等）**只做引用，不内嵌资产明细**。
