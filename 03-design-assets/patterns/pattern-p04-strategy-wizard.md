# P-04 复杂策略分步向导范式 (Strategy Wizard Pattern)

> 💡 **范式定位**：面向高风险、多前置条件的配置，用**分步向导 + 实时配额防呆**把“配错就出事”变成“配不错”。
> 📂 **资产类别**：专家范式（机制库） · `03-design-assets/patterns/`　|　🔗 索引：[patterns-cheatsheet.md](patterns-cheatsheet.md)

---

## 1. 适用场景与业务本质 (JTBD)

| 维度 | 说明 |
| :--- | :--- |
| **业务本质** | 配置存在多前置条件、互斥规则与配额上限，误操作代价高 |
| **典型场景** | WAF 规则编排、BGP 路由划拨、安全拦截策略、开通/导入向导 |
| **适用产品线** | 策略与业务配置类（高严肃度） |
| **不适用** | 单步、低风险的即时开关（用普通表单即可） |

---

## 2. 核心解题机制

* **步骤进度条**：把复杂配置拆成可回退的若干步，降低单屏认知负荷；
* **动态表单联动**：后置字段随前置选择动态显隐/校验，实时互斥提示；
* **实时配额防呆**：下发前试算配额，超限红色拦截并给出调整建议。

---

## 3. 结构骨架

```text
┌─ ① 基本信息 ─② 规则条件 ─③ 生效范围 ─④ 确认下发 ─┐   ← 步骤指示器
├────────────────────────────────────────────────┤
│  当前步骤表单区（动态联动）                        │
│  ┌── 配额试算 ──────────────────────────────┐    │
│  │ 变更前 70% ──▶ 变更后 92%   [未超限 ✓]     │    │
│  └──────────────────────────────────────────┘    │
├────────────────────────────────────────────────┤
│         [上一步]        [下一步]  [保存并下发]     │   ← 固定底栏
└────────────────────────────────────────────────┘
```

---

## 4. 交互闭环关键点

* 底栏操作按钮受状态机约束（校验未过则禁用并挂 Tooltip）；
* 变更前后配额对比以双轴方式呈现，超限即红；
* 高危下发做二次确认，保留可回滚快照。

---

## 5. 常见发力方向（方向级，供步骤 2 挂靠）

| 发力方向 | 体验维度 |
| :--- | :--- |
| 让变更前就能预知影响与是否超限 | 防呆确定性 / 稳 |
| 让复杂配置可拆解、可回退、不卡壳 | 简单 / 低摩擦 |

## 7. 反模式与禁忌

* 🛑 严禁把所有条件堆在一屏长表单里让用户自己找；
* 🛑 严禁高危提交无二次确认、无配额试算；
* 🛑 严禁用复杂审批/频繁打断包装成“体验目标”。
