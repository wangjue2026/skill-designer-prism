# P-07 对象全生命周期巡检范式 (Lifecycle Inspection Pattern)

> 💡 **范式定位**：沿状态流转轴展示关键对象从创建到销毁的演进，并用巡检 Checklist 与一键自愈闭环健康检查。
> 📂 **资产类别**：专家范式（机制库） · `03-design-assets/patterns/`　|　🔗 索引：[patterns-cheatsheet.md](patterns-cheatsheet.md)

---

## 1. 适用场景与业务本质 (JTBD)

| 维度 | 说明 |
| :--- | :--- |
| **业务本质** | 需要跟踪某业务对象的状态演进，并周期性核验其健康与合规 |
| **典型场景** | 云主机/容器生命周期、证书有效期巡检、配置合规检查、设备上架到下线 |
| **适用产品线** | 计算与存储基础设施 / 对象管理类（中） |
| **不适用** | 无状态演进、仅一次性查询的场景 |

---

## 2. 核心解题机制

* **状态流转轴**：以横向时间轴展示对象各生命周期阶段与当前所处阶段；
* **巡检 Checklist**：把健康/合规检查项逐条列出，标出通过/未通过；
* **一键自愈**：针对可自动修复的检查项提供就地修复入口。

---

## 3. 结构骨架

```text
创建 ✓ ── 初始化 ✓ ── 运行中 ●（当前）── 检修 ○ ── 下线 ○
──────────────────────────────────────────────────────
巡检项                                   状态      操作
· 证书有效期 ≥ 30 天                     ⚠ 剩余 12 天  [续期]
· 配置基线合规                           ✓ 通过       —
· 资源水位 < 80%                         ✗ 92%        [扩容]
```

---

## 4. 交互闭环关键点

* 当前阶段高亮，已过/未到阶段视觉降阶；
* 未通过项按严重度用状态三元组标注，并提供就地修复；
* 自愈动作需可追踪、可回滚。

---

## 5. 常见发力方向（方向级，供步骤 2 挂靠）

| 发力方向 | 体验维度 |
| :--- | :--- |
| 让对象当前状态与历经阶段一眼看清 | 可见性 / 掌控感 |
| 让可自愈问题就地闭环、免去人工排查 | 省 / 响应闭环 |

## 7. 反模式与禁忌

* 🛑 严禁只给一个静态状态标签，看不出演进过程；
* 🛑 严禁巡检项只报“异常”不给修复入口与依据；
* 🛑 严禁自愈动作不可追踪、不可回滚。
