# P-06 同源条目聚合管理范式 (Same-Source Aggregation Pattern)

> 💡 **范式定位**：把同源/同地域的海量散落条目**归拢为聚合大卡片**，支持一键全选或差异化配置，防漏配、防超配额。
> 📂 **资产类别**：专家范式（机制库） · `03-design-assets/patterns/`　|　🔗 索引：[patterns-cheatsheet.md](patterns-cheatsheet.md)

---

## 1. 适用场景与业务本质 (JTBD)

| 维度 | 说明 |
| :--- | :--- |
| **业务本质** | 同一来源/地域的条目过多且散落，逐条配置易漏项、易超限 |
| **典型场景** | 分支/地域批量下发、同源告警聚合降噪、多租户同名资源归拢 |
| **适用产品线** | 对象与资源管理类 / 配置类（中~高） |
| **不适用** | 条目之间无同源关系、需逐条独立处理（用普通列表） |

---

## 2. 核心解题机制

* **聚合主卡片**：同源条目归拢为一个父卡片，展示汇总态（如累积脉冲数）；
* **子项折叠面板**：展开后按需查看/勾选子项，支持一键全选；
* **批量配额划拨**：父级统一配置，下发前做配额试算（配合 P-04）。

---

## 3. 结构骨架

```text
┌ ▸ 源站 A · 共 12 条分支      [累积告警 34]   [全选 ✓] ┐
│   ├ 分支 a1   ● 正常                                  │
│   ├ 分支 a2   ⚠ 告警 12                               │
│   └ 分支 a3   ⚠ 告警 22                               │
└──────────────────────────────────────────────────────┘
┌ ▸ 源站 B · 共 8 条分支       [累积告警 3]    [全选  ] ┐
└──────────────────────────────────────────────────────┘
```

---

## 4. 交互闭环关键点

* 父级全选与子项勾选双向联动，父子状态一致；
* 支持“父级统一配置 + 子项差异化覆盖”；
* 聚合卡片的汇总数值须可下钻查看来源，避免黑盒。

---

## 5. 常见发力方向（方向级，供步骤 2 挂靠）

| 发力方向 | 体验维度 |
| :--- | :--- |
| 让海量同源条目一眼看清整体态势 | 降噪 / 聚焦 |
| 让批量处理不漏项、不超限 | 防呆确定性 / 省 |

## 7. 反模式与禁忌

* 🛑 严禁把同源条目平铺成长列表，让用户自己去数；
* 🛑 严禁父级汇总数值无下钻来源（黑盒聚合）；
* 🛑 严禁批量下发不做配额试算。
