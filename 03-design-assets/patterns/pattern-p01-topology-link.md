# P-01 端到端拓扑链路范式 (End-to-End Topology Link Pattern)

> 💡 **范式定位**：面向网状/链状资源依赖排障，用一张可交互拓扑讲清“谁连谁、哪条线坏了、影响面多大”。
> 📂 **资产类别**：专家范式（机制库） · `03-design-assets/patterns/`　|　🔗 索引：[patterns-cheatsheet.md](patterns-cheatsheet.md)

---

## 1. 适用场景与业务本质 (JTBD)

| 维度 | 说明 |
| :--- | :--- |
| **业务本质** | 资源之间存在拓扑/链路依赖，用户需要定位异常链路与影响范围 |
| **典型场景** | 云网络跨地域链路、VPC/专线互联、集群依赖拓扑、服务调用链 |
| **适用产品线** | 云原生网络线（极高严肃度） |
| **不适用** | 无依赖关系的平铺对象清单（改用 P-06 / P-07） |

---

## 2. 核心解题机制

* **虚拟聚合节点**：同源/同类节点先归拢为聚合节点，防止节点爆炸；
* **连线状态流**：以连线的颜色与粗细表达链路健康度与流量大小；
* **图内就地展开 (In-situ)**：点击节点/连线在画布内展开详情，不跳页、不断流。

---

## 3. 结构骨架

```text
┌──────────────────── 拓扑画布 ────────────────────┐
│  [聚合节点 A] ──⚠── [聚合节点 B] ──✓── [节点 C]      │
│        │（虚线胶囊：就地展开控制器）                 │
│   ┌───────────────┐                             │
│   │ 就地详情 / 证据 │                             │
│   └───────────────┘                             │
└────────────────────────────────────────────────┘
```

---

## 4. 交互闭环关键点

* 点击节点施加高亮外框，非关联对象降透明度（视线锚定）；
* 展开/收起控制器（虚线胶囊）就地嵌在拓扑内，**仅控制展开态，不触发下钻或开抽屉**；
* 拓扑状态需与外部指标/表格联动（配合 P-05），避免成为孤岛。

---

## 5. 常见发力方向（方向级，供步骤 2 挂靠）

| 发力方向 | 体验维度 |
| :--- | :--- |
| 让故障点与影响范围一眼清晰可见 | 可见性 / 掌控感 |
| 让排障不脱离上下游上下文 | 低摩擦 / 最简闭环 |

## 7. 反模式与禁忌

* 🛑 严禁花哨 3D 拓扑与纯装饰性连线；
* 🛑 严禁节点不做聚合导致图面爆炸；
* 🛑 严禁点击节点跳转到独立新页面，破坏排障上下文。
