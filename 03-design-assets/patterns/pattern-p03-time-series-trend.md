# P-03 时间切片趋势图范式 (Time-Series Trend Pattern)

> 💡 **范式定位**：在时间轴上呈现指标连续波动，**高亮异常尖刺与离群点**，并用阈值区间给出“正常/一般/差”的标尺。
> 📂 **资产类别**：专家范式（机制库） · `03-design-assets/patterns/`　|　🔗 索引：[patterns-cheatsheet.md](patterns-cheatsheet.md)

---

## 1. 适用场景与业务本质 (JTBD)

| 维度 | 说明 |
| :--- | :--- |
| **业务本质** | 离散切片看不出趋势，用户需要连续波动、拐点与阈值越界 |
| **典型场景** | 链路时延/丢包趋势、访问质量时间线、成本走势、SLA 波动 |
| **适用产品线** | 云网络 / 计费运营线 |
| **不适用** | 只有分类对比、无时序意义的数据（改用报表对比） |

---

## 2. 核心解题机制

* **双轴时序趋势**：折线/散点表达连续波动，取代离散色块方块；
* **阈值分界区间**：以柔和的绿/黄/红三段背景区间标明健康度标尺；
* **异常离群点高亮**：越界点重点标记（含呼吸外环），其余正常连线降噪。

---

## 3. 结构骨架

```text
 y↑ ┌──────────────────────────────────────┐
    │ 差区间    (<60分)      ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
    │ 一般区间  (60~85分)    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
    │ 正常区间  (>85分)      ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
    │      ·——·——●——·——·——◉——·——·——·        │
    └──────────────────────────────────────→ t
        00:00      08:00      16:00      24:00
                    （◉ = 异常离群点，带呼吸环）
```

---

## 4. 交互闭环关键点

* 折线可虚线连接、正常点实体圆点，异常点额外加外环与 Hover 放大；
* Hover 浮出深色 Tooltip：时间 + 健康度评级 + 具体耗时；
* 点击异常点可穿越到该时刻的拓扑/日志（配合 P-01 / P-05）。

---

## 5. 常见发力方向（方向级，供步骤 2 挂靠）

| 发力方向 | 体验维度 |
| :--- | :--- |
| 让异常时刻在趋势中自动浮现、不被淹没 | 降噪 / 聚焦 |
| 让用户知道“什么算正常”，不再凭感觉判断 | 可解释 / 信任感 |

## 7. 反模式与禁忌

* 🛑 严禁折线过密变成“刷子”，必须做 Top N / 离群过滤；
* 🛑 严禁只给数值不给基线/阈值标尺，用户无法判断好坏；
* 🛑 严禁用高饱和纯色大面积铺底。
