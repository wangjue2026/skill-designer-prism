# P-08 安全事件调查与研判范式 (Security Investigation Pattern)

> 💡 **范式定位**：以攻击链阶段时间轴 + 实体关联还原攻击路径，用可复核的证据链支撑研判与处置闭环。
> 📂 **资产类别**：专家范式（机制库） · `03-design-assets/patterns/`　|　🔗 索引：[patterns-cheatsheet.md](patterns-cheatsheet.md)

---

## 1. 适用场景与业务本质 (JTBD)

| 维度 | 说明 |
| :--- | :--- |
| **业务本质** | 需要还原攻击者行为序列、定位影响实体，并给出可采信的处置依据 |
| **典型场景** | 安全事件调查、攻击溯源、威胁狩猎、告警研判与闭环处置 |
| **适用产品线** | 云安全与合规线（极高严肃度） |
| **不适用** | 无攻击语义的普通运维事件（改用 P-01 / P-05） |

---

## 2. 核心解题机制

* **攻击链阶段时间轴**：按侦察→入侵→横向→外泄等阶段串起事件序列；
* **实体关联图**：把源 IP、账号、资产、文件等实体关联起来，呈现影响面；
* **处置证据链**：每步研判结论附可复核证据（原始日志/报文摘要）。

---

## 3. 结构骨架

```text
攻击链时间轴
侦察 ── 入侵 ── 横向移动 ── 数据外泄 ── 处置 ●
  │      │        │           │
  └─证据 └─证据   └─证据      └─证据        [一键遏制] [标记误报]
──────────────────────────────────────────────
关联实体：源IP 10.x.x.x · 账号 svc-a · 资产 web-03 · 样本 a1b2…
```

---

## 4. 交互闭环关键点

* 结论必须与证据同步呈现，支持逐条复核与溯源；
* 高危遏制操作需二次确认并可回滚；
* 支持从阶段节点穿透到该阶段的原始日志明细。

---

## 5. 常见发力方向（方向级，供步骤 2 挂靠）

| 发力方向 | 体验维度 |
| :--- | :--- |
| 让攻击路径与影响面被清晰还原 | 可见性 / 掌控感 |
| 让研判结论可复核、可采信 | 可解释 / 信任感 |

## 7. 反模式与禁忌

* 🛑 严禁只给黑盒“高危”结论而无证据链；
* 🛑 严禁把安全事件做成酷炫大屏而无研判价值；
* 🛑 严禁高危遏制操作无二次确认、无回滚。
