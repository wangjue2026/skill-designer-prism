### `internal-reverse-proxy.js` —— 内网系统访问通道

**用途**：为蒸馏取证打开内网系统的访问通道。

**什么时候需要它**：目标系统位于内网，且内置浏览器**直连打不开**时。典型症状是
`ERR_CERT_AUTHORITY_INVALID` —— 内网多用自建 CA 签发的证书，内置浏览器不信任，
而内嵌 Chromium **不像完整 Chrome 那样提供"继续前往"入口**，导致无手动放行的机会。

**原理三步**：

| # | 机制 | 解决的问题 |
| :---: | :--- | :--- |
| ① | 忽略上游证书校验（`rejectUnauthorized: false`） | 绕开自建 CA 的信任链问题 |
| ② | 以纯 HTTP 暴露在 `127.0.0.1:<PORT>` | 本地回环 + 明文 HTTP，不存在证书校验环节 |
| ③ | 改写响应内容（URL 重写 + `WEB_HTTPS` 中和） | 否则前端会自行跳回 `https://<内网>`，再次失败 |

第 ③ 步同时处理了 `location` / `origin` / `referer` / `Set-Cookie` 的 `Domain` 与 `Secure`，
并转发 WebSocket 升级（SPA 的长连接依赖它）。

**用法（每次三步）**：

```bash
# ① 起代理（TARGET 与 PORT 均为必传，PORT 需独占）
TARGET=<内网地址> PORT=<独占端口> node tools/internal-reverse-proxy.js

# ② 在浏览器打开本地地址（而不是原内网地址）
#    http://127.0.0.1:<独占端口>/<路径>

# ③ 需要登录则交给规划人员手动登录 ➜ 取证 ➜ 用毕停止进程
```

**已知坑**：

| 坑 | 说明 |
| :--- | :--- |
| **端口必须独占** | 一个目标一个端口，**绝不复用**（复用会串台，指向错误的目标系统） |
| **TARGET 无默认值** | 脚本是通用工具，不内置任何内网地址，必须显式传参 |
| **仅支持 HTTPS 上游** | 若目标本身是 http，需改用 `http.request` 微调 |
| **脚本位置** | 本脚本已从临时目录固化入库，请统一使用本路径，不要再复制到 `/tmp` |

> ⚠️ **合规声明**：本脚本会**关闭 TLS 证书校验**，仅用于**自有内网系统的设计蒸馏取证**，
> 请勿用于第三方系统。
>
> 📌 **内网地址不入库**：使用说明中的地址一律以 `<内网地址>` 占位，真实地址由规划人员本地留存。

### `cdp-capture.js` —— 已登录环境的只读取证（CDP）

**用途**：目标系统已在规划人员的 Chrome 中登录时，经 Chrome 远程调试端口（CDP）对页面做**只读取证**——整页截图 / 可见文本 / DOM 读数 / 导航，**不新建浏览器、不改动页面状态**。

**前置**：Chrome 以 `--remote-debugging-port=9222` 启动（可用环境变量 `CDP_PORT` 覆盖）。

| 命令 | 作用 |
| :--- | :--- |
| `list` | 列出所有可取证页面（标题 ＋ URL） |
| `shot <关键字> <输出png>` | 对匹配页面整页截图（`captureBeyondViewport`） |
| `text <关键字> [最大字符]` | 导出页面可见文本 |
| `eval <关键字> "<JS表达式>"` | 在页面上下文只读求值 |
| `probe <关键字>` | 一次输出该页的关键读数（表头 / 量级 / 行高 / 页大小 / 冻结线 / 列设置 / 卡片 / Tab） |
| `nav <关键字> <一级模块> <二级页面>` | 按左侧菜单进入指定子页面（自动判断菜单展开态） |
| `click` / `hover` / `mouse <关键字> <x> <y> [click]` | 真实鼠标事件（部分 SPA 菜单仅响应真实事件） |
| `open <关键字>` | 将该标签置前（便于人工核对） |

**已知坑**：

| 坑 | 说明 |
| :--- | :--- |
| **会话掉线** | 页面关键字按 URL / 标题子串匹配；会话过期后标签会跳到登录页，须**人工重新登录** |
| **侧栏折叠** | 折叠态下菜单标签为空 → 先执行 `mouse <关键字> 24 60 click` 展开侧栏 |
| **真实事件** | 合成事件对部分 `ix-menu` 无效，统一用 `click` / `mouse` 发真实鼠标事件 |
| **素材不入库** | 截图等取证素材存仓库外（如 `/tmp`），避免内网画面与地址入库 |

> ⚠️ **合规声明**：仅用于**自有内网系统的设计蒸馏取证**，请勿用于第三方系统。

### `design-spec-selfcheck.sh` —— SP-A / SP-W 机检载体（gate-sp.sh 的一段）

**用途**：把**资产层与线框层**的硬错（资产引用杜撰 / 样式自造 / 线框规范不符）用机器拦住，不再靠规划人员逐轮挑错。**它不是独立闸门**：由 `tools/gate-sp.sh` 统一调用，只覆盖总表 `SP-A-01~06` ＋ `SP-W-01~03/05`；**单跑 11/11 不等于过 SP**（查不了 `SP-C` 内容一致性与 `SP-D` 自包含）。

**用法**：

```bash
# 交付入口（唯一）：两段串行，任一 FAIL 即整体 FAIL
bash tools/gate-sp.sh _output/<业务名>/design-spec-<业务名>.html

# 只想看资产 / 线框的细项时单独跑（结果不构成准出）
bash tools/design-spec-selfcheck.sh _output/<业务名>/design-spec-<业务名>.html
# 退出码 0 = 11/11 全绿；退出码 1 = 存在未通过项（必须先修，严禁带病交付）
```

**十一项检查**：

| # | 检查项 | 判定标准 | 拦住的病 |
| :---: | :--- | :--- | :--- |
| 1 | 结构完整性 | 五章齐备 **或** Part1/Part2 两段式（2 个 `h2.part`）+ 存在分页面小节（`h3 4.x` 或 `h4 7.x`） | 章节缺失 |
| 2 | 组件真实性 | 每个 `Ix*` 要么在 `idux-component-map.md` 登记，要么在稿内显式声明来源（未登记 / 保留蒸馏名） | 杜撰组件名 |
| 3 | 模板真实性 | 每个 `page-*` 要么在 `01-page-types.md` 存在，要么显式声明（库缺口 / 产线差异） | 杜撰模板 ID |
| 4 | 色值合规 | 所有 `#RRGGBB` 命中 `03-design-assets/` 全量色板 | AI 自造色值 |
| 5 | 按钮用色铁律 | 无"危险型"按钮；无红色实心按钮（danger 底 + 白字） | 红色按钮 |
| 6 | 引用可解析 | 稿内引用的 `.md` 文件均真实存在 | 失效引用 |
| 7 | 经验落点 | 每条被引用的 `EP-xx` 均在「四、核心页面」中有承载 | 空头引用 |
| 8 | 表单左右结构 | 严格遵循左 Label 右 Control 水平左右结构，严禁上下堆叠反模式 | 表单上下堆叠 |
| 9 | 标杆特征物保真度 | **动态契约驱动**：动态加载对应类型的 `signatures/<Type-xx>.json`，核验声明 EP 的物理指纹（未配契约的类型自适应跳过） | 经验执行降级与缩水 |
| 10 | 线框规范符合度 | 弹窗/抽屉页脚主按钮在左、取消在右；操作按钮不带前置图标；表单 Label 非必填项留星号占位；弹窗/抽屉宽度命中允许档位；页面模板与线框容器原语一致（drawer↔modal 不跨用）；线框 UI 文案不泄漏 `EP-xx` / `D0x-EPxx` | 线框与设计资产规范对不上（按钮顺序/图标/表单对齐/宽度超档/容器选型/编号泄漏） |
| 11 | 可视化件声明完整性 | 含可视化件的页面，其《可视化件声明》（`class="viz-decl"`）五字段齐全：件型 / 图形编码规则 / 风格规范 / 交互与退化 / 可替代性 | 图表用通用占位糊弄、可视化件漏声明 |

**附加提示项（不计入 11 项通过率）**：

| 项 | 判定标准 | 拦住的病 |
| :--- | :--- | :--- |
| 线框数据完整度 | 线框区（已排除 `details.sketch-fold` 草图折叠区）**不应残留 `__` 占位符**；命中只提示 ⚠️，不改退出码 | 把草图的占位直接搬进线框，评审看不出列宽、截断与一屏信息量（见 `5.0` 铁律第 18 条） |

> 📌 提示项**不阻断交付**，但出现即说明该页线框还没到"落地级"：须用一套跨页自洽的示例数据补齐，并在第 7 节开头声明示例口径。

**设计要点**：

| 点 | 说明 |
| :--- | :--- |
| **白名单取自资产库** | 色板白名单**动态**从 `03-design-assets/**/*.md` 全量提取，资产一更新，闸门自动收紧，无需改脚本 |
| **两轨制友好** | 组件 / 模板允许"未命中但已声明"通过，与「两轨制」一致——**声明即合规，杜撰才拦截** |
| **可回填** | 因资产缺登记而反复 FAIL 时，正确做法是**回填资产库**，而非在稿内绕过 |

> 📌 **每次出稿必跑**：它是流程动作，不是可选检查。
