一、需求洞察与体验目标

1. 目标用户与核心任务 (JTBD)

  • 资产运营人员（主维护角色）
    • 使用情境：ESM 扫描结果、被动流量、端侧上报和 Excel/CSV 文件四类来源不断产生资产记录，字段和标识口径各不相同；需要把这些记录收敛成一套可维护、可追溯的服务器与终端资产。
    • 核心任务：“我要把各来源送上来的资产记录，一次整理成不会重复、不会分错类型的正式资产，并且能像维护现有 WEB 应用资产那样查、改、导出和对账。”
  • 安全运营人员（消费角色）
    • 使用情境：不直接维护资产字段，但要把统一资产对象引用到后续安全运营中。
    • 核心任务：“我需要一套口径稳定、标识唯一的资产清单，让我直接引用而不用再核对。”

2. 主场景清单与现状痛点

3. 核心体验改进目标

  • 1. 多源整理：四类来源分散整理（不同入口、不同口径） ➔ 统一入池、一次识别；可观察判据：任一首期来源结果到达或文件导入完成后即形成服务器或终端资产，通用字段完整率 ≥ 95%。
  • 2. 身份连续性：人工比对（易重复、易错归） ➔ 规则化归并、连续可追溯；可观察判据：同一 Agent 标识的资产 IP 变化后，平台仍引用同一内部资产标识，并更新当前 IP、保留历史 IP。
  • 3. 台账查看与维护：字段缺失、口径不一 ➔ 完整字段 + 与 WEB 应用资产同口径的就地查看与维护；可观察判据：服务器/终端可获取全部通用字段与专属字段，通用字段可查询、可筛选；10 万级资产可查询、可查看。
🚫 本期不承诺（Non-Goals）：识别与入库失败的状态机、重试与幂等（OPEN-TR1-008，系统需求阶段关闭）；风险数量 / 风险摘要 / 风险跳转；第三方资产平台与 CMDB 自动同步；影子资产、主机漏洞、主动渗透与风险处置；国际化与 NFV（OPEN-NFR-006/007）。以上不派生为前台能力。

二、设计思考、设计决策经验匹配与采纳

1. 需求类型分析 (四子弹定局)

  • 需求类型定性：Type-01 对象与资产管理类。判据：主键是实体（服务器 / 终端资产），对象长期存在并带台账属性（权属、归属、状态），需按类型批量维护，且有生命周期（发现 ➔ 变更 ➔ 退库）。
  • 业务属性与严肃度：企业统一资产治理，中等严肃度 (Standard Enterprise)。资产是下游安全运营的引用基础，字段与口径要求稳定准确，但单条操作多为可逆的常规维护，不需要极重确认。
  • 色彩基调：现代扁平 / 高效规整。超浅底 #F7F9FC 划分区域、卡片白底、去框线化、线条 1px；状态一律“浅底 + 深字 + 浅边框”三元组；全系统只有品牌蓝主按钮，不使用红色实心按钮（破坏性靠二次确认防呆）。
  • 页面职责分工：台账页只管“查 / 筛 / 看 / 维护 / 盘点”；资产识别与入库是后台统一链路，本期不新增前台识别页。
  • 经验来源判定（关键）：纵向 Type-01 分册当前未蒸馏（无经核实的标杆案例），按调度规则“命中类型但分册未覆盖 → 该设计问题走横向”，因此本次全量走横向通用设计决策库，执行《横向库承接与场景拆解桥协议》：把业务场景拆成设计问题 + 分析维度取值，去 D-01~D-11 母尺读数。

五、页面体验与异常保护规则

  • 🛑 状态覆盖完备性：列表与详情均需覆盖加载 / 空 / 部分失败三类态；识别与入库失败的完整状态机、重试与幂等属 OPEN-TR1-008，在系统需求阶段冻结，本期不在前台新增异常状态页。
  • 🛑 加载态与空状态：首屏用 IxSpin（重页带文案）；空数据保留工具栏并展示 IxEmpty；筛选无结果时给“修改筛选条件”引导，不堆砌无关引导语。
  • 🛑 高危破坏性操作防呆：删除一律走 IxModal 阻断确认，原样回显资产名称与唯一 ID，并列出将受影响的来源映射与引用；批量删除回显所选数量与对象集合。
  • 🎨 按钮用色铁律：全系统只有品牌蓝主按钮（#1C6EFF）与描边普通按钮，不使用红色实心按钮；破坏性操作靠“二次确认 + 影响面回显”防呆。
  • 🛑 批量动作安全带：未勾选任何资产时，批量编辑 / 删除 / 导出整组置灰并保留可见，勾选后激活并回显“已选（N）”；表头全选仅作用当前页。
  • 🔍 来源与字段可解释：字段值支持查看来源观察与命中依据；人工值优先级最高，不被自动来源覆盖；存在字段冲突时保留待处理状态而非静默覆盖（REQ-HOST-009）。
  • 🔐 权限与审计：导入、人工修改、来源映射与合并等关键操作按平台权限体系校验，权限不足时拒绝且不改变数据；操作记录可追溯（对象 / 来源 / 关键依据 / 结果 / 操作者，REQ-HOST-011）。
  • 📈 规模与结果护栏：支持 10 万级资产查询与查看；结果集超出引擎上限时显式提示“仅展示前 N 条”，不静默丢记录；分页默认每页 20。
  • 🧾 客户端与页面文案人性化：面向资产运营人员的提示使用业务语言，专业代码与字段标识放括号内辅助，不出现底层报错码。
  • 🚫 范围护栏：不提供风险数量、风险摘要或风险跳转入口；不把资产能力推导为前台风险能力（Non-Goals 已冻结）。
