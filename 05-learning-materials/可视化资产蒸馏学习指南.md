## 第二章 六步统一流程（任何件型都走这六步）

```text
S1 定件型    D-11 母尺 ①要不要做 → ②.1 用哪个内容件 / ②.2 用哪个图表
             产出：件型键（VIZ-0x-形态 / CHART-家族·子类型）
S2 起通道    Chrome 独立 profile + 9222；必要时内网反向代理；确认 cdp-capture list 命中
S3 全景取证  整页截图（/tmp）＋ 可见文本 ＋ 区域结构树（容器层级、尺寸、position）
S4 分层量取  按第三章字段字典，逐层取几何 / 颜色 / 字阶 / 阴影（数值优先，截图只校验）
S5 交互取证  hover / click / 折叠 / 缩放 / 空态 / 加载；必须做"干净态三步验证"
S6 落库验收  四件套 + 台账 + 裁决；check 脚本 + grep 复核落盘
```

**S3 的前置判断**：先看页面有没有现成"区域容器"（`getBoundingClientRect` + `position`），再决定从哪个祖先开始遍历。**从 `body` 平铺遍历会得到上千个节点，必然读不完**。

**S4 的终止条件**：能回答"每一层的高、内距、间距、圆角、底色、描边、字阶、色值"六项，且每项都有读数、不是"看起来差不多"。

**S5 的终止条件**：hover 每个可交互对象、click 每个可疑对象，并明确记下"**哪些没有反馈**"（没有也是结论）。

## 第三章 通用采集字段字典（所有件型共用）

### 3.1 怎么取

```js
const d = document.querySelector("iframe")?.contentDocument || document;  // 有 iframe 就穿透
const el = d.querySelector("<选择器>");
const r = el.getBoundingClientRect();
const c = getComputedStyle(el);
// 几何取 r.width / r.height / 相对父级 x,y；样式取 c.*；伪元素用 getComputedStyle(el, "::before")
```

- **相对坐标**要减父级 `rect`，否则写进线框时会带进无关偏移；
- **`getBoundingClientRect` 反映变换后的视觉尺寸**（含 `transform: scale`），若页面有缩放要同时记 `offsetWidth`；
- **伪元素**（竖条、箭头、点）必须单独读 `getComputedStyle(el, "::before")` 的 `width/height/background/content`，截图看不出来源。

### 3.2 几何字段（缺一项即不可还原）

| 字段 | 取法 | 常见误读 |
| :--- | :--- | :--- |
| 容器宽高 | `rect.width/height` | 与内容实际包围盒不一致时**两个都记**（例：节点声明 200×32、内容溢出到 178 高） |
| 内距 | `padding`（四向分别记） | 只记 `padding: 8px` 会丢左右不对称的情况 |
| 项间距 | `gap` / 相邻项 `rect` 差 | **行距 = 行高 + gap**，两者必须分开写，不能含混成"行距 40" |
| 描边 | `border-width/color/style` | 白描边（`1px #FFFFFF`）在浅底上截图看不见，只有读样式才知道存在 |
| 圆角 | `border-radius` | 子元素圆角被父级 `overflow:hidden` 裁切时，子元素自身读到 0 |
| 阴影 | `box-shadow` | 要区分"卡片浮起影"与"节点柔和落影"，两者数值差一个量级 |
| 定宽 | 元素 `width` 是否固定 | **没有定宽就没有截断**；看到 `ellipsis` 必须量容器宽 |
| 层级 | `z-index` / DOM 顺序 | 浮层/工具条常是 `position:absolute` + 高 `z-index`，不在主文档流里 |

### 3.3 颜色字段

1. **先查命名 token**：`03-design-assets/tokens-cheatsheet.md` 与 `token/基础-token.md`；
2. 命中 → 写 `命名 token（值）`；未命中 → 先判能否归位到现有色阶，仍不行才登记**件型级 token**；
3. **裸 hex 永远要带命名**，否则视为自造色；
4. 状态色遵守**三元组**：浅底 + 深字 + 浅边框，禁原生高饱和纯色。

### 3.4 字阶

- 记 `font-size / font-weight / line-height / color` 四项；
- 样式库只有 `14/22`、`12/20` 两档时，出现 `20/700`、`24/700` 这类**无命名档**，照实写数值并注明"样式库无此档"；
- **数值字重**：0 值与有值时若只差颜色，必须两态都记（否则回归时会写成一色）。

### 3.5 状态与交互（表：触发 → 要记什么）

| 触发 | 记录项 |
| :--- | :--- |
| 默认 | 底 / 描边 / 阴影 / 字色 |
| hover（对象本体） | 描边色变化、阴影变化、位移/缩放、`cursor` |
| hover（是否出浮层） | 浮层尺寸 / 圆角 / 底 / 阴影 / 内距 / 头行 / 字段行结构 |
| 点击 | URL 变化、同标签或新标签、抽屉/弹窗（选择器 + 尺寸） |
| 选中态 | **先证伪再用**：是否高亮自身、是否置灰其他元素 |
| 禁用 / 不可用 | 透明度、色值、是否仍可 hover |
| 空 / 加载 / 无权限 / 全零 / 单点缺失 | 有没有样本；无样本标 🚧 并写建议 |
| 折叠 / 展开 | 前后高度、图标方向、动画时长 |
| 缩放 / 拖拽 | 是否出滚动条、控件默认态（收起/隐藏） |

**干净态三步验证**（判定"是交互态还是数据态"）：

```text
① location.reload()（iframe 内执行）
② 等渲染完成（轮询关键元素出现，SPA 可能要 10s+）
③ 鼠标移到窗口角落 (5,5)，避开画布 → 读一次 → hover 目标 → 再读 → 移开 → 再读
三次一致 = 数据驱动；不一致 = 交互态，补"进入/保持/退出"三段取值
```

### 3.6 结构量：只写规则，不写数字

| 错误写法 | 正确写法 |
| :--- | :--- |
| 三列：x=16 / 692 / 1064 | 列数 = 分组维度数；列起点按内容排布，列间留白 ≥ 32 |
| 组内固定 4 行，行距 68 | 行距 = 节点高 56 + 12，行数 = 该组对象数 |
| 概览卡两栏 552 / 625 | 栏数 = 字段组数，栏宽按内容均分 |
| 图例列 528 宽 | 图例列宽随容器，图标 32，行距 12 |
| 步骤 3 步 | 步骤数 = 任务阶段数，>4 步改竖排/折叠 |

### 3.7 证据等级（引用时必须标）

| 等级 | 含义 | 允许用作 |
| :--- | :--- | :--- |
| A · 设计源文本 | 设计文档原文规则 | 规范结论 |
| A · 设计源属性 | 属性面板 / 矢量导出的真实 CSS、命名样式 | 规范数值 |
| B · 实现层实测 | 线上 DOM 计算样式（CDP 量取） | 实现对照，**不冒充设计源** |
| C · 截图取色 | 仅用于未暴露的系列色，误差 ±1 | 交叉校验 |
| 🚧 | 未取到 | 只能标缺口，**不得脑补** |

## 第五章 图表件采集卡（`CHART-*`）

### 5.1 通用必采 12 项（任何图表都要）

| # | 项 | 取法 / 说明 |
| :---: | :--- | :--- |
| 1 | 图表容器尺寸 | 父级 `rect`；图表按容器自适应，必须记"设计稿给的高"与"实际渲染高" |
| 2 | 内边距 / 绘图区 | `grid` 四向；决定标签是否被裁 |
| 3 | 轴 | 轴线色/宽、刻度线长、刻度文字字号色、轴标题有无 |
| 4 | 网格线 | 方向（横/竖）、颜色、虚线段长与间隔 |
| 5 | 柱宽 / 点径 / 线宽 | 柱 `barWidth`、折线 `lineWidth`、散点 `symbolSize` |
| 6 | 类目间距 | 柱 `barGap`（**单位是百分比还是 px 必须写清**） |
| 7 | 圆角 | 柱顶圆角（堆叠只顶段给）、横向柱圆角方向 |
| 8 | 渐变 | 方向（`linear-gradient` 角度 / ECharts `x1x2y1y2`）+ 两端色 + 停靠点 |
| 9 | 图例 | 位置（上/右）、图标尺寸、文字字号色、列数、翻页规则 |
| 10 | 数据标签 | 是否显示、字号色、位置（柱顶/柱内/柱端）、数值格式化 |
| 11 | tooltip | 底/圆角/阴影/字号色/触发方式/延迟 |
| 12 | 状态 | 空 / 加载 / 全零 / 单点缺失 / 极端量级（**没样本就标 🚧**） |

### 5.2 分家族差异（易漏点）

| 家族 | 额外要点 | 坑 |
| :--- | :--- | :--- |
| 柱状图 | 竖向/横向/标签在上方三种；分组/堆叠两套关系；卡片化容器 | 堆叠圆角只给顶段 `[1,1,0,0]`；`barGap` 百分比与 px 混用 |
| 折线图 | 平滑 vs 折线（波动大看趋势→平滑；读准确值→折线）；面积填充透明度；点径与 hover 放大 | 无序分类禁用折线；面积图不要另立家族（`Line + areaStyle`） |
| 饼图 | 环形是 iDux 默认（`radius` 缺省）；实心需显式 `radius:'80%'`；玫瑰 `roseType:'area'`；图例/标题在右；环形双层圆底（外 144 / 内 80，按短边等比） | 饼类目 >10 或和 ≠100% 就别用；双层底用固定 px 会在小容器崩 |
| 面积图 | 条纹/阴影两种写法；两端透明 | 与折线区分靠 `areaStyle`，不是新组件 |
| 玫瑰图 | 角度 vs 面积语义 | 与环形混用会导致读者误读比例 |
| 气泡 / 条形 / 子弹 | 整类未采 | 需求命中时**先立键再采**，不能临时自造图形 |

### 5.3 从 iDux 文档取源码（省一半功夫）

```text
打开组件文档页 → 示例右上角 "<>" 展开源码 → 复制到 demo
要点：先复制可运行的最小示例，再按设计源 token 改色改宽，不要从零写配置
```

### 5.4 图表落库四件

1. `图表件/<家族>.md`：解剖 / 尺寸 / 配色 / 轴与网格 / 图例 / 标注 / 状态词表 / 反例；
2. `图表件/<家族>-亚型规范.md`：逐亚型的结构线框 + 还原判据 + 官方源码；
3. `图表件/demo/<键>.html`：最小可运行，**一键一文件**，拼装而非重写；
4. `token/图表-tokens.json`：机读镜像（键 → 变体 → 数值规范），改完必须同步。

### 5.5 图表校验（每次改完跑）

```bash
node tools/check-charts.js     # C1 键一致 / C2 色值覆盖 / C3 游离色值 / C4 相对链接 / C5 裁决台账有带日期行
```

## 第八章 坑库（按发生频率排序）

### 8.1 采集坑

| 坑 | 症状 | 处理 |
| :--- | :--- | :--- |
| 调试端口没生效 | `curl 9222` 无响应 | Chrome 136+ 必须独立 `--user-data-dir` |
| iframe 取不到 | `contentDocument` 为 null | 跨域或未加载完；先代理 + 等渲染 |
| 鼠标点不中 | 点了没反应 | 坐标未加 iframe 偏移；或需真实 `Input.dispatchMouseEvent` |
| 浮层残留 | "卡片也有浮层" | 每次 hover 前先移到空白 |
| 把数据态当交互态 | 以为"点击后其余置灰" | 干净态三步验证（3.5） |
| 只截图不取数 | 评审时说不出 px | 截图只做交叉校验，数值必须来自 DOM/SVG |
| 容器尺寸 ≠ 内容尺寸 | 线框高度画错 | 两个都记并标差异 |
| 2.5D 用 `perspective` 硬凑 | 节点近大远小、与素材透视打架 | 平面用纯旋转矩阵、节点用逆矩阵扶正（样式卡 §3.8.6） |
| 连线画在 canvas 上却想读样式 | `getComputedStyle` 读不到线宽/色 | 用 `getImageData` 统计颜色与连续段长度（相当于量线宽） |
| 背景图案靠猜 | 点阵间距写错 | `fetch` 背景 SVG 读 `<pattern>` |
| 素材入库 | 内网地址/截图进仓库 | 一律 `/tmp`，用完删 |

### 8.2 判型坑（错件比缺件更糟）

| 混淆 | 分清判据 |
| :--- | :--- |
| ③ 原理图 vs ⑤ 配置图解 vs ⑧ 拓扑 | ③ 讲原理（可收起图文）／⑤ 讲"这项配置影响谁"（左配置右图）／⑧ 关系本身是主体 |
| ① 概览 vs ⑨ 摘要榜 | ① 指标名+值，无实体；⑨ 多对象+排序，回答"先管谁" |
| ⑩ 分布条 vs 饼图 | 单类目构成 → 饼/环；多类目并列 → ⑩ |
| 内容件 vs 图表件 | 装在哪 → `VIZ`；图形怎么画 → `CHART`；一个容器里两者可叠加 |
| ⑨ 摘要榜 vs 表格 | 有表头/列宽/多列排序 → 表格 |

### 8.3 落库坑

| 坑 | 后果 | 处理 |
| :--- | :--- | :--- |
| 业务名/业务规则混进规范 | 下个需求照搬就错 | 改框架名；业务规则归说明书第四章 |
| 列数/行数/个数写死 | 换需求就崩 | 写规则（3.6） |
| 设计源与实现层混拼 | 比例失真 | 同页只用一套；差异进裁决台账 |
| 一值多处定义 | 漂移 | 一值一出处，别处引用 |
| 只有正向样本 | 0 值/空态/超限必翻车 | 补两态对比；无样本标 🚧 |
| 杜撰组件/图标名 | 交付对不上 | 只写实测名 |
| 拿实现层值冒充设计源 | 证据等级错 | 标注 A/B/C |

### 8.4 图表专属坑

| 坑 | 说明 |
| :--- | :--- |
| `barGap` 单位 | 百分比与 px 混用会差一倍 |
| 图例翻页 | 死规则"超过两行必须翻页"已被覆盖为"按可用高度排满再翻" |
| 渐变方向 | CSS `270deg` = 右→左；ECharts 用 `x:1→x2:0`，写反会暗端在左 |
| 堆叠圆角 | 只顶段给圆角，全段加会露齿 |
| 饼图双层底 | 必须按容器短边等比，写死 px 会在小容器崩 |
| 柱宽 | 常态 `barWidth = 10`，设计源的 6px 是下限 |

### 8.5 工具坑

| 坑 | 症状 | 处理 |
| :--- | :--- | :--- |
| 大文件编辑静默失败 | 工具报成功，`git status` 没变 | 改用脚本写入 + `grep` 复核 |
| 链接漂移 | 目录改名后文档还能打开但点进去空 | 改完跑 `node tools/check-links.js` |
| 图表资产漂移 | 键/色值 md 与 json 不同步 | 跑 `node tools/check-charts.js` |
| 交付物自检 | 说明书/线框硬伤 | `bash tools/gate-sp.sh <spec> [<sketch>]` |

## 第九章 验收清单

### 9.1 通用 12 条

```text
[ ] 件型键已落（VIZ-0x-形态 / CHART-家族·子类型），未用口语名
[ ] 解剖写成「容器 ▸ 区 ▸ 项」
[ ] 几何六项全有值（高 / 内距 / 间距 / 圆角 / 描边 / 定宽）
[ ] 每个色都能反查命名 token
[ ] 每处文字都有 字号 / 字重 / 行高 / 色
[ ] 状态：默认 + hover + ≥1 异常态（或 🚧 说明）
[ ] 交互：触发 / 反馈 / 可否下钻（含"无反馈"结论）
[ ] 结构量写成规则，无写死数字
[ ] 口径标注（设计源 / 实现层 / 示例）齐全
[ ] 线框无 `__`，示例数据中性且已声明
[ ] 反例节存在，能指认错误做法的后果
[ ] check-links 0 断链；改图表再跑 check-charts
```

### 9.2 分件型"一眼验收"

| 件型 | 关键三条 |
| :--- | :--- |
| ① | 项高/间距分开写；数值两态色；分析型双区不重复定义图形 |
| ② | label 定宽；字段栅格列数；超长值截断策略 |
| ③ | 位图 or SVG 已判；禁 DOM 重绘；不越界成拓扑 |
| ④ | 序号尺寸；步骤数上限；关闭后是否记忆 |
| ⑤ | 左右栏宽规则；不越界成拓扑 |
| ⑥ | 高亮形态明确；联动延迟；预览不可用表现 |
| ⑦ | 失败/回退态；阶段数压缩；不越界成拓扑 |
| ⑧ | 连线画法与 marker；曲率是路由不是参数；数据分级 ≠ 选中态；2.5D 是否纯旋转矩阵 + 节点扶正 |
| ⑨ | 序号与行底同系；截断方向；计数 = 1 文案 |
| ⑩ | 0 值与未上报区分；段色序；类目定宽 |

```js
// 1) 结构骨架：列出可见容器的层级 / 尺寸 / 定位
(() => {
  const d = document.querySelector("iframe")?.contentDocument || document;
  return [...d.querySelectorAll("div,section,ul")].slice(0, 80).map(e => {
    const r = e.getBoundingClientRect(); const c = getComputedStyle(e);
    return [e.tagName, ((e.className || "") + "").slice(0, 36),
      Math.round(r.width) + "x" + Math.round(r.height), c.position,
      c.fontSize + "/" + c.fontWeight].join(" | ");
  }).filter(s => !s.includes("0x0"));
})()
```

```js
// 2) 单元素全量读数（几何 + 样式 + 伪元素）
((sel) => {
  const d = document.querySelector("iframe")?.contentDocument || document;
  const e = d.querySelector(sel); const r = e.getBoundingClientRect();
  const c = getComputedStyle(e); const b = getComputedStyle(e, "::before");
```
